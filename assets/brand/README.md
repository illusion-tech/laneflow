# LaneFlow 品牌标记

LaneFlow 标记由三条嵌套的转向流线组成。平行路径表达车道与确定性推进，连续转向
表达从静态路网到运行时与表现层的流动；图形不绑定车型、引擎或具体应用场景。

## 资产

| 文件                     | 用途                         |
| ------------------------ | ---------------------------- |
| `laneflow-mark.svg`      | 浅色背景上的默认彩色版本     |
| `laneflow-mark-dark.svg` | 深色背景上的高对比彩色版本   |
| `laneflow-mark-mono.svg` | 无法使用颜色时的深色单色版本 |

三个文件都使用透明背景和 `viewBox="0 0 256 256"`，不包含字体、位图、滤镜或外部资源。

## 使用规则

- 数字界面中的最小建议尺寸为 `24 × 24 px`；低于该尺寸时不保证三条路径都清晰。
- 标记四周应保留至少一条路径宽度的净空，即显示宽度的 `28 / 256`。
- 保持原始宽高比和路径相对位置；不要拉伸、裁切、旋转或重新排列路径。
- 不添加渐变、阴影、描边外框、背景底板、文字或其他图形。
- 浅色背景使用默认版本，深色背景使用 dark 版本；只有单色媒介使用 mono 版本。
- 标记旁边已有可见的 LaneFlow 标题时可使用空 `alt`；单独出现时使用 `alt="LaneFlow"`。
