# 准入空贡献筛选的远处限速下降证明

**文档状态**: Accepted（#832 / PR #833；#834 接受设计，候选未采用）<br>
**最后更新**: 2026-10-08<br>
**适用范围**: 道路机动车准入候选缓存完整重建时，非空限速下降后缀的预览成功性

本提案补充[准入筛选合同](traffic-runtime-admission-contender-filter.md)第 3.4 节，
不替换其已接受的身份、权利、ETA、严格同边运动、原校验、空 owner、错误及资源合同。
它不是放开所有限速下降，也不把 P2 可将运动错误后移 P5 的论证用于公共准入命令。
设计接受只允许按充分条件验证候选，不预先认证产品收益。
#834 的[独立实现与有界测量](../../research/issue-707-city-parallel/admission-distant-results.md)
通过定向正确性与资源验证，但未显示可重复收益，已撤回产品候选。当前 Runtime 仍使用完整预览。

## 1. 问题与本次边界

[#830 的未采用结果](../../research/issue-707-city-parallel/admission-filter-results.md)
显示：观察窗只筛除 1.0494% 扫描，5967157 次扫描因后续限速下降而回退。
两组普通配对的公共命令耗时均增加。该回退数不等于本提案的命中数或潜在收益；
旧候选、失败记录和否定结论保持原样，不因新设计改写。

本次只证明一类充分条件：**第一处下降虽存在，但其精确有限距离严格超过已有制动窗上界**。
标量完整预览的两个降速循环因此均在首项成功退出，不调用降速投影、不读取后续下降项。
这比证明任意近处下降的求解一定成功更窄。近处、边界相等及不能证明的情况仍走完整路径。

本设计不新增公开 API、格式、配置开关、常驻缓存或依赖；不改变普通 step、P5、
增量刷新、错误分类、交通安全规则和所有权生命周期。实现与测量须另立任务记录 G2。

## 2. 已有源码与不能直接复用的结论

源码核对基线为 `d046d80619dcc7716e00e1e9f1a91806531c240f`；实现前重新核对所选基线。

| 原语 / 路径                                    | 当前行为                                                       | 本提案的使用方式                                                       |
| ---------------------------------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `tick.rs::speed_drop_window_upper`             | 用受检数值与原 `f32` 顺序构造最大后继速度和制动窗              | 直接复用同一函数，不复制公式或改变其原消费者                           |
| `columnar_motion.rs::speed_drop_may_constrain` | 无可读取下降项、`BeyondFinite` 均返回 false；查询失败返回 true | 只作现有证明与测试的参考，不把 false 直接当成准入成功性证书            |
| `MotionCursorRow::speed_drop_distance`         | 已匹配行可给出空或有限距离，否则要求完整查询                   | 首版不新建或跨命令复用该缓存；从当前路线调用原距离查询                 |
| `tables.rs::distance_to_occurrence_start`      | 分段坐标得到精确有限距离、`BeyondFinite` 或失败                | 使用与标量循环相同的起点、目标 occurrence 与进度；仅接纳成功的有限结果 |
| `constrain_upcoming_speed_limits`              | 先读取首项距离；距离大于本次制动窗便 break；否则可能投影       | 证明其首项距离查询成功且严格在窗外                                     |
| `clamp_travel_to_speed_down_boundary`          | 先读取首项距离；距离不小于实际位移便 break                     | 用同一上界证明首项也在最终积分位移之外                                 |

特别注意：原循环使用 `speed_limit_drop[first..]`。`get(first)` 的 None 既可能是
合法空后缀，也可能是越界，不能据此跳过原本会失败或暴露内部不变量错误的路径。
准入专用包装必须先以受检切片查询区分这两种情况；它只返回“已证明”或“完整求值”，
不新增命令错误、也不将查询失败改成准入成功。

## 3. 准入专用充分条件

只有原准入合同全部前提成立后，才进入以下附加检查。每次检查读取当前绑定的完整路线
句柄、profile、hop、cursor、`progress_mm` 和 `carry_um`，不使用上一命令或上一拍结果。

1. 读取当前 hop 的 `speed_drop_first`，受检取得 `speed_limit_drop[first..]`。
   无法取得时回退；合法空切片保留原空后缀分支。
2. 对非空切片只取首项，不跳过不明首项去找更远项。以与原循环一致的受检转换和
   `from_route_edge_index + 1` 取得目标 occurrence，复用原分段距离查询。
3. 距离必须为 `Finite(mm)`。`None`、`BeyondFinite`、缺失列、索引或加法溢出均回退。
   同一物理边的不同 occurrence 不合并；不使用后缀路终相减替代分段距离。
4. 复用 `speed_drop_window_upper`，其 `desired` 是当前 profile 期望速度与当前边限速
   的较小值，不能直接用 profile 期望速度替代。其他参数与原预览完全相同。
5. 上界不可构造时回退。距离换算使用原 `si_meters`，仅当 `si_meters(mm) > W` 才命中；
   比较的是原求解器使用的 `f32` 米，不改成数学实数、整数毫米比较或 epsilon 近似。

| 状态                                        | 结果                                   |
| ------------------------------------------- | -------------------------------------- |
| `first == len`，切片有效且为空              | 仅满足限速后缀这一项；仍执行其余原前提 |
| 非空，首项精确有限距离严格大于有效 `W`      | 仅满足限速后缀这一项；仍执行其余原前提 |
| `first > len`、转换或目标索引溢出、距离缺失 | 完整求值                               |
| `BeyondFinite`                              | 完整求值，首版不扩展到该分支           |
| 距离为零、位于窗内或与 `W` 相等             | 完整求值，保留降速投影及舍入           |
| 数值不有限、非正参数或上界溢出              | 完整求值                               |

距离查询跨分段时可能遍历中间 segment totals，本提案不宣称其总为 O(1)，也不增加
一个独立索引来隐藏这项成本。完整重建的规范遍历、原 notes/apply 和空 owner 继续执行。

## 4. 两个降速循环的成功性

以下符号只描述现有函数，不授权实现另写一套数值公式。取原 `f32` 换算结果：
当前速度 `v`、有效期望速度 `d`、最大加速度 `a`、舒适减速度 `b`、步长 `dt`。
`speed_drop_window_upper` 按源码顺序计算：

```text
nU = (v + a * dt).max(0).min(d)
W  = dt * (v + nU) + nU * nU / b
```

数值前提继承原准入合同和受检 profile：`MotionReach` 的 speed/accel/delta 域，
毫米速度与间隙、有限 profile 值，以及正舒适/紧急减速度。原 IIDM 的实际后继速度
`n` 非负且不大于 `nU`：其两个阻力项非负，计算得到的加速度不超过 `a`；
同序乘加及最后的非负/期望速度截断保持该上界。非正 leader gap 的早返回给出 `n = 0`。
有效期望速度为零时使用原 `raw_proposal` 的零目标分支，输出 `n = 0`；
不以那个分支中未使用的除零中间值来声称所有中间量都有限。

原成功性义务仍须保证 raw proposal 返回有限值；上界函数成功不能替代该义务。
不允许 FMA、fast-math、代数重排或修改现有 SIMD/标量路径来满足证明。

### 4.1 制动约束循环

`constrain_upcoming_speed_limits` 的实际窗为
`dt * (v + n) + n * n / b`。各参与量非负、`b > 0`，且窗上界已确认有限；
按原操作顺序，浮点单调性给出实际窗不大于 `W`。

筛选已经执行相同首项的目标转换、加法和分段距离查询并取得有限 `D`，
故原循环不会在这些 `?` 处失败。`D > W` 保证首项即触发 `distance > constraint_window`
的 break，不执行 `cap_next_speed_for_limit`，也不读取第二项。返回值仍为 `n`。
这里证明的是原预览根本不会进入投影，不是声称所有近处投影都不会失败。

### 4.2 位移边界循环

制动循环未改变 `n`。原重新积分的未钳制位移是 `(v + n) * 0.5 * dt`，
沿相同非负运算的单调性，它不大于 `dt * (v + nU)`，后者不大于 `W`。
合法前车、停止点、路终与已验证有限包络的钳制只会收紧位移。

`clamp_travel_to_speed_down_boundary` 再次查询的是相同首项距离，仍能成功取得 `D`。
`D > W >= travel` 保证首项触发 `distance >= travel` 的 break；零距 continue 分支
不会进入，之后的下降项亦不会被读取。因此这个循环也不新增预览失败。

后续量化、整数硬房间、同边 `apply_travel_mm` 及结果位置校验继续由原合同证明，
本补充不因两个循环成功就跳过它们。原 `leader_query_horizon` 和
`speed_limit_path_envelope_from` 的可能失败校验仍保留；后者不等同于“没有近处降速”。

## 5. 实现形态与错误、资源边界

未来实现应在 `tick` 侧使用一个私有、只读、无分配的准入证明包装，复用既有数值
上界与分段距离原语。为它伪造整份 `MotionInputs` 或完整预备运动输入没有必要，
也不能为了共享布尔结果改变 P5 对 `BeyondFinite`、缺失行和后备查询的现行语义。

除这一个后缀充分条件外，复原候选须重新绑定当前基线并保留原完整路径作为测试参考。
不得把上一轮未采用的二进制或诊断计时当作新候选基线。任何证明失败都调用原预览，
由它决定原来的错误顺序；不要提前返回成功、错误或伪造静止提交态。

命中仍调用原 `contender_notes` / `apply_contender_notes`，保留三个空贡献和 owner
元数据；不改变增量维护、外层预留、缓存失效、`built_for`、已提交状态及故障重试。
首版不新增常驻字段、向量或跨命令证书。资源验收要同时覆盖空后缀和有限远处两类命中，
仍用保留容量账本与故障后的存量核对，不以进程 working set 代替。

## 6. 实现必须增加的验证

已有 `speed_drop_window_covers_actual_proposals_and_rejects_unprovable_inputs` 和
`distant_speed_drop_preserves_candidate_but_near_drop_keeps_solver_rounding` 只提供原上界
与 P5 路径的依据，不能单凭这两个单测认定准入包装已经通过验证。

| 类别           | 必需覆盖                                                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 数值与舍入     | 原上界与实际 proposal 对拍；零目标速度、零速、最大合法速度/加速度/步长、舒适减速度边界、负/零/最小正间隙及极大 gap；非法域回退         |
| 严格门槛       | `D < W`、`D == W`、最邻近可构造毫米值和 `f32` 舍入邻域；保留既有近处下降改变一 ULP 的回归例，不用整数比较代替浮点比较                  |
| 后缀与分段     | 合法空、单项、多项、`first == len` / `first > len`、目标索引溢出、缺失/逆序列、同段与跨段、`BeyondFinite`、重复物理边的不同 occurrence |
| 原成功性       | 证明命中时完整标量预览必须为 Some，三个贡献必须为空；零进度、余数越界、当前边末端可达、停车/冲突/等待权利继续回退                      |
| 完整缓存与命令 | best/rank、cell owner/ETA、waiting、空/非空 owner、built_for 与参考逐项一致；成功/失败/恢复/改绑/槽复用的连续命令、事件及快照一致      |
| 错误与资源     | 必需预留故障仍返回原错误；不标记失败缓存有效、不半提交；释放故障后重试一致；两类命中的冷/暖分配、保留容量与重复重建存量                |

故障构造应覆盖实际查询会读取的项；被首项正常 break 后不会读取的任意后缀损坏，
不得伪装成合法产品状态，也不要求为了该损坏全扫后缀而改变原路径的失败语义。

## 7. 后续候选的采集边界与停止条件

本设计不直接授权产品采用。独立任务先完成上述证明到 guard 的对应与正确性/资源验证，
再以当前正式完整预览为参考、新候选为实验臂，冻结输入、计划、Rust 工具链、
源码和两份全新普通 release 二进制。

只允许首轮十万道路机动车、16 workers、512 拍暖机 + 1024 拍观察的 ABBA 四次；
需要诊断时最多一次同窗口插桩，分开正式延迟。分别统计空后缀命中、有限远处命中、
近处/未知回退和实际完整预览，不能把 #830 的 5967157 次回退写成新方案已命中数。

报告公共准入、完整宿主命令阶段、全程墙钟和 step 分布，说明计时边界。完整宿主阶段
若只在唯一候选诊断中计时，须明确其没有普通 A/B 对照，不能据此声明阶段收益。五轮上限内
逐字节对拍状态、命令、事件、展开计划并核对十万 step 前 Active、补充请求身份、
拒绝原因及末端 pending；沿用原合同的资源账本和后台竞争记录。

作为新候选的最低继续条件，两组普通配对都必须显示公共准入耗时减少且全程墙钟改善，
没有明确 step 或资源退化。四次短窗不提供长期置信度；相对于同臂波动无法区分的
微小变化应记为未证实，不自动追加 BAAB 或长测。仅筛除比例上升不能支持采用。
任何状态/错误/所有权差异先停止性能声明；无目标准入收益时保留否定结果并停止候选。
父任务 #707 的四基线、三轮完整观察、交通质量和正式资源认证继续独立开放。
