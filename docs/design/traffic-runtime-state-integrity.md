本文是 #955 G1 设计，冻结运行时状态完整性校验与失真处置的权威边界。背景约束来自
#794 归因收口：普通机器（无系统级 ECC）在内存压力下存在**页级内存失真**（首个分歧
偏移落在 4 KiB 页边界、整页替换、页整数倍位移、伴随零页；见
`../reference/validation-matrix.md` 环境失真指纹），失真不绑定特定测试或固定
entry，`fs::read` 与映射读回均可观察。确定性（ADR 0003/0030）是重演的必要条件，
但不自动提供正确性判据：确定性只保证「相同输入得到相同输出」，不保证「内存里的
状态仍是曾经提交过的那个状态」。本设计补的是后一个判据及其处置边界。

现行合同不因本设计改变权威归属：失同步只诊断、处置归宿主
（[`traffic-runtime-snapshot.md`](traffic-runtime-snapshot.md) §6）；输入命令序列与
检查点由宿主记录（ADR 0021）；确定性状态摘要前像为 #302 冻结的 SHA-256
（digest 7 / runtime state 5）；共享静态根不在 C(T) 内（ADR 0030）。本设计只在其上
增加检测面、失败关闭语义与遥测，不新增隐藏输入权威，不改变交通状态、摘要前像与
容器版本轴。

## 1. 问题、设计立场与范围

**问题**：页级内存失真把静默损坏写进运行时状态。确定性回放能定位分歧区间（宿主对拍
检查点三元组 `(command_cursor, tick, deterministic_state_digest)`），但它把「失真」
与「确定性缺陷」混在同一信号里，且只有在状态已经错了之后才显形。需要在运行时内部
提供正确性判据：检出失真、给出可信判因、并把处置权放在唯一权威处。

**设计立场**：

- **检测与处置分权**：Runtime 负责检测并失败关闭；恢复处置归宿主（§3）。
- **两类前像分立**：逻辑摘要前像管「状态内容是否仍是已提交的那个逻辑状态」；物理
  完整性前像管「物理字节是否发生失真」。两者对象、前像、算法与期望值来源各自独立，
  不互相替代（§2、§4）。
- **无可信基准不作宣称**：期望值无法建立或独立核验时，不得宣称检测或恢复成功；
  判因允许「无法判因」（§2、§7）。
- **不进入提交关键路径**：完整性校验不得进入 committed-state barrier，不得因执行
  块切分额外延迟一拍（§4.5）。
- **1.0 前只留一套权威**：恢复权威落点冻结为一条政策的两个阶段，不并行第二套
  （§3、ADR 0032）。

**范围外**（显式不做）：

- 每 tick 全量校验；
- 恶意篡改防御（本设计只处理非恶意的环境失真与随机损坏，不构成安全边界）；
- 分布式重放；
- 实现与实测（性能实测、retained-memory 账本合入、恢复率测量归实现 Issue）；
- 权威落点冻结前的任何自动纠偏（自动回滚、自动重演、自动重写状态一律不属本设计）；
- 代码页、栈、宿主自有内存、GPU/设备内存的完整性（漏检面显式声明，§5）。

## 2. 可信期望值与前像（必答第 0 项定案）

### 2.1 前像总表

**五类前像全部在 G1 冻结**；每类的规范字节、域分隔、绑定与算法身份如下，实现不得
自行取舍字段或对 Rust 布局取哈希：

| 前像           | 定义                                                                                                                                   | 管什么                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 逻辑摘要前像   | #302 确定性状态摘要的规范化前像（域分隔 `laneflow:runtime-state-digest:v1\0`、digest 7、runtime state 5、规范记录序列），布局无关、只覆盖 C(T) | 逻辑状态内容正确性：当前状态是否仍是曾经提交过的那个逻辑状态（多重度、绑定、live 序保留）。算法 = SHA-256（#302 冻结，**不替换**） |
| 逻辑记录与结构前像 | #302 规范前像中**记录与结构成分的同一规范字节**（记录规范序列化 + 计数 / 绑定多重度 / live 序结构的规范表示），逐记录 / 逐结构面可独立重算 | 记录与结构级保留期望值的主族与异族复核副本各自按本前像计算（§4.2/§4.3）                    |
| 输出批次前像 | 待决输出批次（events / observations / StepOutcome 载荷）**公开逻辑字段的规范序列化**（非 Rust 布局、不得含 padding；仅已初始化字节）：域分隔 `laneflow:output-batch:v1\0` + `(tick, 批次种类)` + 规范字段序列 | 待决输出载荷正确性：生成后、放行前是否被失真改写。**独立机制**，期望值双副本与哈希族按 §2.3 / §4.3 |
| 耐久根内容前像 | 共享根**权威语义内容**的规范序列化（公开语义字段规范序；不含布局 / 地址 / capacity / 派生表）：域分隔 `laneflow:shared-root-content:v1\0` + `NetworkRevisionId` + 版本轴 | 跨进程 / 重启可用的共享根内容基线（§2.2）。算法 = SHA-256（独立域分隔，声明级）；派生表不入前像，由权威内容确定性重建，其物理正确性由物理布局基线承接 |
| 物理完整性前像 | 对物理内存区域（热表、工作区、共享静态根 backing）按实际字节布局逐区域计算的完整性前像：域分隔字节 + 区域种类 + 页序 + 长度 + 内容字节（**仅已初始化字节**） | 物理字节正确性：内存区域是否被页替换、零页、页整数倍位移等失真改写，与逻辑值无关、布局绑定。**独立机制**，哈希选型见 §4.3 |

两层前像的边界：逻辑摘要前像不因布局、地址、capacity 变化而变；物理完整性前像
逐页绑定物理布局，句柄表重排、容量调整都会改变物理前像，这正是它要检测的面。物理层
检出「页被打中」，逻辑层检出「失真已经进入逻辑状态的后果」；两层都失败时以 §7 判因
轴归类，允许「无法判因」。物理前像按**区域种类**（热表 / 工作区 / 共享静态根 /
登记表）分域分隔；共享静态根不在 C(T) 内（ADR 0030），只有物理层覆盖它，逻辑层不为
共享根另设第二份摘要。

**初始化字节约束（Rust soundness）**：物理前像只覆盖**已初始化字节**。保护页进入
scrub 集合前必须整页已初始化，或按受保护的页内初始化掩码登记（形态见 §11）；
`Vec` spare capacity、结构 padding 等未初始化字节所在部分不入前像（读取它们在 Rust
中非法，且会让期望值依赖无关的分配器内容）。未初始化字节不在前像内，显式记入 §5
漏检面。

### 2.2 期望值合同：来源、时点与绑定

期望值由**写者**（写入该状态的路径）在**写冻结点**建立，登记进完整性期望值登记表
（下称登记表）。**登记时点即期望值冻结点**：此后该页 / 该状态视为不可变，直到下一次
合法写入触发重新登记；「登记后失真」是唯一可注入语义（与 #954 读回合同一致）。

| 对象                     | 登记时点（可信时点）                                                                                                                                       | 绑定                                  |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| 逻辑状态（记录与结构级） | 每个**已提交变更边界**随状态**原子发布**：期望值在提交前预计算（含预留，见 §2.4），与 C(T+Δ) 在同一原子切换中发布；覆盖记录内容与结构面（计数 / 绑定多重度 / live 序） | `(tick, command_cursor)` 每次提交推进 |
| 逻辑状态（全量共因核对） | 抽样拍（间隔 `N_L`）的校验窗内由登记路径与校验路径各自计算并比对；**不跨提交持有、非检测判据**（§4.2）                                                     | 抽样拍 `(tick, command_cursor)` + 摘要版本轴 |
| 热表 / 工作区            | 该页最后一次写入完成后的写冻结点；页期望值按**写集增量更新**（§4.3 构造硬要求）                                                                             | `(tick, 页序, 区域种类)`              |
| 共享静态根               | 基线分两层：**耐久内容基线**（布局无关的分段内容摘要 + `NetworkRevisionId` 绑定，构建完成点由构建方建立，宿主持久旁车携带、跨进程 / 重启持久、受第一层（#954）读回保护）与**物理布局基线**（页序绑定，**不持久**）。安装 / 认证以耐久内容基线核对当前 backing（发布 → 安装间失真可检），核对通过后才建立新的物理布局基线；重启 / 重载不得沿用旧物理基线（布局可变），也不得在未核对内容基线前自行再生基线（自发基准无效） | 内容基线 `(NetworkRevisionId, 分段)`；物理基线 `(区域种类, 页序)` |
| 输出批次                 | 输出批次（events / observations / StepOutcome 载荷）生成完成点（进入待决结果之前）；校验窗放行前独立重算比对（§4.5）                                          | `(tick, 批次种类)`                    |
| 恢复后状态               | fresh restore / 同修订恢复成功、world 发布前的 staging 完成点；登记表建立失败 = 恢复失败关闭、零部分恢复（snapshot §5）                                       | 恢复后的 `(tick, command_cursor)`     |
| 校验器控制状态           | 校验窗调度点（冗余导出更新，§2.3）                                                                                                                          | 单调序号双写                          |

登记表是进程内诊断状态，**不进入快照、摘要前像与容器版本轴**（digest 7 /
runtime state 5 不变）。

**独立核验**：校验路径与写入路径分离——校验在拍后校验窗内从被校验对象**重新计算**
前像并与登记表比对；重算使用校验自有缓冲，不复用写者缓存缓冲，使「缓存与内存
不一致」类失真可分歧（与 #954 两路读回同一口径）。校验读取必须真实触达被校验字节
（不缓存折叠），使零页与整页替换可被观察。

### 2.3 保护不变量

登记表自身也受失真威胁。以下为不变量（实现形态见 §11）：

1. **页隔离**：登记表页与被校验页**不得同页**；安装 / 恢复时断言登记表页号集合与
   被校验页号集合不相交，断言失败 = `Untrusted`。**每次登记表分配 / 迁移（含容量
   边界增长）后重建页映射并复核不相交**，复核通过才随登记表写入同一原子发布新
   版本——不存在无隔离断言的登记表版本，scrub 不得继续使用已释放地址或迁移前页
   映射。登记表不与任何被校验对象共享 backing 页、缓存缓冲或中间数组。
2. **双副本异族**：每个登记项保存主副本与复核副本；两者不同布局、不同分配域、
   **哈希族不同**（族规则见 §4.3）。复核副本不只是登记表冗余——它是独立复核的
   **比对基准**：没有第二族保留值就没有可比对基准，`Untrusted` 判因不成立。
3. **三层互证**：登记表内容、复核副本、登记表滚动摘要三方一致；任意两层分歧 =
   `Untrusted`。滚动摘要与登记表写入**同一原子推进**——不得留到校验窗才刷新（滞后
   会把合法登记误判为三层分歧），也不得先刷新再比对（会把期间损坏洗白）；校验窗只做
   三方**只读**互证。
4. **校验器控制状态保护**：轮转游标与调度位置单调双写并由滚动摘要冗余导出；失败
   关闭粘滞位正 / 反相双副本，**置位不得晚于失败可见性**。控制状态页纳入保护页
   集合；控制状态失配 = `Untrusted`。
5. **checked reserve**：登记表的建立、增长与重算缓冲全部按计数可失败预留（#532
   原语）；预留失败语义见 §2.4，不进 fixed-step 热状态。

### 2.4 可信基准、失败分类与「无法判因」

**预留失败 ≠ 不可信**：登记缓冲 / 记录表 / 期望值缓冲的**提交前容量预留失败**是
**尝试局部可恢复错误**——tick 或命令未提交、世界无损、不置 `Untrusted`、调用方可
重试（#532 口径）。恢复 staging 期的登记表建立预留失败同理：恢复失败关闭、零部分
恢复（snapshot §5），宿主可重试恢复。

**`Untrusted`（校验过程不可信）只来自**：

- 页隔离断言失败；
- 双副本初始化分歧、登记表三层互证分歧；
- 期望值绑定不闭合（tick / 游标单调性破坏、跨修订绑定错位）；
- 校验器控制状态失配（§2.3 第 4 条）；
- 检查点锚与宿主持久副本分歧（下表）。

不可信时**不得宣称检测或恢复成功**：世界失败关闭，遥测输出「校验过程不可信 /
无法判因」，不输出「通过」结论，不进入恢复语义。

**检查点、输入命令日志、摘要自身被打中**：

| 被打中对象           | 保护与处置                                                                                                                                                                                                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 检查点锚             | 检查点三元组 `(command_cursor, tick, deterministic_state_digest)` 由宿主持久（宿主存档清单，对象外绑定，ADR 0021）；Runtime 在校验窗登记同值锚并与之核对。分歧 = 不可信基准，无法判因，交宿主；宿主持久层自身的写后回读由第一层（#954）覆盖 |
| 输入命令日志         | 宿主拥有（ADR 0021），持久完整性不在本设计覆盖内。命令期望值为**宿主自报**：宿主按耐久身份前像计算命令摘要并随命令传入，Runtime 登记 `(command_cursor, 宿主摘要)`，**不独立重算宿主前像**（Runtime 不保存或解释宿主 ID，snapshot §6）；跨权威比对归宿主检查点对拍。Runtime 侧只检登记条目自身失真（三层互证）；两侧前像口径差异不判因、不判 `Untrusted`，有效重放不得因句柄映射差异被误判 |
| 确定性状态摘要自身   | 摘要值经双副本 + 三层互证保护；登记值与重算值一致但都经同一失真内存时的残余风险显式声明（§4.4），此时允许「无法判因」，不得把「重算得同一错误值」当作通过                                                                                                                                 |
| 登记表本体           | 双副本 + 滚动摘要三层互证；任意两层分歧 = 失败关闭、无法判因                                                                                                                                                                                                          |

## 3. 恢复权威落点（必答第 1 项定案）

**定案：一条权威政策的两个阶段，不并行第二套。**

- **阶段一（检测，失败关闭）**：校验发现失配或校验过程不可信，立即失败关闭——世界
  停止推进，不自动纠偏、不自动回滚、不自动重演、不重启世界。
- **阶段二（处置，归宿主）**：检测后交宿主处置。宿主按现行设施恢复：从检查点
  （Runtime Snapshot + 命令游标）恢复并依序重放输入命令序列，用检查点三元组对拍
  定位首个分歧区间（[`traffic-runtime-snapshot.md`](traffic-runtime-snapshot.md) §6）。
  Runtime 只交付检测结论、判因与失真指纹，不执行处置。

这是现行合同（失同步只诊断、处置归宿主）在完整性维度的延伸：失同步的状态仍是合法
确定性状态，因此只诊断不停机；完整性失配的状态可信度已被破坏，因此先失败关闭再交
宿主。两者处置权相同（宿主），区别只在是否停机，权威不双轨。

**已发布结果的处置**：失败关闭不撤销已发布事件 / 观测 / 宿主副作用（不自动纠偏）。
从检测时刻起 Runtime 不再产生新提交；宿主在自己的边界决定丢弃、重放或对拍。Runtime
不隐藏、不重发、不去重事件——事件去重与副作用回退属于宿主回放链，不是 Runtime 职责。

**共享静态根被打中的独立失败语义**：共享静态根（`SharedNetworkRevision`）不在 C(T)
内（ADR 0030），**不属回滚 / 重演可修复面**。**触发条件 = 聚合侧的任何 `Mismatch`
或 `Untrusted`**——根字节失配、根校验器期望值 / 游标 / 控制状态不可信（共享基准
不可信等价于根失配），不只根字节失配。触发时：

- 世界失败关闭（与其它失配同一阶段一语义）；
- **根级失效（poison）同步传播**：失效标记**不写入共享根本体**——共享根保持不可变、
  无原子、无内部可变（[`shared-static-network.md`](shared-static-network.md) §8/§11），
  失效状态由**共享根完整性租约**承载，且租约必须**绑进共享根 API**：完整性开启时
  跨边界的唯一句柄是**共享根绑定聚合**（根 `Arc` + 共享根完整性租约 + 构建方旁车
  基线），一切安装、绑定、恢复与切换输入都携带聚合并随事务**原子更替**（含租约与
  旁车基线；[`shared-static-network.md`](shared-static-network.md) §4/§8、
  [`traffic-runtime-shared-consumption.md`](traffic-runtime-shared-consumption.md)、
  [`traffic-runtime-revision-cutover.md`](traffic-runtime-revision-cutover.md) 与
  [`adapter-api.md`](adapter-api.md) 已同步回写，签名调整归实现切片），**不得存在只传
  根、拿不到租约的第二条绑定路径**；
- **租约守卫覆盖完整操作（lease guard）**：租约携带单调失效世代；消费者在入口取得
  **租约守卫**（世代快照 + 共享读），**持有守卫跨越整个操作直到提交 / 发布完成**才
  释放——杜绝 check-then-publish 竞态：poison 置位与守卫互斥（置位阻断新守卫，使
  在途发布中止或等待释放），worker 整 tick 持根借用同样在守卫内完成。全部公共
  共享根访问器返回守卫或携约 facade，完整性开启时裸 component 借用不外露。修订
  绑定的只读 facade / snapshot（含 `RuntimeRevisionSnapshot` 等价物）必须保留并核对
  同一租约与世代，只留根 `Arc` 的 facade 不得作为消费路径；
- **共享根验证点在聚合侧**：共享根的轮转校验由**根校验器**承担——挂共享根绑定
  聚合（每根一份，非每世界），期望值与轮转游标随旁车基线 / 租约携带，**随消费摊销
  推进**（任一活跃消费——步进、位姿提取——摊销推进根轮转）；无消费者期间不推进也
  无暴露面。检测界的量纲**以消费操作次数计**（`M_phys_root` 次消费，§5）；秒界只对
  按标称 cadence 消费的世界成立。稀疏消费者（如纯 Spatial 按宿主调度提取）必须
  二选一（G2 落定）：**入口全量校验**（每次消费前全量核对内容基线）或**墙钟周期
  推进**（根轮转按墙钟周期推进）——两者都使秒级上限重新成立，穷尽覆盖稀疏情形。
  纯 Spatial 绑定经聚合自带根校验器，不存在无校验器的根消费者；
- **完整性模式属于共享根绑定聚合**：每根一份、绑定时冻结、不可变；显式提供、不猜
  默认（与 `ExecutionConfig` 同口径）；全部消费者共享同一模式，**混合模式消费者
  拒绝**（同一聚合下模式不一致 = 绑定失败）；模式字段入 G2 API 清单（§11）；
- 处置只能是根重建：重编译 / 重安装 / 重新认证共享根后，所有消费者重新恢复 / 重绑；
  宿主不得期望通过检查点回滚或命令重演「修好」共享根；
- 遥测把共享根单列判因类别；根级失效是共享事件，单列遥测。

**备选取舍记录**（四个落点冻结其一；(c)(d) 不采用）：

## 4. 校验机制合同（必答第 2 项定案）

### 4.1 校验对象与验证点职责分列

| 类别   | 对象                                       | 前像             | 验证点持有方与说明                                                                                                       |
| ------ | ------------------------------------------ | ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 逻辑   | C(T) 不可变已提交视图                      | 逻辑摘要前像     | 每世界登记表；提交完成后到下一拍开始前不可变，校验窗内只读                                                               |
| 逻辑   | 已发布输出批次（events / observations / StepOutcome 载荷） | 输出批次期望值（第三类） | 每世界登记表；生成时登记、**放行前**独立重算比对（§4.5 待决结果），失配则该批次不放行并失败关闭                          |
| 物理   | 热表、工作区                               | 物理完整性前像   | 每世界登记表；写集增量登记 + 轮转 scrub                                                                                  |
| 物理   | 共享静态根（不在 C(T)）                    | 物理完整性前像   | **根校验器（聚合侧，每根一份）**：构建方旁车基线 + 租约，随消费摊销推进轮转（§3）；换根 / 恢复 / 审计时全量重验          |
| 保护面 | 完整性期望值登记表                         | 自身三层互证     | §2.3；不是被校验对象的期望值来源，是保护面本身                                                                           |
| 保护面 | 校验器控制状态（轮转游标、调度位置、失败关闭粘滞位） | 双副本 + 冗余导出 | §2.3 第 4 条；控制状态失配 = `Untrusted`                                                                                  |

工作区与输出的取舍（不变量）：不为工作区做消费前逐页校验（那会进入 tick 热路径与
提交关键路径）；失真后果按发生时刻分三种——消费前失真并进入提交值 / 生成输出 =
**不可检**（§5 漏检面，登记即错口径）；消费后残留 = 下一轮物理 scrub 可检；输出批次
登记后、放行前 = 输出批次期望值可检。消费前对提交载荷工作区的有界校验为实现切片
可选强化（§11），落地前第一类按不可检声明。

### 4.2 逻辑层判据：记录与结构保留期望值

- **记录与结构保留期望值轮转（逻辑检测判据）**：期望值在每个已提交变更边界增量
  登记、**跨时间保留**，覆盖 #302 前像的全部成分——记录内容之外，还有**结构面**
  （集合计数、路线分组绑定多重度、live 序序结构）。只登记记录内容会漏掉「丢条目 /
  重复条目 / 换序 / 车辆改挂路线分组」这类每条记录摘要纹丝不动的结构失真。校验窗按
  记录与结构轮转独立重算子集并逐项比对；期望值保留自提交点，因此能检出**窗口之前
  已持久化**的 C(T) 失真。记录期望值同样按 §2.3 双副本异族保留：主族与复核副本各按
  **同一记录规范字节**计算（复核副本用异族构造，§4.3）。逻辑层检测滞后 = 轮转
  周期 `M_rec`（§5），这是覆盖 C(T) 全部前像成分的逻辑检测界。
- **全量共因核对（间隔 `N_L`，非检测判据）**：抽样拍校验窗内登记路径与校验路径从
  同一不可变 C(T) 视图各自按 #302 规范前像计算 SHA-256 摘要并比对；同窗建立、同窗
  比对、不跨提交持有。它只检路径缺陷 / 窗口内失真 / 账目分歧（转 `Untrusted`），
  **检不出窗口前已持久化的 C(T) 失真**（两路径读到同一坏视图产出同一摘要），因此
  不作正确性判据、不承担检测界。
- 分段 / 抽样子校验是独立机制，只作检测线索，不冒充 #302 摘要、不作判据。可选强化
  （§11）：跨提交增量维护的全态累积摘要作为保留期望值，落地后可提供全态 `N_L`
  检测界并回写本节。

### 4.3 选型原则与族配对

- **逻辑层**：SHA-256（#302 冻结，不替换、不新增第二**逻辑摘要**算法）。该禁令只
  保护 #302 确定性状态摘要的身份；完整性登记的双族构造（记录 / 结构期望值的主族与
  异族复核副本）是独立机制、不受此限，复核副本按同一记录规范字节以异族哈希计算
  （§4.2）。
- **物理层构造硬要求**：**写集增量维护**——页期望值按写字节增量更新（成本
  O(写字节)），**禁止每脏页整页重哈希**（会把 §8 摊销预算打穿）；delta 形态二选一：
  真可移除构造（移除旧字节 / 加入新字节），或子块 Merkle（只重算改动子块 + 合并
  路径，过量哈希以子块粒度为界）。物理层为独立机制（域分隔
  `laneflow:physical-integrity:v1\0`），不替换 #302、不进入摘要版本轴。
- **正式候选与选择倾向**：三方案候选矩阵（① 性能优先、② 界最优、③ 保守基线）及其
  回退顺序冻结于 [§11](#11-g2-落定清单实现内容收口不属-g1-冻结)，**① 性能优先为默认倾向方案**；
  G2 以 **delta 更新成本**（非整体吞吐）为主测项实测落定，证伪则按 ② → ③ 回退并
  回写。
- **族配对规则**：主 / 复核必须来自**不同构造谱系**——线性（CRC / 键控 XOR / 加法）、
  乘法混合（XXH3）、密码学树（SHA-256 / BLAKE3）三系，**不得同为线性系**，禁止同族
  配对（§2.3 双副本的异族要求即本规则）。G2 选型成对落定并回写 §2 / §4.3 / §4.4。
- **独立复核（共因隔离）**：轮转 scrub 之外，周期性以第二族整页重算并与**第二族
  期望值**（复核副本）比对。判读规则：两族**分歧** = `Untrusted`（主构造被打中 /
  增量账目分歧 / 构造缺陷）；两族**一致失配** = `Mismatch`（失败关闭），但**归因
  页失真须有独立佐证**（失真指纹符合环境失真指纹、或独立读回证据）——两族共享
  同一写集更新源时，写集遗漏会同时打中两族期望值，无佐证时判因二义（§7 允许
  「无法判因」）。可选强化（§11）：第二族按受保护登记日记**独立更新**，落地后
  分歧可精判账目路径、一致失配可直判页失真。复核周期 `M_rev` 为合同值，进入检测
  滞后界（§5）。两族期望值均写集增量维护（增量成本 ×2），计入 §8 预算。

### 4.4 碰撞声明模型与残余风险

- **失败关闭口径**：失配或校验过程不可信即失败关闭；不设容差、不取「多数副本正确」。
- **声明模型（概率声明的前提）**：数值声明依赖以下模型之一，未声明模型的数字只是
  启发式，不是保证——
  - **通用哈希模型**：键独立随机生成并受保护（如键控 XOR 构造）。对任意固定结构化
    失真（整页替换 / 零页 / 页移位），未检出概率 ≤ 2⁻¹²⁸（128 位键）是**可证明**
    的界；
  - **随机失真内容模型**：对固定非密码算法（如 XXH3），2⁻¹²⁸ 为**启发式假设**——
    固定结构化失真对固定算法可能确定性碰撞，显式标注不作保证级声明；
  - **随机预言机 / 第二原像模型**：SHA-256 类的 2⁻²⁵⁶ / 2⁻¹²⁸ 依赖随机预言机（或
    第二原像难度）假设——固定结构化失真下「失真值 ≠ 期望值」属第二原像事件；标准
    抗碰撞是计算假设，**单独不给出该数值界**。不采纳该模型时改定性声明。
- **未检出碰撞残余风险（按所选构造声明，G2 落定后回写为唯一值）**：
  - 逻辑层单点比较（SHA-256，256 位）：≤ 2⁻²⁵⁶ / 事件（**随机预言机 / 第二原像
    模型**，见声明模型）；
  - 物理层：键控 128 位构造 ≤ 2⁻¹²⁸ / 页·事件（通用哈希模型，声明级）；固定
    128 位算法 ≤ 2⁻¹²⁸ / 页·事件（启发式）；CRC 类 ≤ 2⁻³² / 页·事件（随机模型）。
    落定前按弱构造（2⁻³²）保守声明，倾向方案落定后降档；
  - 线性构造弱点声明：键控 XOR / CRC 对恶意构造碰撞不设防（威胁模型已排除恶意
    篡改，§1 范围外）；对随机环境失真的未检出概率仍按上式；
  - **累积风险**：N 次失真事件的累计未检出概率 ≤ N × p，按声明事件数累计，不做
    独立性承诺；
  - 登记表共因失真（主 / 复核副本同击中且保持互相一致）：≤ 主构造弱族上界，是本
    设计声明的**最大残余风险**；独立复核把构造失效 / 共因 / 增量账目分歧收窄为
    `Untrusted`，残余碰撞面仍按本值声明；
  - 三层互证同击中的联合残余风险不作数值承诺，命中即「无法判因」。
- 未检出碰撞不构成恢复成功依据：任何「通过」结论都只覆盖声明的对象与窗口。

### 4.5 发布时序与操作边界

- **期望值随状态原子发布**：前像计算与登记缓冲准备在提交前完成（含 checked
  reserve，属既有「提交前完成一切可能失败的预留」合同，
  [`traffic-runtime-phase-protocol.md`](traffic-runtime-phase-protocol.md) §5.2），
  P7 只做与状态同一原子的指针切换（无新计算、无新错误）；发布后不存在无期望值的
  已提交状态。登记预留失败在**提交前**失败关闭尝试、无副作用、可重试（§2.4）。
- **校验窗的位置（同步合同）**：完整性校验窗是**每次 `step` 尝试（无论成功失败）
  之后**的必经同步操作：

  ```text
  apply_pending → step（返回不透明待决结果）→ 完整性校验窗（放行 / 截留）→ consume
  ```

  `step` 的 P0–P8 语义不变（P8 仍只移交已准备载荷、无新计算、无新错误）：P8 移交的
  是**不透明待决结果**（API 形态 `PendingStepOutcome`，见
  [`traffic-runtime-shared-consumption.md`](traffic-runtime-shared-consumption.md)）——
  事件批 / 观测批 / StepOutcome 载荷在放行前**不可消费**
  （不可读取内容、不可施用）。校验窗核验通过后**放行**为可消费；失配则不放行并
  失败关闭，待决结果作废。校验窗返回 `Pass` / `Mismatch` / `Untrusted`；失败关闭
  是世界状态，此后 `step` 返回「世界已失败关闭」终止性错误（属其调用自身的调用
  归属）。已放行结果照旧不撤销。检测滞后含窗调度余量 `W_sched` ≤ 1 tick。**失败
  尝试同样必经校验窗**：`step` 返回普通 `StepError`（如坏引用 / checked 算术输入）
  时不产生待决结果，但校验窗照常运行并推进校验调度；**完整性结论优先于
  `StepError`**——检出即以 `Mismatch` / `Untrusted` 覆盖可恢复失败，不得把不可信
  世界误分类为可恢复步进失败（否则检测界被错误路径绕破）。
- **快照保存的完整性门控（作用于真实保存路径）**：门控位于 `capture_snapshot` →
  `encode_lfrs(&CapturedSnapshot)` 通路——`capture_snapshot` 返回的 `CapturedSnapshot`
  是**待决快照**：放行前不可 `encode_lfrs` / 不可持久（或 capture 以前置校验放行为
  条件）；`encode_lfrs` 只接受已放行快照。检出前的坏状态若被固化为检查点，会在日后
  恢复时成为「新可信基准」，粘滞失败收不回已持久制品；[`traffic-runtime-snapshot.md`](traffic-runtime-snapshot.md)
  §5 已回写。
- **不得进入 committed-state barrier**：比对（校验）的读、算不进 P0–P8 任何阶段，
  不改变首错、事件、提交语义，不增加可恢复错误；校验窗内的失败只产生遥测与失败
  关闭信号，不回灌当拍结果。
- **跨块不额外延迟一拍（写入冻结约束）**：期望值发布随状态原子（上文），校验窗
  自有状态（scrub 游标等）写入只发生在校验窗；执行块与 worker 切分不改变校验调度、
  期望值发布时机与检测滞后，不得因分块新增一拍延迟或第二份期望值权威。校验任务只读
  C(T) 与登记表；worker 数不进入登记表、不进入任何前像（ADR 0030）。

## 5. 间隔、抽样 / 增量与漏检面（必答第 3 项定案）

**检测滞后公式**（`W_sched` = 校验窗调度余量，合同值 ≤ 1 个校验窗）：

```text
逻辑记录轮转滞后       = M_rec × fixed_delta_time_ms + W_sched        （逻辑检测判据）
物理页 scrub 滞后      = M_phys × fixed_delta_time_ms + W_sched        （快变集合：热表、工作区）
共享静态根 scrub 滞后  = M_phys_root × fixed_delta_time_ms + W_sched    （不可变集合，以消费操作次数计）
独立复核滞后           = M_rev × fixed_delta_time_ms + W_sched          （构造失效 / 共因）
总检测滞后上限         = max(以上各项)，按类别列明
（全量共因核对周期 N_L 非检测判据，不进上式，不承担检测界）
```

**机制与间隔**（拍数为待验证预算，实测归实现 Issue；§8 表格为分规模数值的唯一
权威）：

| 机制                           | 覆盖                             | 间隔 / 周期（待验证预算）                                | 漏检面                                                                                                       |
| ------------------------------ | -------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 逻辑记录与结构轮转（检测判据） | 逐记录 + 结构面                  | 轮转周期 `M_rec ≤ 128 拍`（一百万 ≤ 512 拍）              | 记录被合法写入覆盖（自愈）后不可检；登记即错不可检（见下）；被打中的期望值本身由 §2.3 三层互证承接            |
| 逻辑全量共因核对（**非检测判据**） | 全部 C(T)                    | 周期 `N_L`：一万 64 拍；十万 256 拍；一百万 1024 拍       | 同窗双路径检不出窗口前已持久化的 C(T) 失真（两路径读到同一坏视图产出同一摘要）；只检路径缺陷 / 窗口内失真 / 账目分歧 |
| 物理页轮转 scrub（快变集合）   | 热表、工作区全部页               | 全覆盖周期 `M_phys ≤ 256 拍`（一百万 ≤ 1024 拍）          | 失真发生在某页 scrub 之后且在其下次 scrub 之前被合法写入覆盖（自愈）；被消费后清空的工作区残留不可检          |
| 物理页轮转 scrub（不可变集合） | 共享静态根全部页                 | 全覆盖周期 `M_phys_root ≤ 1024 拍`（以消费操作次数计）      | 无合法写入覆盖，故不新增自愈类漏检；代价只是该类检测滞后更大                                                  |
| 独立复核（第二族）             | 物理主构造、登记表               | 复核周期 `M_rev ≤ 1024 拍`（进入检测滞后界）              | 构造失效 / 共因 / 增量账目分歧的检出滞后；不承担页失真检测                                                    |

**间隔拍数的权威口径**：§8 为分规模数值唯一权威。cadence 未冻结的规模（一百万）及
任何长步长配置（ADR 0028 允许 `fixed_delta_time_ms` 到 1000 ms），拍数按下式导出
收敛：

```text
N = min(标称拍数, floor((该类检测延迟上限 − W_sched) / fixed_delta_time_ms))
```

**检测延迟上限（秒）是合同，拍数是导出值**；实现不得在长步长配置下沿用标称拍数
突破秒上限。秒界**只对按标称 cadence 消费的世界成立**；稀疏消费者（纯 Spatial 等）
的界以**消费操作次数**计（`M_phys_root` 次消费），或按 §3 稀疏策略（入口全量校验 /
墙钟周期推进，G2 二选一）恢复秒级上限——三种口径穷尽覆盖，不得存在无检测界的消费
形态。

**显式漏检面（总表）**：

1. 自愈性覆盖：失真落在两次检查之间且被合法写入改回 / 覆盖——两层都不可检；
2. tick 内工作区失真：①消费前失真并进入提交值 / 生成输出——期望值随后从已错内容
   建立（登记即错），**不可检**；②消费后残留——下一轮物理 scrub 可检；③输出批次
   登记后、放行前——输出批次期望值可检。消费前校验是可选强化，落地前第 ① 类按
   不可检声明；
3. 未覆盖面：代码页、栈、宿主自有内存、GPU / 设备内存、宿主持久层（检查点制品与
   命令日志的持久完整性由 #954 第一层与宿主合同覆盖）；
4. 三层同击中（登记表主 / 复核 / 滚动摘要一致地坏）：不可检，「无法判因」；
5. **登记即错**（写者写入时读到的字节已坏）：期望值忠实记录坏值，之后 scrub 复现
   同一坏值，**不可检**（部分写重登记还会把写集外坏值洗白）；只由宿主检查点回放
   对拍兜底。可选收窄：精确写集 + 写集外差分比对（§11），落地前按不可检声明；
6. 输出批次「重算之后、放行之前」的极小窗口失真；
7. 校验器控制状态被击中且双副本 + 冗余导出一致地坏（与第 4 条同口径，「无法判因」）；
8. 未初始化字节（`Vec` spare capacity、结构 padding）不在物理前像内（§2.1）。

最大检测延迟按类别与规模写明（待验证预算）：逻辑检测判据（`M_rec`）一万 ≈ 2.1 s、
十万 ≈ 4.2 s；快变集合（`M_phys`）一万 ≈ 4.1 s、十万 ≈ 8.4 s；共享根（`M_phys_root`，
消费操作计）与独立复核（`M_rev`）≤ 1024 拍，一万 ≈ 16.4 s、十万 ≈ 33.8 s；
全量共因核对不计检测延迟；一百万全部检测类别合同值**上限 60 s**（无实时 SLA）。
秒上限合同对任何合法 `fixed_delta_time_ms` 成立（导出规则收敛）。

## 6. retained-memory 裁决与分类方案（必答第 4 项定案）

**裁决**：服从第 1 项落点——验证点持有方分两层：**世界内对象**（热表 / 工作区 /
输出 / 登记表）由各世界完整性校验组件持有（随世界生命周期）；**共享根**由**根
校验器**持有（挂共享根绑定聚合，每根一份，随消费摊销推进，§3/§4.1）。两层都只有
检测面，**不另给恢复语义**——登记表、校验器与校验 scratch 都不是恢复设施，不承载
回滚 / 重演 / 纠偏能力。

**#380 账本穷尽分类**（按所有权穷尽枚举，新增字段触发编译失败强制分类；实现不得
以「诊断内存」笼统归类）：

| 所有权类目                                        | 性质     | 规模说明                                                                                              |
| ------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------- |
| 期望值登记表主副本                                | 稳态保留 | O(保护区总页数 + 逻辑记录数 + 结构面)                                                                 |
| 期望值登记表复核副本（第二族增量期望值）          | 稳态保留 | 同上（不同布局 / 族 / 分配域）                                                                        |
| 登记表滚动摘要与页映射表                          | 稳态保留 | O(保护区总页数)                                                                                       |
| 校验器控制状态（双副本 + 反相 + 冗余导出）        | 稳态保留 | O(1)                                                                                                  |
| 共享根旁车基线                                    | 稳态保留 | O(共享根段数)；构建方 / 宿主持有，**N 世界共享一份**（2/8/32 worlds 不随世界数线性放大）               |
| 共享根完整性租约与根校验器游标                    | 稳态保留 | 每根 O(1)（失效标记双副本 + 失效世代 + 轮转游标）；经绑定聚合为全部消费者共享一份                     |
| 页初始化掩码 / 前缀边界                           | 稳态保留 | 整页初始化方案 = 0；掩码方案另行入账（形态与账面见 §11）                                              |
| 校验重算缓冲（逻辑全量 + 记录与结构级）           | 校验峰值 | 与全量摘要缓冲同量级，校验窗内短持有                                                                  |
| 页 scrub 读缓冲                                   | 校验峰值 | 固定 K 页缓冲，校验窗内短持有                                                                         |
| 诊断 / 遥测缓冲（失真指纹输出）                   | 校验峰值 | 有界，仅在失配时持有                                                                                  |

**口径**：保护区 = 热表 + 工作区 + 共享静态根全体页集合（§2.2 登记对象一个不漏）；
登记表为每个保护区页持有主 / 复核条目与页映射，即使内容不可变。每页账面字节与掩码
代价为 G2 实测入账项（§11），任一类保护页不入账都会使本账本与实测少算。共享基数：
旁车 / 租约 / 根校验器每根一份，2/8/32 worlds 共享不随世界数放大；随世界数增长的
只有各世界登记表与校验器部分。

**稳态保留与恢复峰值分列**：稳态保留 = 上表前七行（校验关闭配置下，登记表与校验器
部分为零；旁车基线与租约随共享根存在）；校验峰值 = 后三行，校验窗内出现、窗后
释放。**「恢复峰值」不属 Runtime 侧**：落点下恢复是宿主处置（restore + 重放），其
峰值按 snapshot §8 度量分列在宿主恢复链。实现报告必须把「稳态保留 / 校验峰值 /
宿主恢复峰值」三列分开，不得相加冒充单一数字。

## 7. 失败语义与遥测级别（必答第 5 项定案）

**校验结论三值**：

| 结论        | 含义                             | 语义                                       |
| ----------- | -------------------------------- | ------------------------------------------ |
| `Pass`      | 本窗口声明对象全部一致           | 只覆盖声明对象与窗口，不外推               |
| `Mismatch`  | 期望值与重算值不等               | 失败关闭；判因按对象类别                   |
| `Untrusted` | 校验过程不可信 / 无可信基准（§2.4） | 失败关闭；判因「无法判因」，不输出通过   |

**失败分类不变量**：提交前容量预留失败是尝试局部可恢复错误（§2.4），**不进入**失败
关闭态；`Mismatch` / `Untrusted` 才触发粘滞失败关闭。二者不得混同——混同会让「可
重试」承诺失效。

**失败关闭语义**：`Mismatch` 或 `Untrusted` 使世界进入完整性失败关闭态——不再推进、
不再提交、不自动纠偏 / 回滚 / 重演 / 重启。校验窗自身返回三值结论；失败关闭后
`step` 返回「世界已失败关闭」终止性失败（世界状态轴，非 `StepError` 可重试语义，
API 标识符 G2 落定）。**未放行的待决结果作废**（§4.5）；已发布事件 / 观测 / 宿主
副作用不撤销。失败关闭粘滞态拒绝**一切变更入口**——生命周期命令（路线注册、spawn、
replace、停车、despawn）、管理面写入口、快照保存与切换一律返回同一终止性错误（各
API 暴露同一错误轴，不得留下任何能改写冻结视图的提交边界）；只读**取证入口**显式
保留（导出冻结视图、登记表与遥测，不承诺可信、不进入正常观测流）。句柄、世代与
冻结视图保持不变供宿主取证。共享根失配触发根级失效传播（§3）：所有绑定消费者失败
关闭，不止检测方。处置权在宿主（§3）。

**判因轴**：`逻辑对象` / `物理-热表` / `物理-工作区` / `物理-共享静态根` / `登记表` /
`无法判因`。判因不承诺唯一根因；多层同时显形时按「最靠近写者的证据」归类，证据
冲突一律「无法判因」。判因输出附失真指纹分类（与 #794 / `validation-matrix.md`
对齐）：页边界偏移、整页替换、页整数倍位移、零页、非页对齐（后者提示非环境失真，
转代码嫌疑，走环境对照再谈代码）。

**遥测级别**（递进包含，不是并行通道）：

| 级别            | 内容                                                                | 默认 |
| --------------- | ------------------------------------------------------------------- | ---- |
| `L0 Trace`      | 校验窗进度、scrub 轮转位置、登记量                                  | 关   |
| `L1 Verdict`    | 每校验窗 Pass / Mismatch / Untrusted 计数与滞后实际值              | 开   |
| `L2 Mismatch`   | 失配现场：对象、页序、tick / 游标、期望 vs 实际、指纹分类           | 开   |
| `L3 FailClosed` | 进入失败关闭 + 判因轴结论 + 处置提示（宿主恢复入口）               | 开   |

遥测是诊断面，不进入 C(T)、不进入摘要、不进入快照；遥测失败不影响失败关闭语义。

## 8. 性能测量协议与待验证预算

**计入口径（定案）**：校验摊销**单列**，不计入
[`core-runtime-performance-baseline.md`](core-runtime-performance-baseline.md) §6
W1 presentation 主行 p95（一万 Core ≤ 2 ms/tick、十万 Core ≤ 16 ms/tick）；校验是
可配置韧性面，混入 Core p95 会把韧性成本误记为交通求解成本。同时给两个独立预算，
**同一个 5% 不得两种解释**：

- **摊销预算** = 校验窗总耗时 / 窗间拍数（跨轮转周期平均）≤ 对应规模 Core p95 主行
  的 5%；
- **突发预算** = 校验拍（单个校验窗在一拍内完成时的整拍）tick 墙钟上限，报告
  p50/p95/p99/max 与 `burst_max`（对齐 §8.2 W4 burst 口径）；摊销达标但单窗超突发
  上限仍不合格，反之亦然；
- `(N_L, K, M_rec, M_phys, M_phys_root, M_rev)` 必须同时满足两预算；放不下突发预算
  只允许调大 `N_L`（降核对频率）或缩小核对范围，**不得跨拍分片重算**（分片跨越提交
  会把多份已提交状态拼进同一摘要）；间隔 / 周期是合同值，变更回写本节与 §5；
- 两预算覆盖的校验成本 = 写集增量登记（双族）+ K 页 scrub + 周期独立复核 + 输出批次
  核验 + 记录与结构轮转重算，全部实测计入摊销 / 突发行；逐脏页整页重哈希出现即视为
  预算外。

**测量协议**：普通拍 / 校验拍分列统计（对齐 catch-up frame 口径）；恢复停顿口径 =
宿主处置链停顿（`restore_lfrs` + 命令重放至失配区间前），按 snapshot §8 度量，**不进
产品 Gate**；稳态零分配纪律沿性能基线 §8.3（登记表增长在安装 / 恢复 / 容量边界一次
checked reserve，校验窗缓冲复用预留容量）；百万档无实时 SLA，只定检测延迟上限。

**待验证预算**（分规模；全部为待验证预算，实测归实现 Issue；1.0 前可依据可复现
证据收紧、放宽或重构，影响合同或验收结论时返回 G1）：

| 维度                                   | 一万（16 ms 拍）                          | 十万（33 ms 拍）                          | 一百万（不冻结 cadence）           |
| -------------------------------------- | ----------------------------------------- | ----------------------------------------- | ---------------------------------- |

## 11. G2 落定清单（实现内容收口，不属 G1 冻结）

以下为实现选型、参数与形态，G2 按实测落定并回写对应章节；**任何一项被实测推翻并
影响合同或验收结论时返回 G1**。正文的合同与不变量不依赖本清单的具体取值。

**哈希选型（§4.3）**：

| 方案                   | 主构造                                | 复核族（异族）                       | 主构造碰撞界 | 落定要点                                             |
| ---------------------- | ------------------------------------- | ------------------------------------ | ------------ | ---------------------------------------------------- |
| ① 性能优先（**倾向**） | 页内子块 Merkle，子块哈希 = XXH3-128  | CRC32C 写集 delta                    | ≤ 2⁻¹²⁸（启发式，§4.4） | 子块重算快、过量哈希小；复核族真 delta、便宜      |
| ② 界最优               | 键控 XOR / Zobrist 128 位（真 delta） | 子块 Merkle（SHA-256 截断或 BLAKE3） | ≤ 2⁻¹²⁸（通用哈希模型，可证明） | delta 成本最低；键材料派生 / 存放 / 保护落定      |
| ③ 保守基线             | CRC32C 写集 delta                     | 页内子块 Merkle（SHA-256 截断）      | ≤ 2⁻³²       | 教科书式可移除构造；双族 ×2 下 delta 成本风险        |

实测主项 = **delta 更新成本**（不是整体吞吐）；性能依据（各算法吞吐量级、双族增量
最坏成本对比）以 G2 实测报告为准，文档不冻结参考数字。若要声明级碰撞保证，按 §4.4
选抗碰撞族承担。`xxhash-rust` / `blake3` 等新 crate 须过
[`../governance/dependency-security.md`](../governance/dependency-security.md) 与
cargo-deny。

**构造与参数形态**：子块 Merkle 粒度；写集 delta 的移除算法；登记表双副本布局；
滚动摘要合成形态（已认证增量 / 受保护日志合成）；校验器控制状态冗余导出与粘滞位
写序；键材料派生与保护；初始化掩码形态（整页初始化 / 连续前缀边界 / 任意位掩码，
掩码方案账面 ≤ 512 B/页量级须实测入账）；K 页 / 校验窗与 `M_rev` 取值修正；每页
账面字节上界；可选强化（消费前提交载荷校验、精确写集差分重登记、全态累积摘要、
第二族按受保护登记日记独立更新）。

**API 标识符（G2 落定）**：完整性错误轴与「世界已失败关闭」错误类型；校验窗入口；
不透明待决结果（`PendingStepOutcome`）与其放行 API；待决快照（`CapturedSnapshot`
放行门）；租约守卫 API（取得 / 释放 / 发布互斥）；共享根访问器的守卫化返回；
完整性模式字段（聚合所有、显式提供）；根校验器入口；取证入口；遥测句柄。
