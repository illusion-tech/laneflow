## 1. 结论

三个合成工作负载与三种模块图配置档组成的九个自然身份都找到了可靠基础规模 `B`。
每个 `B` 均由七个独立冷实例 `timing` 子进程产生：墙钟中位数达到时钟可靠阈值、
中位绝对偏差（MAD）不超过中位数的 `2%`，七次语义摘要一致，研究停止护栏均未触发，
并通过独立 `oracle` 子进程的完整计数与有类型输出核对。

## 3. 计算规则

每项指标都只使用同一自然身份在 `B` 上的七个原始值：

1. 对七个精确整数排序并取第四项作为中位数；
2. 对每项计算其与中位数的绝对差，排序后取第四项作为 MAD；
3. 取七项最大值作为观测上界；
4. 以 `观测上界 / 中位数` 作为同组离散放大比，再把该比值应用于观测上界；
5. 墙钟向上舍入到 `100` 纳秒，字节向上舍入到 `1` 字节。

因此临时预算为：

```text
ceil_to_quantum(observed_upper * observed_upper / median)
```

这是一条透明、保守且容易从七个原始值重新计算的首轮规则，不冒充基于两批正式阶梯的
重复性包络。

## 4. 正确性核对

Rust 重算器拒绝以下输入：缺少任一自然身份、`N = 1` 起始或严格二倍递增路径错误、
`B` 不是首个合格级别、样本不是七个不同冷实例、身份或二进制角色不一致、时钟阈值或
MAD 不合格、护栏触发、语义摘要不一致，以及独立预言机未通过。它随后从原始值重新计算
中位数、MAD、观测上界、精确有理放大比和预算。

对本次 JSON 另做了一次只读核算：十八项指标都恰有七个原始值；中位数、MAD、最大值和
预算公式的重算不一致项为零；来源检查点摘要相符。
