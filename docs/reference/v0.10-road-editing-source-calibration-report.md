## 1. 结论

本轮在 `LF-P100-REF-01` 上完成 84 个串行 fresh release process：80 个计时进程和 4 个
allocator probe。十组 workload/profile 各有 1 个预热样本和 7 个正式样本，共形成 70 个
正式样本、10 组中位数/MAD 汇总；没有删除异常值。

- 九种主 P100 档位组合及 Fine/Smooth regularity companion 均完整编译成功；
- compiler-controlled peak 最大为 7,256,043 B，低于冻结上限 43,269,120 B；
- 四个 allocator probe 均完成，三个 complete-compile probe 的实际新增 heap peak均由同次
  production compiler ledger 覆盖；candidate build+encode 单独报告，不冒充编译器账本；
- companion 精确产生 3 次 horizontal-regularity node visit，覆盖主 P100 全直线 alignment
  无法触发的 curved-offset 路径；
- 单模块改写只改变 `p100.m02`，另外四个模块保持 byte identity，并在旧 accepted revision
  与候选 buffer 同时存续时完成候选编译；
- 全部位置观测值均低于对应 2/5/10 cm 档位的固定网格观测目标；最终方向以冻结的
  binary64 cosine-squared bits 判定，不用平台数学库角度值作规范事实。

## 6. 判断边界

本轮支持以下判断：

- 现有 `43_269_120` B compiler-controlled ceiling 对冻结 P100/companion 有充足余量；
- verifier、语义 lowering、曲线细分和原子候选生命周期均已进入可复核证据；
- 方向验证不依赖 `acos`、`atan2` 或平台数学库逐 bit 一致性；
- B1 可进入 G3 复核，但仍需 CI、exact-head 审阅和 Delivery/cutover 门禁后才可作为产品路径
  合并。

本轮不支持以下推断：

- 2/5/10 cm 是连续曲线全域误差上限；
- FlatBuffers 已被实测证明比 Protobuf 或未选择的旧 JSON 路径更快；
- P100 是全部合法城市的最坏输入，或这些毫秒值是玩家设备 SLA；
- 当前 unpublished B1 bytes 获得长期兼容或迁移承诺。

覆盖已有输出，应写入新路径后比较。
