# 共享根认证与直算摘要实测基线

> **状态**：`LF-ATTEST-P100-PRODUCTION-R0-v1` 已完成描述性实测。<br>
> **测量源码**：提交 `06f239c39b3983efd8d39ecb0820131bc140fd77`，测量日期 2026-10-23。<br>
> **紧凑证据**：`v0.10-attestation-production-baseline.json`。

本基线对应 #987，报告发布来源共享根认证与直算摘要的描述性成本，不构成产品 SLA。
认证调用、合同峰值、稳态保留、装载世界并发干扰和直算摘要对照均按下述边界测量。

## 工作负载

`LF-ATTEST-MIXED-SYNTHETIC-TIERS-v1` 使用一万、十万、一百万稳定静态实体的混合
合成网；含信号、冲突、准入门和可安装策略集。策略集自身的一个实体计入总数。
直算摘要分别装载一千、一万、十万辆车及 437、4369、43693 条路线。这是短链记录
负载，不代表同规模城市运行世界。

`LF_ATTEST_SMOKE=1` 仅选择一千静态实体、一百辆车、43 条路线；所有输出带
`smoke=true`。它只验证 harness，不用于生产基线，也不得与正式样本合并。

## 测量边界

- 墙钟二进制不插桩。`fixture_prepare_ns` 覆盖生成、编译、发射和共享根构建的
  整个准备过程，不再命名为根构建耗时。认证计时只覆盖一次认证调用。
- 直算与现行路径分别暖机两次；五个正式样本逐一验证摘要相等。现行路径每个样本
  连续执行 capture → digest，分别报告两段及端到端耗时；快照析构在计时区外。
  比较使用端到端样本的中位数，不把两个独立中位数相加。
- 并发对照在十万静态实体、一万辆车的两个相同初态世界进行。各暖机 16 tick，
  各测量 256 tick，固定步长 4 ms；短模拟时长确保所有车辆仍在场，并在末尾断言。
  工作线程随测量结束停止，分别记录重叠窗口耗时、窗口内已完成认证次数和包含
  尾次认证的总次数；无完整认证与 tick 重叠则拒绝该轮。末尾摘要必须相等。
  干扰报告有符号中位数与 p95 差值，不把负值截为零；不能外推至其他运行负载。
- `stats_alloc` 二进制只有一个测试。暖机在 Region 外，每条路径使用独立 Region，
  分配字节按该库的 realloc 净增口径计数；不包含前一路径和暖机。
- DHAT 峰值二进制也只有一个测试。每个区间创建独立 profiler，逐分配事件记录
  堆请求字节的最大 live 值，避免定时采样漏峰。它与墙钟、Region 计数分离。
  分析器自身开销、分配器元数据、栈和 RSS 不属于所报告的堆请求字节。
- 认证额外堆峰值由 DHAT 直接测量；**合同增量 = LFCA 来源字节 + 额外堆峰值**，
  **合同共存总量 = 合同增量 + 被认证根实测保留堆字节**。根的保留堆字节在独立
  构建区间测量，不能以 `retained_logical_bytes` 代替。来源虽被借用，仍需计入。
- 直算摘要同时报告限额二分得到的归一化 scratch 预算边界及 DHAT 堆峰值；二者
  口径不同，不能将限额边界冒充实际堆峰值。验证边界值通过、少一字节失败。
- 新增稳态保留由 Region 前后有符号 live 差与 DHAT 区间末尾 live 值分别核对为零。

## 正式结果

2026-10-23 在交流电、平衡电源方案下顺序测量；AMD Ryzen 9 9955HX（16 核／32
逻辑处理器）、66232508416 B 物理内存、Windows 11 build 29683.1000、Rust 1.98.0／
LLVM 22.1.8。计时窗口用时 147.3 s，计数与堆峰值窗口用时 186.1 s，均未超时。
两轮计时各三档、每档五个样本；并发对照四轮；Region 与 DHAT 各两轮。全部断言
通过；两轮分配、归一化预算边界及堆峰值逐项相同。JSON 保存计时样本、源码提交、
文件树、二进制和日志 SHA-256、退出状态及实际运行时长。认证和摘要保存逐样本值，
并发 tick 只保存分位汇总，不保留逐拍时序。完整 stdout/stderr 留在
本地忽略目录，仓库不承诺原始日志的外部下载或长期恢复。

| -----: | ---------------------------: | -------------------: | -------: | --------------------: | ---------: |
|   1000 |                       593546 |     749944 / 1198500 |   37.43% |      712968 / 1027956 |     30.64% |

两条路径每个样本摘要一致。直算分配减少 37.43%–41.24%，实际堆峰值减少
30.64%–34.90%；墙钟比现行完整路径慢 21.99%–32.03%。归一化 scratch 预算只约束
指定的归一化存储，不能当作整个调用的堆峰值：一千／一万辆车时，调用峰值高于
该预算边界。免物化和更低内存成本不意味着墙钟更快；本基线不承诺直算速度优势。

## 复现与采信

正式计时、计数需分别取得安静窗口授权。窗口前完成 release 编译；窗口内清除
`LF_ATTEST_SMOKE`，顺序执行，禁止并行运行三个二进制：

```powershell
cargo +1.98.0 test --release --locked -p laneflow-runtime --test attestation_wall_clock_evidence -- --ignored --nocapture --test-threads=1
cargo +1.98.0 test --release --locked -p laneflow-runtime --test attestation_allocation_evidence -- --ignored --nocapture --test-threads=1
cargo +1.98.0 test --release --locked -p laneflow-runtime --test attestation_heap_peak_evidence -- --ignored --nocapture --test-threads=1
```

小规模功能验证使用相同命令，并在当前进程设置 `$env:LF_ATTEST_SMOKE = '1'`。
本次直接运行预编译 release 测试二进制，参数与以上命令等价；重复轮次使用同一
二进制。以后改变测量源码、工具链、输入或系统环境时，应新建基线修订，不原地
改写本次结果。城市运行质量、长期浸泡和宿主完整恢复链的成本不由本基线认证。
