## 1. 结论

R0 已完成九个自然身份的基础规模发现和两批正式阶梯，共记录 2446 个受监控新进程
运行；本轮没有无效运行或受护栏运行。九个正式阶梯均完成五级规模，形成 180 条按完整
测量分层计算的预算建议和 30 条候选分类。

- `LF-COMP-ID-v1` 的三个模块图配置档均在正式阶梯观察到确认拐点；宽星形与深链形的
  校准/压力规模为 128/256，共享汇入有向无环图为 256/512。
- `LF-COMP-CORRIDOR-v1` 未在五级内观察到拐点，三个配置档的校准/压力规模均为 8/16。
- `LF-COMP-JUNCTION-GRID-v1` 未在五级内观察到拐点，三个配置档的校准/压力规模均为
  32/64。
- 候选矩阵没有得到可重复改善：25 条为噪声范围内无差异，1 条证据不足，4 条为可重复
  回退。三种规模下 `deterministic-radix-sort-v1` 均为可重复回退；
  `deterministic-bucket-sort-v1` 只在基础规模回退，另外两种规模处于噪声范围。
- 因此 #308 不建议 #292 仅凭本轮候选墙钟替换完整管线基线；候选安全与正确性资格结果
  仍可作为 #292 实现基准的输入。

## 6. 候选矩阵判断

候选性能范围是 `LF-COMP-JUNCTION-GRID-v1` 的基础、校准与压力规模；每项比较均使用
两批平衡顺序、同批同轮基线配对和精确有理数中位比值。结论分布为：

| 分类             | 数量 | 说明                                                                              |
| ---------------- | ---: | --------------------------------------------------------------------------------- |
| 可重复改善       |    0 | 没有候选在两批均越过墙钟重复性包络的改善侧。                                      |
| 噪声范围内无差异 |   25 | 两批结果均落在重复性包络内。                                                      |
| 可重复回退       |    4 | `deterministic-radix-sort-v1` 三种规模；`deterministic-bucket-sort-v1` 基础规模。 |
| 证据不足         |    1 | `sorted-vec-binary-search-v1` 外部字符串键域校准规模，两批方向不一致。            |

本轮结果不支持提前替 #292 选择哈希或容器。特别是 XXH3、XXH64、FNV-1a64、
`hashbrown` 与 `indexmap` 在受测完整管线中均没有越过重复性包络形成可重复改善。

## 7. Evidence 工具性能修正

原实现把原始检查点展开为九千多条 Evidence 运行记录，并在大型复杂数组上执行 JSON
Schema `uniqueItems` 比较；一次投影/验证需要十几分钟，临时检查点累计占用约 44 GiB。
G2 修正删除了该二次数据模型：Schema 从 230966 字节缩为 5485 字节，Evidence 从调试
阶段的约 170 MiB 降为 2692021 字节。严格复用基础规模试运行验证、逐条拒绝无效正式
运行封套并闭合三个二进制角色后，当前工作树的已编译 release 二进制写出/独立验证
实测分别约为 1.2 秒和 1.4–1.7 秒；Cargo 首次重编译时间不计入工具运行时间。验证器还会
将每条正式阶梯的 `B` 和首级绑定至选定基础规模，从已验证的前级观察重算护栏预检，并
复核五级平衡轮转。候选分类前会重算冻结 scope 与三个规模，强制其与三个键域形成完整
九格矩阵，再从注册表、安全结论和资格子进程重建参赛名单，一次性复核平衡顺序、有效
尝试、进程结果、资源护栏与轮次语义，并以索引读取分类样本，不按
候选重复扫描原始记录。路径同时从六次原始子进程运行重建每项常量哈希资格，并从清单
独立重建全部正式层级的预言机结果和工作负载计数。未被预算、拐点或候选决策消费的对数
增长斜率不再进入 Evidence。篡改原始 SHA-256 后验证器以非零退出状态拒绝。该计时只
证明工具工程问题已消除，不属于编译性能预算。

Evidence 发布提交保存，不要求存在于较早的测量提交工作树中。

```powershell
cargo +1.96.0 run --release --locked `
  -p issue-308-compiler-budget-calibration-research `
  --no-default-features --features research-runner-full `
  --bin issue-308-compiler-budget-calibration-research -- `
  run --protocol compiler-calibration-v1 `
  --environment <environment-declaration-path> `
  --output <new-formal-execution-path>
```
