## 4. Authority、原子性与确定性

最终权威边界与 ADR 0016、ADR 0017 一致：

- Core 拥有 vehicle state、identity、route、occupancy、speed limit、Signals、Maneuver occurrence 编译、Gate permission 和原子 replace invariant，但不拥有目标人口、seed 或入口选择。
- `laneflow-scenario` 的可选 reference policy 拥有 v0.9 的目标人口、stable catalog normalization、SplitMix64 state、portal/lane/route 决策和 blocked retry；未来宿主可以替换它。
- Adapter 拥有 `VehicleHandle <-> Entity` 部分双射和 `Lifecycle -> Step -> Observe` schedule transaction；它不复制交通规则。
- Spatial 拥有 canonical centerline/frame/pose，Presentation 只拥有 proxy、mesh、Transform、灯具与 HUD。
- Junction/Movement/ManeuverPath/ManeuverGate 是 Traffic v0.8 的静态 identity 事实；RoadSection、LaneGroup 与 JunctionGroup 只冻结长期语义，不进入 v0.9 schema 或 runtime。

Core replace 和 Adapter binding 采用预检后提交。`Blocked` 与 fatal validation 都保持 committed authority 不变；成功后 mapping 在同一公开事务中从 old handle 轮换到 new handle。一个 outer frame 运行多个 catch-up step 时，每个 fixed step 都重复 lifecycle、Core step 和 ordered completion consumption，因此 outer-frame 分块不改变 Core/population replay。

同 seed、catalog、fixed-step input sequence 与同一实现版本得到相同 initial/recycle 决策。初始 Fisher–Yates、per-slot weighted RouteChoice、portal/lane/route draw order、simultaneous completion 顺序和 blocked retry 不消耗新随机数均由 golden tests 固定；该承诺不是跨版本或跨平台 bit-level 兼容承诺。
