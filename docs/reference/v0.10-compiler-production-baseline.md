# #292 P100 首轮生产编译基线

> **状态**：`LF-COMP-P100-PRODUCTION-R0-v1` 已实测<br>
> **测量日期**：2026-08-04<br>
> **编译器实现**：与本证据同一提交<br>
> **紧凑证据**：`v0.10-compiler-production-baseline.json`

本文保存 #292 在产品推荐参考机型 `LF-P100-REF-01` 上首次运行真实生产编译器的描述性
基线。它回答“当前已实现的完整生产编译管线能否正确、快速且按规模可解释地编译合法
产品语义”，不是城市容量、玩家编辑停顿或产品服务等级协议（Product SLA）。

## 1. G1 修订来源

G2 证明 #308 研究替身的 126 条自然身份不能无损映射为合法生产语义。产品负责人随后
在 #292 追加 [G1 性能证据边界修订][g1-revision]：#308 保留为容量估算输入，生产
编译器改用真实可编译场景形成首轮基线。

第一次试运行还确认，加入第 6 份完整走廊时，`SourceBytesTotal=560374` 已超过
`LF-COMP-P100-INITIAL-v1` 的 `542741` 字节上限。该失败发生在计时区外并正确失败
关闭。后续 [G1 规模阶梯更正][g1-scale-correction] 因而冻结资源配置档内已实测成功的
1、2、3、4、5 份完整走廊，不静默放宽资源上限，也不删减工作负载语义。

## 2. 工作负载与测量边界

`LF-COMP-PRODUCTION-CORRIDOR-v1` 重复仓库内受版本控制的完整信号化走廊 Traffic +
Spatial 样例；每份副本使用独立的 Traffic/Spatial 来源模块命名空间。每份包含 66 条
`LaneEdge` 以及横断面、路口、机动路径、信号、停车、准入、车辆配置、静态路线和规范
空间几何等 #292 G1 首批生产语义。

- `serde_json` 解析、规模复制、Synthetic DSL 构造和 `CompilationUnit` 建立均在计时
  区外；
- 唯一计时区从调用 `Compiler::compile` 前开始，在取得完整 `CompilationOutput` 后
  结束；
- 指标读取、语义指纹核对、当前态投影和 JSON 序列化均不进入计时；
- 编译器控制峰值取 HIR、MIR、LIR 和源映射冻结各阶段“持久数据 + 当阶段暂存数据”
  估算的最大值；它不等于进程工作集，也不会漏掉早于最终输出出现的阶段峰值；
- 每级 1 次预热和 7 次正式样本；单进程、单工作线程、release；
- 同一 `Compiler` 顺序执行。当前实例不持有跨编译 arena 或缓存，保留容量为 0，因此
  不重复制造没有语义差异的冷实例/复用两套样本；
- 仓库只保存五级 `min/median/max` 紧凑汇总，不保存 35 条逐样本 raw。

复现命令：

```powershell
cargo +1.96.0 test --offline --locked --release `
  -p laneflow-compiler-test-support --test current_equivalence `
  p100_production_compiler_baseline -- `
  --ignored --exact --nocapture --test-threads=1
```

## 3. P100 结果

测量环境与 #308 的 `LF-P100-REF-01` 是同一物理机器：AMD Ryzen 9 9955HX
（16 核 / 32 逻辑处理器）、66232508416 字节物理内存、交流电、平衡电源方案、
Rust 1.96.0 / LLVM 22.1.2。本次操作系统为 Windows 11 Pro Insider Preview build
29639；相较 #308 记录的 build 29617 已发生系统更新，因此本报告不与 #308 墙钟值作

## 4. 结论与使用边界

- #292 已取得真实生产 `Compiler::compile` 的时延、编译器控制峰值、保留容量、输出量和
  五级规模扩展基线；
- `LF-COMP-P100-INITIAL-v1` 在所有正式级别继续失败关闭，且第 6 份走廊的试运行证明
  来源总字节上限确实生效；
- 本次结果只冻结后继生产实现的同机 R0 对照，不把 #308 研究值或本次绝对时延升级为
  产品 SLA；
- 后继改变编译阶段、缓存、容量复用、工作负载内容、工具链或参考机系统环境时，必须
  使用新基线修订，不能原地改写本文件；
- 玩家在线编辑停顿、真实城市路网容量、最低硬件和 portable artifact / static image
  发射仍由后继 Issue 验证，不属于 #292 G3。
