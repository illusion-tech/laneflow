# LaneFlow 1.0 前

尚未对外发布。当前树没有用户、没有兼容承诺。开发中走过的路是弯路，不是产品世代。

## 原则

1. **当前只有一套真相。** 代码、接口、文档、测试都只表达现在的权威。旧实现以 git 为准，不在当前树并行存活。
2. **接口不要演出版本世代。** 名称里的世代后缀会暗示旁边还有另一套。载荷上的版本数字是拒绝闸口，不是公开 API 的分身。
3. **兼容是发布之后的事。** 禁止为「以后可能用到」保留转换、双轨、弃用别名或开关切旧路径。没有外部用户，就没有兼容包袱。
4. **文档服务纯净，不是化石。** 1.0 前 G1/ADR 冻的是此刻的权威。若字面会逼出兼容层，改文档、删代码。不要用「已经冻过」对抗清扫。
5. **1.0 是分界。** 本原则到正式发布为止。发布后的对外兼容必须单开设计，不得把本 Skill 读成「永远可以拆」或「必须提前堆 shim」。

本 Skill 只约束态度，不枚举字段、算法身份或历史校准名。那些以当前 design / ADR 为准。
