## 短窗四臂

Core 均值是每轮均值的等权平均；p95 给出各轮范围，不合并不同轮次样本冒充正式认证。
iteration 包含研究质量观察与交通日志写出，不含计时/计数 CSV 行写出及结束 flush。

| ---- | ------------ | ---: | -----------: | ---------------: | ----------------: |
| 10k  | A 基线       |    3 |        3.995 |      4.665–4.826 |             9.454 |
| 10k  | B 仅 P3      |    2 |        3.464 |      4.044–4.229 |             8.698 |
| 10k  | C 仅 Waiting |    2 |        3.845 |      4.644–4.666 |             9.317 |
| 10k  | D 组合       |    2 |        3.377 |      3.918–4.559 |             8.657 |
| 100k | A 基线       |    3 |       54.070 |    62.665–66.713 |           129.565 |
| 100k | B 仅 P3      |    2 |       47.235 |    53.647–58.074 |           122.033 |
| 100k | C 仅 Waiting |    2 |       50.968 |    58.135–63.817 |           124.427 |
| 100k | D 组合       |    2 |       44.995 |    54.489–55.374 |           118.914 |

D 对 A 的 Core 均值改善约 **15.5% / 16.8%**；iteration 均值改善约 **8.4% / 8.2%**。
本批两次 D 都快于三次 A。首次 A/A 均值差为 0.023/0.026 ms；包含末次 A 的
基线极差为 0.173/1.362 ms。它们只描述本批波动，不是永久噪声阈值。
10k 的 C 单独差值约 0.151 ms，小于三轮 A 极差；D 相比 B 的增量也未充分分辨。
100k 的 C 与组合均给出改善信号，但不能把二者之和当作组合收益。

每档四臂的实际初态文件摘要一致，均接纳全部 10000/100000 个体（7500/75000 Active，
2500/25000 Parked）。短窗质量聚合值也一致：10k 完成 435、成功替换 11、
推进约 102.003 km；100k 完成 9411、成功替换 880、推进约 2097.804 km。
实际 Active 分布逐轮保存在机器数据中，100k 是个体总数，**不是稳定 100k Active**。
聚合一致是本窗口观察事实，不是重新引入旧逐拍轨迹等价门槛，也不证明所有场景等价。

## 工作量与成本转移

独立计数构建，各档四臂、单 worker、256 拍。计数不进入上述延迟结果。
周期覆盖整个 `Harness::advance`，其中运动计算可能包含当拍命令的安全预览。

| 规模 | 数量                |     A 基线 |   D 组合 |
| ---- | ------------------- | ---------: | -------: |
| 10k  | P3 完整求值         |    1905007 |    23747 |
| 10k  | P3 逻辑状态复制字节 |  167640616 |  2089736 |
| 10k  | Waiting 完整预览    |    1180361 |        9 |
| 10k  | 全部运动计算调用    |    1924321 |  1924321 |
| 100k | P3 完整求值         |   18623146 |   477081 |
| 100k | P3 逻辑状态复制字节 | 1638836848 | 41983128 |
| 100k | Waiting 完整预览    |   12065682 |      841 |
| 100k | 全部运动计算调用    |   19672074 | 19672074 |

P3 求值减少约 98.8%/97.4%。B 与 D 的 P3 数量相同，C 与 D 的 Waiting 数量相同。
Waiting 预览的巨大下降**没有减少总运动计算次数**，计算主要转移到后续消费；这解释了
不能用 Waiting 局部减量宣布同等整拍收益。当前证据支持删除不必要的候选准备与表示成本。

逻辑复制字节由求值次数和 `size_of(VehicleState)` 推导，不是硬件带宽或完整 cells/claims
账本。诊断为单 worker，P3 分发预数没有执行，零计数不代表多 worker 无扫描；多 worker
删除预数的代码变化可核对，但本项没有独立测量该扫描耗时。总运动计算没有按 P2/P3/P5
拆分，不能单靠此列量化 Motion 阶段的毫秒转移。

## 10k 长窗与质量限制

A、D 分别从原初态执行 16384 拍，即 262.144 秒，越过两个 7656 拍信号周期。
长窗是单次 A/D，作为范围与质量延伸；没有将它计作新的重复性能认证。

| 窗口                  | A Core 均值 / p95 ms | D Core 均值 / p95 ms | A / D iteration 均值 ms |
| --------------------- | -------------------: | -------------------: | ----------------------: |
| 513–15312，运行段     |        4.153 / 4.864 |        3.663 / 4.506 |           9.834 / 9.192 |
| 15313–16384，后段回流 |        4.341 / 5.161 |        3.762 / 4.511 |          10.238 / 9.464 |

两臂均完成 2909 次行程片段、成功替换 978 次、推进约 822.326 km；大于 8 m/s²
的拍间减速计数均为 10022。车辆守恒与原 Harness 同边车体重叠校验通过；未配对
clear 事件与完成 owner 残留 reservation 均为 0，窗口末尾仍有 95 个未结束 reservation。
这些指标不证明完整二维碰撞安全，8 m/s² 只是研究诊断阈值。

两臂共同暴露出严重的长期等待：8478 条片段中，5569 条被窗口右截断，4990 条片段
最长连续停车至少 60 秒，最长连续停车 **260.48 秒**，片段最长停车的 p95 为 244.8 秒。
完整新起止且完成的行程为 **0**。因此不能仅凭已有完成者报告总体旅行时间，也不能宣布
公平性、交通质量或持续服务率合格。候选未在这些已测指标上加重问题，但并未解决它。

## 验证、结论与未覆盖项

- 普通 release 与独立计数 release 构建成功；`cargo check` 通过。
- 3 个新边界测试通过：近／远门、前一门与未知数值域、Waiting membership、同槽新代次。
- 组合模式下 7 个既有 `failed_` 回归通过，覆盖失败提交、发布、资源暂存、重试和槽位复用。
- 原主干两档接纳试跑成功；研究共有 **28 个完整运行**：18 个重复短窗、8 个计数运行、
  2 个 10k 长窗。一次 100k P3 诊断中断，无退出状态和完整包，已排除并另目录重跑；
  中断文件也列入索引，没有补写成功状态。
- 分析器接受有效包，拒绝退出失败、来源变化、HEAD 漂移、脏研究树、二进制摘要不符、
  worker 不符、计数模式不符、缺失拍号等 8 类损坏。重建源全树摘要一致。
