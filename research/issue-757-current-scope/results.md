**保留 P3 工作范围缩减候选，并推进 `laneflow-runtime` 接入。** 本批仅 P3 在

P3 求值减少约 98.8%/97.4%；B 与 D 的 P3 数量相同，C 与 D 的 Waiting 数量相同。

## 10k 长窗与质量限制

A、D 各从原初态执行 16384 拍（262.144 秒），越过两个 7656 拍信号周期。
各一次长窗只扩展已观察范围，不构成重复性能认证。“周期后段”是时间窗口名称，不能据此声称完整回流链已覆盖。

| 窗口                  | A Core 均值 / p95 ms | D Core 均值 / p95 ms | A / D iteration 均值 ms |
| --------------------- | -------------------: | -------------------: | ----------------------: |
| 513–15312，运行段     |        5.223 / 6.330 |        4.848 / 5.883 |         11.872 / 11.392 |
| 15313–16384，周期后段 |        5.287 / 6.298 |        5.079 / 6.011 |         12.026 / 11.833 |

两臂均完成 2909 次行程片段、成功替换 978 次、推进约 822.326 km；急减速计数均为 **7113**。
急减速仅统计前后均为 Active 且拍间减速大于 8 m/s² 的情况，阈值只是研究诊断值。
旧值 10022 多计了 2909 次完成时清零速度。原始错误值未被回填修改，现表使用修正观测器重测。

车辆守恒和原 Harness 同边重叠校验通过，未配对 clear 与完成 owner 残留 reservation 均为 0；
末尾仍有 95 个未结束 reservation。这不证明完整二维碰撞安全。
两臂共同存在长期等待：8478 条片段中 5569 条右截断，4990 条最长连续停车至少 60 秒，
最长停车 **260.48 秒**、片段最长停车 p95 为 244.8 秒，完整新起止且完成的行程为 **0**。
不能仅凭已有完成者报告总体旅行时间；候选在这些指标上未加重问题，也没有解决它。

## 验证与交付边界

- 普通与计数 release 构建成功；研究 Harness lib 21 个测试通过、3 个原有专项手动测试保持 ignored。
- 新急减速回归覆盖正常急减速、阈值边界、完成/停车清零；3 个筛选边界与 7 个既有失败/重试回归通过。
- 修正后完整重测 28 个运行：18 个短窗、8 个计数、2 个 10k 长窗；旧的一次中断尝试继续单列排除。
- 分析器接受有效包，拒绝 23 种损坏，包括跨运行/跨窗口质量、其他规模的真实输入摘要、缺失/重复拍号和丢失进程输出。
  质量记录绑定运行 UUID、规模、模式、workers、拍数、计划与输入，summary 同时封存质量和行程文件摘要。
  计时、工作量和交通日志还须逐文件匹配已提交的原始清单；进程元数据摘要将运行 UUID 绑定到这些文件，
  清单自身的规范 JSON 摘要锁定于 identity.json，不能通过重新索引被替换的计时文件来接受它。
- 全部 28 对新旧运行的初态、逐拍/命令/事件日志和行程 CSV 字节相同，其余质量字段相同。
  这只证明本次观测修复没有改变交通执行，不给后续算法优化附加历史轨迹等价门槛。
- 来源重建摘要一致；Python、Rust 格式、Markdown 表格与差异检查通过。源码、输入和原始包身份可追溯。

#758 的完成是研究工具、修正证据与结论合入。#759 的目标是将 P3 整理进 `laneflow-runtime`，
以筛选、近门/跨边、资源持有、句柄代次、失败/重试的正确性测试、适度性能复测、审阅与 CI 验收。
LaneFlow 仍在 1.0 前，内部代码合入不等同于面向客户的上线或最终产品认证。

100k 多周期、稳定 Active、worker 扩展性、正式三轮、完整资源/线程/屏障成本和最终 2/16 ms p95 预算
尚未认证，继续由 #707 在适当阶段承担，**不作为本次研究或 P3 接入的默认合入前提**。
44544 拍来自历史正式计划的四周期暖机加八周期观察，本项没有证明它是验证此优化的必要最短长度。
如后续确需追加长测，应先写出具体未解决风险、现有测试缺口和结束条件，不能仅因短窗不是正式认证就扩测。

归档补充校验：23 种分析负例、4 种矩阵/工作量归属负例均被拒绝；搬迁后的真实
运行解析结果一致，Debian 重建源码摘要与原封存值一致。原始 344 项大小/摘要未变。
冻结观察器不支持命令停车结束时间戳；本批 28 次运行均无该类结束，分析器亦拒绝
含此类数据的包。此边界不影响上述短测与长窗统计，不能外推成通用观察器正确性。
