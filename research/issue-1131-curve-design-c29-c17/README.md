## C29 / C17 联合验收结论

- **C29（两条完整路径，同一赋值同时验收）**：共享入口边 `sumo:--30452_0` 与后继 `sumo::-20112_0_0` 本轮均零候选，分量保持 `missing_real_programs`、组合赋值 0 次；两条完整路径（`sumo:-20112:--30452_0-to---31818#6_1::-20112_1_0` 与 `sumo:-20112:--30452_0-to--31818#7_0::-20112_0_0`）在同一赋值口径下同不接受（逐轮断言「分量接受 == 两路径同时接受」通过）。`sumo::-20112_1_0` 等原成功边冻结不可改，逐轮断言通过。
- **C17（单条完整路径，两份程序齐备后验收）**：`sumo::-10564_3_0` 有 1 份保留候选（见上），但 `sumo::-10564_6_0` 零候选——两份程序不齐备，分量保持 `missing_real_programs`、组合赋值 0 次。局部候选不记分量恢复。

## 结论边界与差异记录

**探索性定位（plan §6）**：`sumo:--30452_0`、`sumo::-10564_3_0`、`sumo::-10564_6_0` 三条第 1 轮未决边的本轮研究定位为**有限设计变量探索**：148 几何/边的有限族完成且无候选只表示本族未通过，不作可行或不可行结论；零恢复不写成任何可行/不可行结论，不预设必须恢复。`sumo::-20112_0_0`（首弦局部见证 + 注入族耗尽）同理。本轮不改变 #1121 逐边诊断结论——诊断只对原固定 cubic 成立，本轮改变了这些边的内部曲线设计但未越过既有阻点。局部候选（`-10564_3_0`）不构成分量或路径恢复。

**不变量确认**：原 SUMO 输入、全部原成功程序/规范点、身份、拓扑、控制器成员、信号组、停止线、机动门声明、四条边首末坐标与存在端钳制方向（含 `sumo:--30452_0` 末端与 `sumo::-20112_0_0` 起始的 fan-out 钳制冻结值）均保持原 f64 位；sink 1.95°、端弦 0.95°（存在钳制端生效）、规范弦严格大于 0.1 m、0.01 m 研究筛选、compiler 配置档全部不变。结果对照使用 #1115 `variants.new` 仅作对照，未作候选点位来源。

**差异记录（plan §7，两处经 lead 重新授权）**：

1. **`unit end clamps` 断言放宽为对存在端校验**。#1115 模板把其样本口径（首末两端均有钳制）编码为通用断言 `clamps.iter().all(|c| c.is_some_and(…))`，与本冻结样本冲突：`sumo:--30452_0` 起始端为 interior Catmull-Rom tangent、无钳制（`edges.json` / `edge-cohort.json` 的 `direction_source` 均只记其末端 `finish_boundary_clamp`）。经停止、归档（`candidate-run-aborted-unit-end-clamps*`）与报批，lead 授权改为 `input.clamps.into_iter().flatten().all(|d| (norm(d) - 1.0).abs() < 1e-12)`（标签不变）。对两端钳制输入行为逐位不变；#1115 冻结重放复验通过（searches.json 逐字节相等 + pinned 入口内建断言）。attempt 的 0.95° 端弦检查按端可选语义未变。
2. **`.into_iter()` 形态适配**。授权表达式字面形态 `.iter().flatten()` 因 `norm` 按值参数不可编译（E0308，`d` 绑定为 `&[f64; 3]`），lead 裁决采纳适配器 `.into_iter().flatten()`，闭包 `|d| (norm(d) - 1.0).abs() < 1e-12` 与标签逐字保留，语义等价。
3. **与 #1130 流 B 共享 `geom/s1/reshape.rs`**。按 lead 收敛协议单源一致（16,466 字节，SHA-256 `47011e6a68fc26f2d5c7e3e3512cf7fcb42af5268fbaa26fe5c0c81315bda2f3`），两分支对该文件的最终 diff 逐字节相同（diff SHA-256 `e4c9b730…`），各在恰好一个提交落地，合并组 rebase 无冲突。段容量参数化（`search_with_curve_cap` / `policy_with_curve_cap`，`search()` / `policy()` 默认 6 不变）与临时程序 ≤ 96×段数+1 断言为两流共用口径。
