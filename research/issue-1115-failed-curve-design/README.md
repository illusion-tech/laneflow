# 两条失败边的几何调整与信号闭包研究

本轮在两条原失败边内部调整控制柄并合并分段，恢复 `sumo:-16502` 与
`sumo:-28860` 两处完整信号闭包。全部四条 / 八条关联路径联合编译接受，LFCA
后发射检查通过；原 84 条目标的接受数由 26 增至 28。**这是测试研究的正例，
不是生产转换接入或生产 G1 接受。** #790 保持打开。

## 范围与冻结

基线为 `3ad0cfaeb8fee8e7b42821da1ba07eb5ae9423af`；输入为 pinned LuST
`c4bd5bd3751d426d42a9a1749c815e47ea188549`。[执行前方案](plan.md)和
[设计](design.md)先于实验冻结。首轮源码为 `fb6488ef649f81364d0e318152157f8f01a717a1`，
正式源码为 `57a6a222ab57ee3b66a27802627804fd047fd7d2`；独立二进制和源码归档的
身份见 [experiment-protocol.json](experiment-protocol.json)。

只允许 `sumo::-16502_0_0`、`sumo::-28860_3_0` 的内部控制柄与分段改变。
边界端点、首末钳制、全部 16,265 条原成功程序及规范点、拓扑与完整控制信息不变。
原 8,230 条失败诊断重新捕获并核对，没有把研究成功回写为生产成功。sink 1.95°、
端弦 0.95°、弦长严格大于 0.1 m、采样偏离筛选 0.01 m 和 compiler 配置档均未放宽。

## 几何候选与质量

每条边遍历冻结的 148 个几何尝试；原参考、保留分界、相邻两段合并、整边合并
全部保留真实结果。来源拟合的两个方向使用相同算法比较原参考与新参考，分别
要求新估计不高于原估计。0.01 m 管新参考到规范折线的采样偏离，不能当作来源
拟合预算。普通 f64 的保守估计不构成向外舍入的连续认证。

- `sumo::-16502_0_0`：一份完整程序，几何 131，整边合段，首末控制柄因子
  `[1.5, 1.5]`，等 t 23 片。原参考双向拟合估计为 0.014506 / 0.014515 m；
  新参考为 0.013514 / 0.013905 m；规范折线观察为 0.013218 / 0.013196 m。
- `sumo::-28860_3_0`：两份完整程序，均为整边合段。排序第一的几何 124 使用
  `[1.25, 1.5]`、等累计切向角 58 片；原参考为 0.238253 / 0.258135 m，
  新参考为 0.211824 / 0.209303 m，规范折线观察为 0.190958 / 0.206523 m。
  另一份几何 118 使用 `[1, 2]`、等 t 92 片，也通过完整闭包编译。

正向 / 反向依次表示曲线到来源、来源到曲线。以上是冻结估计的通过值；不能据此
声称真实 Hausdorff 距离必然减小或新的生产质量合同已经成立。首轮规范折线观察
按整弦选一个来源段，跨来源顶点时估计过松；正式版仅将该最终观察细化到每弦
64 段。首轮记录和协议保留，全部候选完整程序、控制点、参数、顺序和长度逐值
核对不变；候选筛选与排序没有根据观察结果重调。

每条边都完成有限族，未触发预算。`-16502` 的 148 个几何中，54 个控制回折拒绝、
84 个来源拟合拒绝、9 个本划分族无完整程序、1 个成功；`-28860` 分别为
38、77、31、2。划分次数为 1,827 / 6,228，采样工作为 35,322 / 207,965，
来源距离评估为 7,626,752 / 11,575,296；去重键保留 24 / 152 个点。
完整控制点、拒绝阶段和程序见 [searches.json](searches.json)。

## 长度与控制锚点

`-16502` 来源 `@length` 为 3.64 m、shape 折线为 3.631270 m；原参考弧长估计
3.633023 m，新参考 3.629685 m，规范弦累计 3.629641 m，compiler 得到 3,630 mm，
与来源 `@length` 相差 -0.010 m。

`-28860` 来源 `@length` 为 16.18 m、shape 折线为 16.182038 m；原参考估计
16.004343 m，选中参考 16.094951 m，采样器规范弦累计 16.094333 m，compiler
规范弧长 16.094332 m、长度 16,094 mm，与来源相差 -0.086 m。参考弧长用每段
4,096 片的弦长 / 控制多边形估计，完整双值保存在结果中。不同累计精度的微小
差异如实保留；没有缩放几何或重写源长度。原失败边没有可接受规范长度，不能说
这两条边的规范长度不变。

两处停止线都绑定原成功边。完整程序及所有规范点核对后，继续核对停止线身份、
边身份、端点、规范长度，以及每个机动门的原路径身份、转换下标与信号组。
四条 / 八条路径共 12 个机动门全部核对，通过的两个分量制品分别为 84,227 /
109,314 字节。证据见 [closure-summary.json](closure-summary.json)。

## 完整回归与边界

两组均重新验证 53 个依赖分量和 84 条目标。基线逐值复现 #1113 的完整结果。
新增池使分量接受数由 26 增至 28，缺程序由 24 降至 22，保留池拒绝仍为 3。
两个新分量分别穷尽 1 / 2 份赋值并全部接受；全分量共尝试 62 份赋值，
无组合预算停止。真实目标为 28 接受、3 跨边方向拒绝、53 未完成目标检查。
12 条控制器关联路径与新增的 2 条原目标是不同统计口径，不相加。

这解决了 #1113 已定位的两个固定曲线阻点，但未交付真实多失败边同时恢复，
也未解决其余缺程序分量、三个涉及原成功几何的跨边方向拒绝或全网转换。
正例之外，常规测试保留曲线内部偏离、来源拟合预算、短弦/端向拒绝、回折、
共享多边控制器的错误赋值与缺程序，以及组合预算停止的负例。

## 证据、成本与复跑

四个独立 release 进程按基线/新增、反向、反向、正向运行。每轮保存全部原成功
程序/规范点、控制信息、原失败诊断、候选、分量结果及接受制品；除计时文件外
每轮 60 个非计时文件（88,639,257 字节）逐文件 `fc.exe /b` 比较，文件名集合也完全相同。文件清单、大小和外部互操作用
SHA-256 见 [evidence-manifest.json](evidence-manifest.json)，计时见
[measurements.json](measurements.json)，机器与工具链见 [environment.json](environment.json)。

四轮整进程墙钟为 64.890、67.013、69.063、65.534 秒。两条边的搜索均值分别为
0.040774、0.061645 秒；基线 / 新增组完整验证均值分别为 4.827080 / 5.265838 秒，
新增组多验收两处完整闭包。来源捕获、搜索和完整验证分别计时；没有用局部搜索
替代全流程成本。研究没有空闲门槛，没有 allocator
峰值测量；工作量、点数或容量不能写成实际堆峰值。这些操作在路网生成研究中
执行，不在交通仿真 tick 内执行，尚未进入生产转换，不能推算产品吞吐或实时收益。
迁移成本和生产调用频率未测，不能用迁移成本抵消潜在重复执行收益。
