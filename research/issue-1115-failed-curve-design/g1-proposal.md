# 两处信号闭包恢复后的生产决策材料

**状态：Proposed；未接受生产 G1。** 继承 #1113 的固定曲线诊断和本轮
[有限几何调整设计](design.md)。ADR 0022 / 0028 / 0033 的现行权威不变。

两条失败边在保留端点、首末钳制、原成功几何、拓扑、控制锚点和现行阈值的条件下，
通过整边合段及有限控制柄调整取得真实完整候选。两处控制器的四条 / 八条关联
路径、联合编译、LFCA 后发射及控制锚点核对均通过，84 条目标接受 26 → 28。
因此不再把“真实信号闭包没有恢复正例”列为未决事实；真实多失败边同时恢复仍缺。

当前相对来源拟合筛选只说明冻结的普通 f64 双向估计没有超过原修复参考对应值。
它不提供生产绝对拟合预算、不证明真实偏离必然改善，也不构成连续硬认证。
0.01 m 采样筛选与来源拟合、规范长度及锚点语义必须继续分层；原失败边规范长度
已新生成，不能声称与源 `@length` 相同。生产设计需决定工程质量目标还是经过
数值认证的硬保证，并明确合段允许跨过哪些内部构造与道路语义位置。

建议下一研究先审计剩余 22 个缺程序分量的失败边与共享约束，选择真实多失败边
分量形成事前冻结的范围和候选族，沿用完整联合验证。不能直接把本次 148 个候选
族推广为全网策略；不能用两处单缺边成功证明多边搜索规模和全转换资源可控。
三个原跨边方向失败涉及原成功几何，继续留给独立范围判断。

正式接入还缺每边、每分量及全转换的资源和实际堆峰值边界、生产执行频率与收益，
以及与 compiler 规范几何和控制锚点关系的完整生产权威。当前实现仅在 `cfg(test)`
研究入口使用，原生产路径保持不变。完成 #1115 不关闭 #790，也不构成 LuST 全网
转换、Release assets 或端到端产品路径完成。
