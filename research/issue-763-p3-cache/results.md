# 同拍 P3 可达性缓存的采用证据

Refs #763。采用此内部优化：正确性覆盖通过，两个尺度的三组平衡整拍 mean 均为
正收益，暂存布局和已观测缓冲峰值不增长。100k 的首组基线波动较大、尾延迟尚未
证明稳定改善；本结论不构成 #707 最终预算、信号周期、长等待或长期交通质量认证。

## 独立诊断和维护成本

全窗协调器 mean ms。P2 包含发现/分发/join/规范消费，P3 Discover 只含分发发现。
P3 Fused 是回退融合的全窗摊销，不是每次融合的平均；嵌套段不可重复累加。

| ------- | ----------------- | --------: | --------------------- | ------------------ |
| 10k/1   | 0.588668→0.622446 | +0.033778 | 0.216352→0.106872     | 0.184189→0.111533  |
| 10k/2   | 1.005022→0.946669 | -0.058353 | 0.279480→0.140104     | 0.251233→0.146348  |

| 100k/1  | 8.491176→8.761372 | +0.270196 | 3.308129→1.588651     | 0.751190→0.489828  |
| 100k/2  | 8.258153→8.610688 | +0.352534 | 3.273605→1.624777     | 0.757935→0.482067  |
| 100k/3  | 7.768186→6.688383 | -1.079803 | 3.267098→1.412160     | 0.673542→0.392816  |

P2 差不是稳定正值，诊断整拍及其它未改段也存在较大运行间波动。不能据此说新增
查询让 P2 稳定变快，或把诊断整拍差直接当作净收益。新增工作是明确的同拍保守
查询；P3 发现/融合减量在三轮均可见。线程本地计数及块级归约仍有插桩成本，采用
依据使用上一节无插桩结果。

每轮全窗的总运动调用完全相同：10k 为 1_914_561，100k 为 18_897_935。保守原语
调用从 3_085_314 降到 1_905_854（10k），从 22_077_862 降到 18_762_965（100k）；
对应候选缓存命中为 3_085_314 / 22_077_862。命中可包含发现后融合的再次读取，
不代表有同样数量的独立车辆。总运动调用计数没有增加；计数不证明每次调用的
墙钟成本一致。

在此工具链和平台，两臂布局均为 `MotionCacheEntry=160`、
`WaitingPreviewEntry=144`、P2 `DispatchSlot=144`、P3 `DispatchSlot=440` 字节。
四个受影响缓存/分发缓冲的容量峰值每轮相同：

| 尺度 | MotionCache 容量 | P2 槽位容量 | P3 输入容量 | P3 槽位容量 | 四缓冲字节峰值 |
| ---- | ---------------: | ----------: | ----------: | ----------: | -------------: |
| 10k  |             7500 |        7500 |        7500 |           0 |        3120000 |
| 100k |            75000 |       75000 |       75000 |        3492 |       32736480 |

这只度量四缓冲容量，不包含整个工作区、报告内 Vec 的 backing、分配器开销或
进程 RSS。新字段不新增堆所有者；既有保留资源计账和分配退化测试通过，不能把
上表扩充成未测量的全世界内存结论。

## 正确性和交付边界

Runtime 单元测试 514 passed / 15 ignored；研究工具 14 passed。相关 all-targets
clippy、fmt 和 diff check 通过。新增与扩展用例覆盖身份/逻辑位置/Active 位毒化、
跨边零点、路线和车辆新代次、空/部分/完整缓存、失败重试、workers 1/2/4/8/16、
实际取得/跨拍持有/清空；原有 P2/P3 分配失败、首错及失败清理用例通过。
两份封存 JSON 均由 `verify` 严格复算通过。设计已回写并行和阶段协议。

本项不新增产品开关，不改变公开 API、数据格式、Adapter 或资源公式；所有实现与
研究代码为 Rust。没有追加正式长测，#707 的最终城市性能与长期质量认证仍未完成。
