## 1. 公式核对结论（维护者关键更正项，先报）

**完整 fit 计数公式 `8,448×S×C` 成立，但 S 的口径是「来源段数」而非「参考 span 数」**——
差异根源为符号双义，逐行复核 7 行全等，无需改表：

| 项 | 值 | 依据 |
| --- | --- | --- |
| 公式 | 实耗 = 反向 `2·STEPS²·S·C` + 正向 `4·STEPS·S·C` = **`8,448·S·C`** | fit 机器语义独立重算（`quality.rs`：`distance()` 每点到线段 1 单位、`STEPS=64`；反向 = W·64·(C·64)·2、正向 = C·64·W·4）；#1174 README 行 57 文档闭式同式 |
| **S** | **来源段数 = `input.points.len() − 1`** | #1174 队列 7 边全部 **5 输入点 → S=4**（冻结输入逐边核验） |
| **C** | **完整参考链弦数 = 512 × 参考 span 数** | 「逐 span cubic 513 均匀参数节点」→ 512 弦/span；s=4 行 C=2,048、s=5 行 C=2,560 |
| 逐行复核 | s=4 四行 8,448×4×2,048 = **69,206,016** ✓；s=5 三行 8,448×4×2,560 = **86,507,520** ✓ | #1174 成本表 **7 行**全部精确相等（重算值=表值；表尾注「七边全部超 32M」互证） |
| 33,792/弦 | = 8,448×**4**，只在 **S=4 来源段**时成立 | 本队列 7 边同为 S=4，故两档行同为 33,792/弦（巧合即此） |

**差异记录（108,134,400 算例——归因更正：lead 派工消息笔误，非维护者计算）**：
`8,448×5×2,560` 把 **参考 span 数 5 代入了 S**——S 应代来源段数 4（表值
86,507,520 = 8,448×4×2,560 ✓）。维护者原话口径与本结论一致（「33,792 单位/弦
只适用于来源段数 S=4、公式 8,448×S×C」）。#1174 表行标签
「s=4 边/s=5 边」的 s = **参考 span 数**，与公式 S（来源段数）同字母不同义——符号
双义为差异根源，本补章统一记法：**W = 来源段数（input.points−1）、C_ref = 完整参考
链弦数**，公式写作 `8,448·W·C_ref`；每弦单位 = `8,448·W`（W=4 时 33,792）。**通用
结论：按输入规模预留验证成本即按 W 与 C_ref 线性预留**（W 或 C_ref 更大的边，预留
同比放大；如 W=5 的边每弦 42,240）。

## 2. 可执行预算（三级生产准入上限 + 超限处置）

**总账口径**：验证成本 = 参考基准（1 次折线拟合 `8,448·W·C_ref` + 1 次曲线拟合
`8,448·W·s`）+ 每候选资格拟合（`8,448·W·C_cand`）+ 每赋值试编译（1 次编译 + LFCA）
+ 选中后终验（1 次真实联合编译 + LFCA + 锚点核对）。复核域独立计费续行（只记
consumed 不占搜索池）。

| 级别 | 生产准入上限（确定性） | 超限处置 |
| --- | --- | --- |
| **每边**（候选生成 + 资格复核） | 搜索域：划分 32,768 / 采样 32M / 拟合 32M（现值不提高）；复核域：`8,448·W·C_ref·(2+K)`（基准 2 次 + K≤8 候选）+ 每候选编译/LFCA 各 1 | 搜索域到限 = `budget_stopped`（细分计数域）+ 未访问配置记录；复核域到限 = `review_budget_stopped`、保留已完成观察、未复核候选**不入池不计资格拒绝** |
| **每分量**（赋值验证 + 联合终验） | 赋值 ≤256；试编译 ≤256 次；选中终验 1 次（联合编译+LFCA+锚点） | `assignment_budget_stopped` + 未访问赋值数；**只齐一边不记恢复**；零恢复分列保存 |
| **全转换** | 成功边全量回归（16,265 编译）+ 失败边按每边/每分量聚合上限 + 完整回归断言 | 确定性断点停止（保留已转换部分 + 未完成清单）；墙钟/内存**只作测量与验收指标**（超测量阈值告警、不触发停止） |

- 停止语义沿合同 §2.3：停止触发仅计数器到限/枚举完成两类；墙钟/内存/队列等待不
  进入判定。
- 预留公式（合同补章定值）：验证成本预留 = `8,448·W·C_ref·(2+K) + compile_budget`，
  其中 K = 保留候选数（≤8）、compile_budget = 每分量（256+1）× 编译工作量计数
  （编译/LFCA 次数口径，编译单次工作量另按 §3 待测）。

## 5. 风险与边界

- 公式为**机器语义推导 + 表逐行复核 + 机器计数器恒等式**三重验证；三者任一不符即
  停止上报，不改口径。
- 内存峰值为测量指标（不进停止判定、不作硬保证）；口径注明（进程峰值/域间增量）。
- 不改 28/84 研究结果口径；8 候选终验前不计收益；3 跨边限固定曲线对；C24 独立。
