## 0. 立场与范围

- **工程目标（接受方向）**：确定性、可复算、可验收——全部判定为有限工作量控制下
  的确定性算法输出；数值边界为**保守估计 + 观察记录**，不外推连续硬保证。
- **暂不接受生产合同**：本稿给出合同骨架与定值建议，生产 G1 接受由维护者在
  缺口（§3 待测清单）补测后组织。
- 适用面：失败边曲线/分段设计变量的候选生成、资格复核、联合验证三域
  （#1115/#1130/#1131/#1136/#1137/#1154 全部研究入口的合同口径统一）。

## 1. 质量合同四问（一次回答）

### 1.1 来源拟合允许偏差

**量化口径**（同表示基准，维护者 2026-10-30 裁定）：

- 允许偏差 = **候选折线 vs 原参考的发射折线**，同一估计函数（`quality::fit` 双向
  估计，64 区间/弦；弦近似误差项 `reference_error` 为估计组成部分），两向估计
  **分别**不劣于基准值。跨表示（折线 vs 曲线）比较为**表示伪影**，其拒绝证据保留
  不删，不作判定。
- 「不劣于旧参考」**不得单独接受**：资格 = 拟合复核 ∧ 程序位回环 ∧ 声明绑定
  （edgeEnd/机动门/信号组）∧ 联合编译终验，四面并列。**先例覆盖分列**（不外推）：
  #1154 八候选已完成**四项 8/8**（同表示拟合 / 程序位回环 / edgeEnd 绑定 /
  机动门绑定），**联合编译终验面未执行**（C24 缺七边，待执行）——先例只覆盖
  前三项面，四面定义保留但不得以 8/8 例证联合终验面。
- **独立绝对观察分层**（不替代相对筛选）：最终保留程序的规范折线→来源双向距离
  估计（64 段/弦，计入复核域）与长度清单（§1.3）如实记录。
- 已知保守方向（登记不改）：`reference_error` 弦近似误差项对参数化敏感——
  直线输入下因子≠1 的等形候选会被筛拒（#1137 差异记录）；生产若需区分「几何偏离」
  与「参数化近似误差」，属合同的数值认证选项（§5），不随本稿自动授权。

**裁定方**：研究验收由复核域独立计费的双向拟合复核裁定（§2.1）；生产验收面 =
上述四面并列 + LFCA 后发射检查。**验收面**：8 候选同表示拟合 8/8（联合验证面
待执行）、K1/K2/K1b 校准
不误杀、k2 等值锚逐值防漂移。

### 1.2 允许合段位置

- **边边界与身份固定**：边 ID、拓扑、控制器成员、停止线所在边、机动门声明不可
  因合段改写；合段只发生在**失败边内部**（design.md 变量口径）。
- **规定倒圆切点**：合段可跨（#1115 许可），但须**逐候选记录跨倒圆切点标记与
  被跨结点索引**（#1130 C06 口径；不得写成纯采样优化）。
- **内部 CR 结点**：方向扰动须显式许可声明（#1137 §2.0 口径：新增许可仅覆盖列明
  内部 CR 结点方向，其余不变量保持）；结点类型与切向来源须**实际断言**。
- **跨缝（跨边）**：边间缝位置不可移动；跨边方向判据为编译后几何（`hir/spatial.rs`
  比较编译后边界弦），三例失败属**固定曲线对属性**（§4 B4）。
- **短首段硬障碍**：在冻结常数（弦长 >0.1 m、焊接全角 ≤1.95°、每 cubic ≥2 片）
  下，合并短首段是**该证书覆盖配置 + 结点位置固定的设计变量口径内**改变必要
  条件方向的唯一在册途径（#1137 证书，保守下界 2.7804511 mm；**其他族/配置不在
  证书范围**——`affected_configs.scope` 明确排除整边不可能性，不得外推为设计
  变量空间全域结论）；合段记录不得表述为纯采样优化。

**裁定方**：合段位置合法性 = 构造期断言（结点类型/切向来源）+ 逐候选记录 +
联合编译后发射检查。**验收面**：跨倒圆切点逐候选记录齐全；停止线/机动门/信号组
绑定核对通过。

### 1.3 规范长度与控制锚点裁定方

**两端点域界定**（#1175 自决项 5，入册）：程序位（f64 位）与 canonical f32 规范
端点**分属两域**——程序位可验（位级回环）；canonical f32 端点属**发射/编译域**
（编译后规范多段线），随联合编译终验执行。

- **规范长度裁定方 = compiler**：长度由现行 compiler 推导和验收（`length_mm`）；
  长度清单（#1115 口径）：来源 `@length`、来源 shape 折线、原/新参考弧长（4096
  区间弦长/控制多边形）、规范 f32 弦长累计、compiler `length_mm` 及差值，逐项
  分列；失败边新规范长度**不**声称等同 `@length`；禁止比例缩放或重写源长度。
- **控制锚点裁定方 = compiler + LFCA 后发射检查**：停止线 `edgeEnd` 解析与边绑定、
  机动门路径/转换下标、信号组绑定逐项核对（#1154 四项 8/8 分列中的声明绑定项：
  edgeEnd 绑定 8/8、机动门绑定 8/8；**联合编译终验面待执行**）；原成功边的
  停止线几何保持原样逐字节对照。
- **验收面**：联合编译终验（编译/LFCA/编译后长度/规范端点/联合锚点）——
  canonical f32 端点核对**只**在该终验内执行（依赖清单口径）。

### 1.4 资源停止与失败规则

- **确定性工作量控制算法停止**：全部停止条件为计数器到限或枚举完成
  （partitions/sampling/fit/assignment/dedup 见 §2）；**墙钟与内存永不触发停止**，
  只作测量与验收指标（§3 基线）。
- **失败语义分列**（可执行、可验收；不合并表述）：
  `backtracking_rejected` / `source_fit_rejected` / `no_complete_program` /
  `sink_rejected`（子原因 `degenerate_chord` / `weld_turn`）/ `budget_stopped`
  （细分数值域）/ `compile_rejected` / `missing_real_programs` /
  `not_executed`（验证未执行**不**混入几何拒绝，#1154 口径）/ 预分类标签
  （`skipped_old_family_overlap` 等，零预算）。
- 停止记录：实际访问数与配置序号、停止原因、未完成观察（`observation_incomplete`）
  保留；零恢复/族耗尽/预算停止/未决**分列保存**，均不作无解证明。

## 2. 资源合同

### 2.1 三域预算（候选生成 / 资格复核 / 联合验证）

| 域 | 计数器 | 每单位量纲 | 现值（不提高） | 计费规则 |
| --- | --- | --- | --- | --- |
| 候选生成（搜索域） | 划分尝试 | 次 | 32,768/边 | 每边共享，先到即停 |
| 候选生成 | 采样工作 | 计数（点求值+切向+控制差） | 32,000,000/边 | 同上 |
| 候选生成 | 来源拟合评估 | 点到线段次数 | 32,000,000/边 | 同上；参考拟合计入 |
| 资格复核（复核域） | 双向拟合复核 | 评估次数/单位 | **参考基准 ≈ 全参考链弦数 × 33,792 单位/弦**（s=4 边 2,048 弦 → 69,206,016；s=5 边 2,560 弦 → 86,507,520，#1174 入库成本表两点精确线性） | **只记 consumed 不占搜索池**（lead B 案）；不截断验证算量 |
| 资格复核 | 编译/LFCA 次数 | 次/候选 | 编译·LFCA 各 8 次（#1154 资格层独立编译计数，**非联合终验**；联合终验面待执行） | 同上 |
| 联合验证（验收域） | 赋值枚举 | 次/分量 | 256/分量 | 到限记 `assignment_budget_stopped` + 未访问数 |
| 联合验证 | 联合编译终验 | 次/赋值（选中） | 1 次/分量 | 编译/LFCA/长度/端点/锚点一次终验 |

- **复核域独立计费**（lead B 案入档）：验收层双向拟合/编译/LFCA/锚点计数单列、
  不与搜索域三计数器混列；实耗参考：#1154 八候选复核域 102 次 fit / 5,828,385,024
  单位（8 候选，单边）；**每边参考基准实耗定值**（出处绑定：#1174 入库 README
  成本表 + Release `research-evidence-1174-single-edge-reuse` 重跑版 `d6e9c388…`，
  完整参考链修正后终值）：s=4 边 69,206,016 单位 / s=5 边 86,507,520 单位，两点
  均满足 **弦数 × 33,792 单位/弦** 精确线性（2,048/2,560 弦；`reference_with_curve_cap`
  全 span 重建口径，#1180 P2-2 修正后）；**17M–69M 旧带为截断参考（`replay_span_controls`
  失败前缀）旧值，已作废不引用**。每弦 33,792 单位的公式在 s=4/s=5 两点验证成立，
  其他弦数形状的线性外推入待测清单。
- 每边其余上限（不变）：临时程序 96s+1 点、每 cubic ≤96 片、保留池 ≤8（+既有
  候选不占名额）、去重键 ≤262,144 点、报告行 ≤ 实际访问配置数。

### 2.2 每边 / 每分量 / 全转换预算与失败语义

- **每边**（候选生成）：上表三计数器共享先到即停；失败语义 = §1.4 分列 + 未访问
  配置记录。参考实耗（不作上限）：C17 edge6 27.37M 拟合/15,960 划分（542 配置
  完成无预算停止）；C06/C08 边 3.3M–32M（`--30306#2_0` 拟合预算停止于 80/148）。
- **每分量**（联合验证）：赋值 256 + 一次真实联合编译终验；失败语义：齐备接受 /
  `missing_real_programs`（不齐备，如实）/ `assignment_budget_stopped`（+未访问
  数 = 总赋值 − 已试次数）；只齐一边**不**记分量恢复。
- **全转换**：验收面 = 完整回归逐行一致（84 目标/53 分量/183 关联路径/16,265
  成功边/8,230 失败诊断 vs #1105 基线）+ 四轮 ABBA 非计时输出逐字节 + 结果 JSON
  禁计时；资源测量基线（§3）为验收指标，不设停止语义。

### 2.3 确定性工作量控制停止口径

停止触发**只有**两类：① 计数器到限（budget_stopped，细分数值域）；② 枚举完成
（completed_finite_family / 去重完成）。墙钟、内存、队列等待、主机负载**一律不**
进入停止判定；测量口径（#1113 先例）：原始计时/条件/无空闲门槛注明/描述性限定。
