## A4 核心义务一览

- **P4 约束所有潜在进入者**：不得只查拍初过渡区为空；纳入源/目标车道接近
  车辆的**可达范围与制动约束**，任一无法证明安全 → no-grant、换道车
  `sl-t01` 前等待（证明责任在申请侧）。
- **P5 无门不豁免**：普通直行含无门 hop 遵守当拍预约；`tick.rs:4528`
  `hop_gate_permitted` 的 `None => true` 现状为设计义务起点，非缺陷认定。
- **双保险**：P4 申请侧证明 + P5 全体遵守，缺一不得放行。
- **跨拍安全证明**：`MotionReach` 仅为本拍位移上界，当拍跳过查询不免除预约
  存续期义务（每拍重证）；准入依据具名四项（停止距离公式 / 反应窗口 /
  最小间距 / 后续各拍保持条件），制动参数取 profile 具名值。
- 预约生命周期四态：requested → staged → committed（P7 原子提交）→
  released（`rear >= clearance` 车尾清空）；**未进入撤销分支**：P4 授予后
  P5 未实际 crossing → 整份 bundle 到期、不建预约。
- 读写关系（P3/P4/P5/P7 读写集）在合同 §5.4 表格冻结。
