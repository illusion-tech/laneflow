# P5 成本归因与下一候选

Refs #772、#707。优先验证 **P5 按同拍 Active 投影直接分发，减少输入三元组暂存和
车辆状态复制**。这是待实现与 A/B 验证的候选，不是已获得的性能收益。本项只合入
Rust 研究工具及证据，未修改正式 Runtime。

## 下一实现切片

仅选择 P5 输入减量：现有 `motion_inputs` 为 `(handle, active_index, VehicleState)`
三元组，协调器先读取并复制全部状态，工作线程再复制三元组后求值。
候选直接按同一 C(T) 的 Active 投影分发，在任务中做代次感知的状态读取，避免
每拍生成输入状态副本；继续使用独占结果槽位、完整 join 和规范消费。
本次没有实现该方案，收益和额外访存代价都未知。

实现前单独冻结阶段合同，并验证：

- Active 投影含缺失槽、旧代次、同槽新代次时，仍使用完整句柄读取；原跳过谓词
  与 `active_index` 对 Waiting/Conflict 缓存的含义保留，不能因去掉紧凑输入而错位。
- 结果槽位 `Skipped/Pending/Done`、首错前沿和 join 后消费闭合；失败不提交，重试
  不残留旧结果。缺失状态不能被误报为成功计算或领域失败。
- 近门、跨边零点/carry、路线/停车预留变化、Waiting/Conflict 持有与释放、完整
  MotionReuseKey、可选预留失败后的融合回退不退化；不省略资源处理与领域求值。
- workers 1/2/4/8/16、阈值两侧、空/部分输入、分配故障和失败/重试覆盖。
- 两尺度至少三组无插桩平衡 A/B，另作诊断统计输入/输出暂存、分发与消费成本。
  不能以少一次复制代替净性能测量；收益与本批波动不分离或尺度回归则调整/淘汰。

长测只用于具体未闭合风险，不自动追加 44544/100k 正式计划。
这个候选不改变跟驰模型；若以后需要模型近似应另立可接受行为误差的设计切片。
