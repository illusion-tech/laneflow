## 3. 注入形态与遍历序（冻结）

- **注入形态（唯一执行形态）**：首弦网格 = `[0, t] + 原 513 网格中 >t 节点`（**移除 ≤t 旧节点**，`InjectionKind::FirstChord` 现行实现逐字一致）；末弦对称（`<t 节点 + t + 1`）。**不强制见证弦**（`graph::paths_on` 枚举全部 `i<j` 节点对）。
- **纯并集形态本轮不执行**；如统筹要求探索，以单列变体执行并**独立记账**（不混入上表网格工作池的消耗口径），另行报告。
- **遍历序（统筹裁决修正版）**：见证按清单序（47 项冻结序）→ 每见证按注入变体序（首弦形态 → 末弦形态，各至多一次、上限清单×2）→ **每次搜索内族序（等 t 划分族先于切向角划分族，旧实现口径）** → 程序枚举 n 升序（现行图搜索自然序，报告记实际 n 序）。同边多见证**只按清单序**，不加任何见证排序规则。
- 每见证记录：注入命中（`witness_injection_records`）、见证弦尝试/合格/入返回路径/入选中路径三值证据（沿 §3.6 口径，not_recorded 不归并）。**注入控制点**：运行时经共享三层载体链解析完整六点（`injection_control`，含 `dir_a`/`dir_b`），与清单绑定 `control_f64_bits` 交叉核对前四点一致（`replay_agrees` 口径）；不一致即 §6 停止。

## 4. 候选资格验证与验收分层（冻结）

判据仅现行口径：量化弦长下限 0.099999 m 与实际施加方向检查（0.0341 sink 正切上界仅排除余量）；**见证接受用实际长度 / sink 转角 / 0.01 m 筛选**（不引用排除余量反向充当接受阈值）。

- **(a) 整边候选入池（主目标）**：注入变体搜索产出的候选经判定链全量验证（搜索内实际长度/sink 转角/0.01 m 筛选 + **双向拟合**/编译/LFCA/控制锚点）后入**本轮新增池**；**不回写标准族池**、不与标准族候选混池记账；按边分列报告资格验证通过/拒绝及拒绝阶段。**双向拟合口径修订（维护者裁定 2026-10-30，B 同表示基准）**：冻结口径「`quality::fit` 双向估计 ≤ 原参考同算法值」在折线原生候选下欠规定，裁定解释为**候选折线 vs 原参考的发射折线**（同一估计函数、同表示公平比较，与 #1107/#1111 折线对折线传统一致），"不劣于原参考"按此执行；原跨表示（折线 vs 曲线）8/8 拒绝作为**表示伪影证据保留**（不删），同表示复算**只重跑 (a) 列、不重跑搜索**（8 份候选几何证据外置直接复算）。计费为复核域独立计费（lead 裁决），复核域计数器单独报出。
- **(b) 停止线核对**：沿 D 路三情形口径逐边产出；情形 2（恢复停止线）须真实联合编译/LFCA/编译后长度/`edgeEnd` 解析/机动门绑定五项证据；**依赖不齐时联合检查记「未执行」，与几何拒绝分列**。
- **(c) 分量接受分列**：候选齐备分量才执行联合赋值（沿 #1121 §4）；接受结果与 (a)(b) 分列。
- 「未执行」专列：凡依赖（候选齐备/联合编译前置）不满足而未执行的检查，逐项记 `not_executed` + 原因，**不混入几何拒绝统计**。
