## 1. S1：展开器过渡感知扩展（converter）

### 1.1 目标与语义

让路线展开在**声明的过渡材料存在**时跨越过渡完成物化；材料不存在时行为与现状
严格一致（`can_complete` / `materialize_path` 成功条件仅在声明边界处扩展）。

- **过渡声明输入**（消费 g1-decision-chapter 可自决项 S2 的跨层合同第 4 项）：
  来源 lane 对 + 过渡边界（整边界锚点）+ 最终边链（如 `T01`）+ 许可依据引用。
- **展开语义**：搜索状态"当前来源 lane"仅在声明边界处按声明转移；其余位置保持
  `from_lane == 到达 lane` 的严格语义。声明边界之外的任何 lane 转移仍失败关闭。
- **物化**：跨越过渡的最终边链按完整 `ManeuverPath` 对应展开（如
  `[A0, I1, B0_up, T01, B1_down, I2, C0]`）；无材料处 `lane-continuity-gap`
  的错误定位、可达集合/所需 lane 对输出与阶段分域**不变**。
- **人口合同不变**：选取/排序/截断/绑定、`routes.toml` schema（lane id 序列）、
  目录归一化与失败记录处置（不删、不补位、不跳过）全部保持。

### 1.2 契约同步（随 G1）

`real-road-workloads.md` §3.1 车道级展开条款随 G1 修订：「禁止边内换道」→
「仅在声明过渡材料处允许来源 lane 转移（转移只消费声明的最终边链，不产生
横向转移）」。其余 §3.1 条款（来源映射、稳定顺序、fatal error 面）不动。

### 1.3 A0/A1 测试等值要求（硬性）

1. **逐项语义等值**：A0 五组测试 + 修订后诊断测试 + A1 十组测试全部原样通过
   （真实反例、连续对照、来源错误分域、人口身份/顺序/绑定、重复构建确定性、
   六类诊断分类与逐记录定位）。
2. **等值口径**：旧入口、旧输入、既有结论不变（协调章程 §2 共享改动行为等值
   范围同款）；任何既有断言的改动必须单列理由并经审阅，不得以"顺手更新"混入。
3. **新增只增不改**：样本 `s1` 三拓扑（gap / continuous-control / transition）
   与「无声明即转移」负例为新增验收输入；不修改 A0/A1 夹具钉版值。

### 1.4 验收

- **接受**：样本 `s1` 三拓扑成立（gap `lane-continuity-gap` 失败关闭且无
  lane-continuous 替代路线；continuous-control 物化 lane-0 连续链；transition
  物化跨过渡链）；A0/A1 全部测试等值通过；负例分域不变（unknown lane/road、
  DUE internal edge、缺失道路 hop 各留原错误域）。
- **必须拒绝/不得误判**：任意 `Err` 冒充阶段断言；在无声明边界改 lane 成功；
  把 unknown/internal 引用归类为换道缺口；跳过失败人口或候选尾部补位；改写
  既有断言使测试"变绿"。
- **明确不做**：自由在线选道、任意位置转移、活动车改 Route、`ResolvedLanePlan`；
  不改人口选取/排序/截断/绑定；不改 `routes.toml` schema。

## 2. S3：过渡材料化与静态发射（compiler / authoring）

### 2.1 目标与范围

让合成编制输入（或道路编辑来源）能声明「双车道路段 + 固定预制过渡」，经唯一
最终权威拓扑发射静态制品，供 S1 展开与运行时消费。

1. **来源保真**（裁决口径）：`T01` 若为经授权规则派生的编制材料，保存来源
   映射与构造依据，**不得冒充原 SUMO connection**；合成来源为原生声明，
   标注 `sourceLanguage` 现行登记值；身份按逐修订身份 + 文档化映射登记。
2. **必要分段与锚点**：`B-up`/`TZ`/`B-down` 按 lane 纵向共延伸同切两 lane；
   `T01` 连续几何 + 明确边界 + 整数毫米最终长度；`sl-t01` 进入点停止线与 J2
   门/停止线（`sl0/g0`、`sl2/g2`）重绑到最终边（不沿用旧 gate index、不按
   百分比搬移）；边界不足或重叠失败关闭。
3. **单一最终权威拓扑**：一份归一化输出同时供路线展开与静态发射消费（不发布
   两份拓扑）；LFCA/`SharedNetworkRevision`/`NetworkRevisionId`/digest 与
   合同版本随同一修订产出；编译器仍不预编译路线（ADR 0029）。
4. **几何发射预算实测口径**（A1 失败教训内建，见 §2.2）。

### 2.2 几何发射预算实测口径

1. **实测条件**：以样本 `network` 钉版几何（`T01` chord ≈ 9.487 m 缓斜、`I2`
   chord ≈ 6.708 m）在**冻结提交 + 固定工具链（Rust 1.99.1）+ 全新输出目录**
   实测发射，逐边记录结果；实测属于 S3 实现切片执行期义务，本 G1 材料只冻结
   口径。
2. **失败处置（A1 口径）**：逐字保留发射器错误原文（参照 A1 的
   `repaired curve sampling exhausted … curvature is infeasible under the
   quantized weld budget` 实例），归类为**独立几何问题**；不得修绿几何代码、
   不得提高预算、不得改写为路线物化失败、不得静默改钉版几何。
3. **改几何须走样本版本**：若确需调整钉版几何，`minimal-closed-loop.json`
   `meta.version` 递增 + changelog 说明理由，另行审阅；不得在实现中就地改值。
4. **成功判据**：发射通过且**预算零放宽**；逐边结果与整数毫米长度入证据档。

### 2.3 验收

- **接受**：样本 `network` 发射通过（预算零放宽）；`s1` 三拓扑在最终拓扑上
  成立；过渡路线与直行路线经 `register_route` 注册成功（静态序列合同：完整
  ManeuverPath 匹配、内部边覆盖、首末边/StopLine 规则、hop 区间不相交）；
  锚点绑定与跨层合同六项逐项一致（身份=逐修订身份 + 文档化映射；许可引
  AccessRule 权威；修订/制品锚定 ADR 0025/0033）。
- **必须拒绝**：伪造来源（派生材料冒充原 SUMO connection）；缺失/歧义/绑错边
  的锚点；边界不足或重叠的过渡；旧修订证据复用；放宽预算混过；只比较
  `NetworkRevisionId` 而需同一 `Arc` 的场合。
- **明确不做**：不改生产采样与阈值；不改 LuST pinned 基线的成功几何/拓扑/
  锚点；不实现 #237 运行时安全（S4 职责）。

## 3. 依赖与接口

- **S2 G1 输出为 S1/S3 前置**（裁决顺序：先最小合同、再并行展开器与过渡
  材料化）：S1 消费过渡声明输入契约（D1/D2）；S3 消费承载形式与身份口径（D1）、
  占用映射对象（D2）；执行能力检查按 g1-decision-chapter 可自决项 S3 的定位
  执行（能力声明位置若经裁决调整，S1/S3 文本随之更新）。
- **#790 汇合**：拆边/边界与最终拓扑汇合到同一修订后才落地；不预设 #790 结果。
- **跨层合同**：六项共同输入按 route-design §3.4（附条件）转正式契约，缺保证
  记生产 G1 缺口清单（见 g1-decision-chapter §4）。
