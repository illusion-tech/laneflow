# P3 合入后的剩余热点与下一切片

2026-09-26。Refs #762、#707。下一实现候选：[#763 同拍 P3 可达性结果复用](https://github.com/illusion-tech/laneflow/issues/763)。

**选择缩短 P3 协调器发现与筛选作为下一有界实现候选。** 尝试在 P2 的独立计算中
生成同拍可达性结果，P3 按完整身份复用；缓存不足时仍用同一原语。这里选择的是待验证
候选，没有实现该优化，也没有证明它有净收益。Runtime/API、数据格式和 Adapter 均未改变。

## 冲突准备细分

以下是独立追加三次诊断的均值范围，不与首轮逐拍相减。所有子段在 ConflictPrepare 内；
不得把子段与父段再相加。

| 子段                         | 三轮均值范围 ms |
| ---------------------------- | --------------: |
| Frontier                     |     3.499–3.572 |
| P3 输入发现与筛选            |     2.571–2.646 |
| P3 并行求值及 join           |     0.712–0.738 |
| P3 规范消费                  |     0.311–0.329 |
| P3 融合回退                  |     0.532–0.556 |
| P3 尾部预留与排序            |     0.185–0.190 |
| P4 联合裁决                  |     0.516–0.532 |
| 父段剩余（清理、槽位准备等） |     0.491–0.499 |

每次统计窗口的筛选工作集均为 **846–3423**；192 拍中 **163 拍分发、29 拍融合回退**。
低于 1024 后重新扫描确实发生，但不是每拍；融合回退的表中时间是按全窗口摊销，不能
当成单次回退耗时。P4 也不是当前最主要成本，不能据此启动 P4 组件并行。

输入发现段包括 live 遍历、身份/状态读取、reservation 查询、Gate 可达性、序号转换与
选中状态复制；本轮没有再分开这些子项。因此 **2.57–2.65 ms 不是已测得的可节省时间**，
尤其不能宣称缓存能节省整段。Frontier 仍然更大，但涉及已发布近门名单、
失效与 cell 关系维护；本轮选择已有同拍缓存可承接的局部重复计算，限制下一实现范围。

## 下一实现的验收

#763 保持候选集合、1024 阈值、资源持有/释放及规范次序。只保留一个保守可达性原语，
缓存绑定完整句柄和代次、逻辑更新位置、Active 紧凑位以及同一 C(T)。缺失/部分缓存或
容量退化都必须回到该原语；不维护跨拍第二份近门权威。

验证近门/跨边/未知运动域、已有 reservation、同槽新代次、路线变化、空/部分缓存、
可选分配退化、失败与重试、workers 1/2/4/8/16。检查 cache/preview/槽位大小和暂存峰值。
无插桩 10k/100k 至少三组平衡 A/B，单列 P2 增量与 P3 减量，最终按整拍 mean/p95 判定：
净收益不能与本批波动分离，或另一规模明确回归，就淘汰或调整。局部降幅不替代采用证据。

## 验证与保留边界

- 15 次进程均成功，首轮各规模六次交通日志和 result 语义一致，细分三次交通日志也与
  原无插桩 100k 一致。原生 Harness 对 10k、100k、细分三组代表性比较均为 `probe-match`。
- 所有阶段次数、非负残差、嵌套关系与分发/融合阈值关系通过；逐拍时钟重新计算的
  p50/p95/p99 与原生 diagnostics 一致。原生文件摘要全部核验。
- Python 正常模式与 `-O` 下各 8 项分析器测试通过；三份 release 程序构建成功。
  研究未修改正式 Rust 源码，未额外重跑整个 Runtime 测试矩阵；适用仓库 CI 由 PR 承担。
- 第一次细分准备因匹配位置不唯一被拒绝，未执行测量；失败导出及空输出目录保留为
  `target/hotspot-detail-anchor-failed`、`target/hotspot-detail-runs-anchor-failed`，不属于 15 次矩阵。
  首次尝试共用构建目录导致两臂得到相同二进制，也在测量前检出并以独立目录重建；无此类运行混入。
- 紧凑证据为 `evidence/results.json`、`evidence/detail-results.json` 及原生比较报告；外部
  原始包为 `target/hotspot-runs`、`target/hotspot-detail-runs`，含逐文件大小/SHA-256 索引。
  索引不是原始包，远程复核需另提供包；验证模式拒绝差异且不重写已发布结果。
- 本项未测试长期停车/回流质量、稳定 100k Active、worker 扩展性或最终 2/16 ms 预算。
  没有新增需要长测才能回答的风险；#707 最终性能认证继续独立处理。
