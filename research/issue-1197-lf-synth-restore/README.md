## 保存、恢复与比较

令 `W` 为预热拍数：16 ms 为 14508，33 ms 为 7044。W1/W2 在 `W` 与 `2W`
已观察后保存，终点为 `3W`。W3 在 `W+1` 首批 atomic replacement 命令前后、
下一次 step 前分别保存，终点也为 `3W`；两个检查点 tick 相同，宿主阶段不同。
W4 在 `W` 的 B0 命令前、以及 `W+1` 的 B0 成功并消费观测后保存，终点为
B1 完成后的 `W+2`。

每个检查点包含实际 LFRS 文件和单独的宿主记录。宿主记录绑定路线/车辆的逻辑
身份、快照局部 ID、live 顺序、逻辑代次、命令/事件边界、累计观测、pending 原命令
和停车阶段。它不把旧进程句柄写成耐久身份，也不把宿主状态冒充 Runtime 快照内容。
W3 命令前检查点的待重试命令分别为 100/1000 条，命令后为零；对应命令游标
分别从 10700 到 10800、从 107000 到 108000。

每次恢复均从新进程重新读取并验证正式输入、构建共享路网修订，以存档绑定的
独立 Published 来源期望执行认证；只有 `Pass` 才调用 `restore_lfrs`。恢复端显式
传递并复核实际 worker，按恢复映射重建宿主身份，核对完整路线/车辆归属、live
顺序、停车绑定、规范状态摘要、时钟与命令/事件游标。没有通过重新安装世界并
重放初始化命令代替恢复，也没有改变生产 Runtime API、LFRS/LFCA 或交通规则。

恢复建立无旧基线的新观测 session，最新事件批次为空。从下一成功拍起，精确
比较到参考原终点的公开轨迹、有序事件、`StepOutcome` 的 tick/time 与停车到达，
以及剩余生命周期命令收据和批次。命令前检查点执行尚未提交的批次；命令后
检查点跳过已提交批次。比较前校验起止边界、宿主阶段、准确记录数量、文件头和
完整长度，不以共同前缀判相等。每 1024 拍与最终边界的规范状态摘要、最终宿主
累计记录也全部相等；逐拍公开轨迹不扩展为每拍全部内部状态证明。

独立 PowerShell 文件复核重新解析连续 tick、事件长度及保存点偏移，重算文件
SHA-256，并分别验证轨迹、事件、命令收据的完整后缀、命令批次与状态检查点。
它还确认八个参考和 240 次恢复的身份集合与预定矩阵相等，排除重复或缺项。
这是一条独立文件复核路径，不是独立产品审阅；实际 LFRS 解码由上述新进程执行。
SHA-256 沿用 ADR 0033 的互操作摘要角色，内部 BLAKE3 编码不变。

## 复现与材料边界

从冻结标签的干净独立检出构建并先跑探针，再运行正式矩阵：

```text
cargo +1.99.1 build --release --locked -p laneflow-synth-harness --bin laneflow-synth-harness
laneflow-synth-harness restore-probe <generator-matrix-root> 5b4ab48c26c08970bd187e6e0f31bb5ee38f7633 <environment.json> <evidence-root>/new-probe
laneflow-synth-harness restore-matrix <generator-matrix-root> 5b4ab48c26c08970bd187e6e0f31bb5ee38f7633 <environment.json> <evidence-root>/new-matrix
```

受检输入、环境声明、单次恢复命令与编码规则见
[工具 README](../../tools/laneflow-synth-harness/README.md) 和
[执行设计 §9](../../docs/design/lf-synth-execution.md#9-标称矩阵的快照恢复与继续运行)。
输入包使用上述冻结生成提交；输出目录必须全新。首错停止新启动并保留已启动
材料，不以补跑或拼接完成同一矩阵。

仓库只保留实现、复现合同、本报告与小型摘要。F3 的完整探针/正式回执、快照、
宿主记录、轨迹、事件、日志、环境、复核材料及二进制保存在采集机仓库外；原件与
副本各 2,097 个文件、4,599,658,393 字节，逐文件长度和 SHA-256 核对一致。
原始字节未重新序列化或用重跑替换。副本位于同机同卷，不构成异机灾备；这些
本地材料也不是团队下载入口，不新增外部发布或长期恢复承诺。原件复核需由
材料保管方提供实际访问方式。

## 覆盖边界

W1/W2 的观察中段保存点具有非空最新转换事件：一万规模分别为 4/8 条，十万规模
分别为 30/60 条。恢复后这些旧批次不复活、不重复消费，后续完整后缀仍与参考
一致。所有保存点当拍的停车到达数组为空；非空停车到达顺序的覆盖来自 W3 的
继续运行后缀，每次分别为 100/1000 条，两检查点、五档 worker、三轮合计
33,000 条比较记录。

本次只覆盖同实现、同正式输入的标称保存与恢复，保存端为单 worker。它包含已有
路线表恢复，不执行 Routing 规划；不证明 worker 两两组合、跨修订或 Editable
来源、旧格式兼容、Spatial/Adapter 跨 worker 接线、全部故障点、强制调度置换、
性能或完整五轴认证。三轮重复不等于穷尽调度。
