# 四车批量布局与 IIDM SIMD：停止本轮接入

对应 #805。本轮完成了采集前冻结的全部 36 个进程；三臂交通结果及逐拍状态摘要一致，
但批量布局和 SIMD 候选都使整步变慢。十万规模筛选窗 SIMD 相对基线均值增加
**3.897%**，三组均回退；一万规模均值增加 **10.313%**、平均进程 p95 增加
**6.570%**。`continue_candidate=false`。不把这版候选接入正式 Runtime，也不为它
追加正式长窗。这个结论只适用于本轮四车暂存与 IIDM 实现，不能排除其他 SIMD 设计。

## 实验边界与来源

- 正式基线：`fcd803f2cb28ba7a94f3f0ff589e7e9b7bdbd7d3`。
- 实际采集器及导出补丁源码：`f47ec71f480f5a401a7ff263317aac8ac1529698`；报告随后提交。
- 三臂：A=`base`，原 P5；B=`layout`，四车批量标量；C=`candidate`，同布局显式 SIMD。
- AMD Ryzen 9 9955HX，16 核 / 32 逻辑处理器；Windows x64 MSVC，Rust 1.98.0，
  workers=4。普通 release、locked/offline，默认目标特性；无全局 AVX2、fast-math 或 FMA。
- 使用已冻结 MIXED-PEAK 输入，seed 544；一万总车辆初始 7500 Active / 2500 Parked、
  固定步长 16 ms；十万总车辆初始 75000 Active / 25000 Parked、固定步长 33 ms。
- 每规模三组六进程，依次 `ABC CBA`、`BCA ACB`、`CAB BAC`；每臂每规模六进程。
  三个构建与 Runtime 回归结束后串行采集。每进程 256 拍，无预热；全窗 1–256、
  进入窗 1–64、筛选窗 65–256 分列。先求每进程均值和 nearest-rank p95，再平均进程统计。
- 四车输入和 Motion 准备数据仅在工作块栈上暂存，未改成持久热字段 SoA。
  保留完整句柄、预览复用、规范首错与成功值前缀、完整 join、停车真实预留和原子提交。
  融合执行与 Waiting 预览继续走标量原语。正式 Runtime 源码及 manifest 没有变化。

## 内核诊断与暂存成本

独立 IIDM 诊断在采集完成后执行一次。一个进程内三组轮转，每条计时 409600 辆计算；
批量输入已在计时前收集，**不包含数据收集、Motion 准备、join 或提交**。
它同时比较了验证位置不同的实现，不能将差值全部归因于 SIMD 算术。

| 实现            | 三条计时平均 ns / 辆 |
| --------------- | -------------------- |
| 原逐车标量      | 9.232422             |
| 预收集批量标量  | 4.406657             |
| 预收集显式 SIMD | 7.851400             |

九条原始计时全部保留，摘要均为 `787082915329000`。原标量第一条 4.513600 ms，
后两条 3.415000 / 3.416200 ms；这是很短的单进程诊断，不作为稳定吞吐或整步收益证据。
候选 `IidmBatch::simd` 汇编确实含 `divps` / `mulps` 等 packed 算术；
布局 `IidmBatch::scalar` 的对应函数仅见 `divss` / `mulss` 等标量算术，未见 packed
算术向量化。完整汇编与函数片段已封存。

实际 `size_of`：`IidmInput` 40 字节、`IidmBatch` 276 字节、
`PreparedActiveMotion` 328 字节、`PreparedVehicleMotion` 368 字节。
四个准备值本身为 1472 字节，此外还有输入、结果和其他局部量；这不是实际栈峰值测量。
本轮未新增逐批堆分配，也未证明内存峰值改善。

仅批量标量臂已经回退，说明这版分阶段与暂存改造没有获得整步收益。
额外准备、复制、函数边界或验证可能抵消算术收益，这是待进一步分解的解释；
本轮没有测量各子阶段增量，不能给其中一项分配精确责任。

## 后续取舍

停止本轮 P5 四车暂存接入。下一项研究优先检查 ConflictPrepare 的重复扫描与工作集
收敛，先确认可减少的遍历和准备成本，再做整步对照。若以后重启 SIMD，应另行冻结
持久热字段布局或更大算术块的范围，并把数据维护成本计入整步。本次没有执行这些
后续设计，也没有完成 #707 的正式性能认证。
