# 最小闭环样本（合成 / 钉版输入）

**状态**: 设计材料（`minimal-closed-loop.json` v1）；不是运行结果，不构成执行结论
**关联**: [设计方案](../design.md)、[实现切片与验收计划](../slice-plan.md)、
Issue #1142 / #806 / #237

## 1. 定位

本目录钉版 Issue #1142 要求的「最小闭环样本（合成/钉版输入）」：一个双车道路段
+ 固定预制过渡（`T01`）+ 四角色受控输入 + 下游信号化路口的最小执行闭环，覆盖
设计方案 §2.3 子合同 4–8 与验收矩阵（反例与对照、单车与位姿、目标与源车道安全、
同拍与多车、车尾与下游、持久化与确定性、结构负例）。

样本同时钉住设计边界本身（scenario `s1-materialization-boundary`）：

- **有过渡材料**：道路级需求 `A B C` 物化为
  `[A0, I1, B0_up, T01, B1_down, I2, C0]`——展开器只是**消费**真实存在的过渡边；
- **无过渡材料**：同一需求在 `B→C` 处 `lane-continuity-gap` 失败关闭（可达
  `{0}`、所需 `{1}`）——展开器**不产生**横向转移。

这正是「路线展开负责找到并物化、#237 最小换道负责证明可执行」的可观察判据。

## 3. 拓扑

```text
        J1                        过渡区 TZ                      J2
A0 ── I1 ──┬── B0_up ──┬── S00 ──┬── B0_down ── I0 ──┬── C0 ── R0 ─┐
           │          └─ T01 ───┘                   │             │
           └── B1_up ──── S11 ──── B1_down ── I2 ──┘             │
      （P1）        （固定预制过渡 0→1）     （P0/P2，sl/g2 信号门）  └─→ A0（显式回环）
```

- `B` 段按真实过渡边界必要分段：`B-up`（`B0_up`/`B1_up`）→ `TZ`（`S00`/`S11`/`T01`）
  → `B-down`（`B0_down`/`B1_down`）；同 section 两 lane 纵向共延伸。
- 直行流 `B0_up→S00→B0_down`、`B1_up→S11→B1_down` 保持原车道连续流（普通
  successor，无新增门）；只有 `T01` 承载 #237 最小子合同。
- `R0` 为合成回环返回边，仅服务 `s9-repeated-occurrence`；显式回环合法
  （`route-system.md` D3）。

## 4. 钉版规则

1. **坐标**：canonical 米制 `(x, z)`，精确十进制；语义对齐
   `real-road-workloads.md` §3.2 canonical frame（本样本是合成网络，不挂
   LuST `frameId`）。
2. **长度/速度**：长度整数毫米（编译提交权威），速度 mm/s；米制坐标只是编制
   输入。`T01` chord ≈ 9.487 m（9487 mm）、`I2` chord ≈ 6.708 m（6708 mm）为
   量化后的钉版值。
3. **确定性**：场景只描述输入与期望，不含计时字段；同拍裁决期望写「稳定顺序」，
   不指定具体排序实现。
4. **可表达性分级**：每组期望标注
   `route-expansion-today` / `registration-today` / `needs-237-subcontract` /
   `needs-g1`（见 JSON `meta.expressibility_legend`）。今天的工具链只能验证
   前两级；标记为 `needs-237-subcontract` 的断言是后续实现切片的验收输入，
   **不得**在能力落地前宣称通过或不适用。

## 5. 与 A0/A1 夹具的关系

- **拓扑同构**：A(1 lane)–B(2 lanes)–C(1 lane)，`P1=[A0,I1,B0]`、
  `P2=[B1,I2,C0]`、连续对照 `P0=[B0,I0,C0]`，与 A0/A1 夹具一致，便于对拍
  缺口/连续语义。
- **几何差异（有意为之）**：A1 实测连续夹具在几何修复阶段失败——
  `span 1/1 (chord 5.0000 m) is not emittable: … 2 pieces (chord floor) each
  turn 3.75 deg > 1.90 deg`（`kimi-806-a1/report.md` §5）。本样本因此改用发射
  友好几何（过渡段 9 m 缓斜 ≈ 18.4°、J2 内部边 6 m ≈ 26.6°），不沿用 5 m
  陡斜内部边。该差异是样本设计输入，不是对 A0/A1 证据的修改。
- **分段差异**：A0/A1 的 `B0`/`B1` 整段边在本样本按过渡边界拆为
  `*_up/TZ/*_down`；展开对照时以「来源 lane 0/1」语义对齐，不以边名对齐。

## 6. 已知风险与使用约束

1. **几何发射未验证**：样本几何按发射预算友好原则设计，但本轮未运行任何
   编译/发射（协调章程实验排程约束）。实现切片必须实测发射；若仍失败，如实
   记录为独立几何问题（对齐 A1 的处置口径），不得修绿几何代码或改写为路线
   失败。
2. **过渡建模形态未冻结**：`T01` 以「带中心线的真实边 + 普通连接」建模
   （设计方案 §2.4 建议）；是否还需 Junction/ManeuverPath 声明（以及
   `road-junction-model.md` §17.4 merge/diverge 独立 G1 的适用性）是
   `needs-g1` 未决项，样本不预设结论。
3. **占用投影公式未冻结**：`transition_material.t01.occupancy_projection` 只钉
   要求与映射对象；精确公式、与 `vehicle-following.md` §6.4 overlap 判据的
   组合顺序属 #237 G1。
4. 本样本不得被用作「换道已实现/已安全」的证据；它与 A0/A1 证据一样，只证明
   输入与期望被完整钉版。
