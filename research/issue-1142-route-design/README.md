## 一句话结论

**路线展开（converter）不产生横向转移，只消费它们**：缺过渡材料即
`lane-continuity-gap` 失败关闭，`can_complete`/`materialize_path` 在设计接受前
不放宽；**#237 最小换道子合同**（8 项：物理相邻、跨越许可、固定过渡、双占用
投影、目标前后车与源后车、进入仲裁、原子提交与车尾清空、快照重放）负责把固定
预制过渡（建议物化为带中心线的真实边 `B0_up→T01→B1_down`）证明为可执行；
注册成功不是安全证明。
