# 有界采样的重复计算优化与同样本开销

任务：[#1093](https://github.com/illusion-tech/laneflow/issues/1093)，父议题
[#790](https://github.com/illusion-tech/laneflow/issues/790)。比较基线来自
[#1090](../issue-1090-s1-validation/README.md)，输入仍是 #1084 的同一 17 条真实样本。
本轮只改变测试研究入口，生产采样、阈值、失败清单与 G1 状态没有改变。

## 结论

2026-10-27，同机串行交错测量中，样本搜索与候选指标构造的中位耗时由
**9.677 秒降至 5.335 秒，减少 44.9%**。全部候选程序、跨度参数和指标逐值相同，
没有新增恢复：9 条原失败边仍只有 `sumo::-10004_5_1` 产生 8 份候选，
6 条因划分预算截断，2 条耗尽当前有限候选族。

扫描复用贡献主要收益。去重在本次真实样本中没有命中重复项，未证明其性能收益。
游标式回溯复用前缀坐标和已算指标，减少了部分重复计算；它没有解除六条样本的预算截断。
当前证据仍不足以接受生产 S1 的 G1。

完整路径 A / D 实跑结果相同：34 条目标路径的基线为 7 条接受、3 条跨边方向拒绝、
24 条缺失程序；候选赋值为 8 条接受、3 条方向拒绝、23 条缺失程序。
全部 16,265 条原成功边重放，完整 f64 程序和画布选择键相同。
8 条接受路径仍全部无信号，真实多边同时恢复和有信号路径恢复没有新增证据。

单边观察到的最大保留量：6 张扫描表、3,078 个累计 f64 值、12 个回溯帧、

这些是容器内容计数，**没有测量 allocator 堆峰值**；节点、容量、JSON 指标、
候选程序和临时参数向量等额外分配不能据此视为零。

## 实现规则与实验预算

- 同一固定 cubic 的 512 步累计切向扫描只计算一次。命中时比较全部 6 个控制 /
  方向向量的 f64 位；插值算术与原函数逐位对照。零初始导数和零累计角保持拒绝语义。
- 去重比较完整有序 f32 规范点的位值，保留首次出现的 f64 代表。中间点变化不能被
  首末点相同掩盖，原始 f64 不同但量化后相同的候选可被去重；没有用哈希替代相等。
- 每个回溯帧保存下一划分序号、已见规范点序列和当前前缀。父帧变化时丢弃全部子帧，
  因而不会跨不同入射方向复用“已通过”结论。复用的坐标仍逐点进入原
  `EmissionSink`。保存的指标随对应前缀一起复用。
- 等 t / 等累计切向角的顺序、每 cubic 的 2–2,048 片候选族、1.95° sink 阈值、
  严格大于 0.1 m 的弦下限和 0.95° 完整边端弦约束保持原研究规则。
- 每边至多 32,768 次划分尝试、32,000,000 个工作计数、8 份唯一完整程序。
  D 的工作计数包含新候选点使用、切向求值和复用前缀点使用；重复检查仍付预算。
  完整路径共享赋值仍以 128 次为上限。
- 每边至多 256 个 cubic / 回溯帧、262,144 个去重键点、262,144 个前缀点；
  去重键预算同时包括活动帧和完整程序去重集合。扫描、去重和回溯存储超限均记
  `budget_truncated`，不会改记为候选族耗尽。

本次最大值均远低于新增存储上限。六条未恢复边触及的仍是划分尝试上限；
恢复边达到程序池上限；两条无候选边穷尽当前有限族。这些结论都不证明其他划分无解。
实验限额、去重等价关系和计数对象仍不是生产资源合同。

## 测量协议与结果边界

硬件为 AMD Ryzen 9 9955HX、32 个逻辑处理器，Windows x86_64，Rust 1.99.1。
四个可执行文件使用相同 workspace test profile：converter 为 opt-level 0，
compiler 等依赖沿用仓库的 opt-level 2 覆盖，并非 release 性能测试。

先按 A B C D 各运行一次预热，再串行执行
`A B C D D C B A A B C D D C B A`。每轮新进程，测量期间本任务没有编译或运行其他测试。
原始输入先逐位对照 #1084，再重放原程序或完整错误，包括真实钳制来源。
这些验证、JSON 输入解析和文件写出不计入每条边的计时；候选搜索、几何指标和返回记录
构造计入。它衡量当前研究入口的实际成本，不是纯采样内核吞吐。

机器没有做 CPU 亲和绑定或独占隔离。正式轮次开始前系统 CPU 观测为 5%–25%；
两次进程快照间观测到的其他进程 CPU 时间为每轮 5.078–19.031 秒。
该竞争量仅覆盖两次快照中均存在的进程，不是所有后台 CPU 的完整账本。
中位数、全部轮次、进程 CPU 和每边计时保存在 [measurements.json](measurements.json)。
没有只取最快轮次，也没有给小差值做统计显著性声明。

包含全网准备的完整验证单次耗时为 A **158.483 秒**、D **218.210 秒**；其中未改动的
全网转换阶段分别为 **133.821 / 186.280 秒**，8 次共享赋值编译为
**12.238 / 18.496 秒**。这两次完整运行没有采用交错复测，不能给出全流程加速结论；
本轮实际观测也没有显示全流程提速。阶段明细保存在 [comparison.json](comparison.json)。
不得将局部 44.9% 节省外推为全网生产转换性能或所有失败边的恢复率。

## 恢复与完整路径验证

四阶段输出的全部候选程序、跨度参数和指标均与 A 精确比较相同；每阶段的预热及
4 次正式输出又分别逐字节相同。单纯扫描复用未改变枚举结果；去重没有真实命中；
有界回溯在相同上限内访问的部分中间状态改变，但最终保留池相同。

A 和 D 分别运行了完整 pinned LuST 验证，重新核对 8 个来源文件及来源提交，
导出的 17 条完整输入逐字节相同。D 计时入口与完整入口的候选、搜索计数精确一致。
A / D 的目标路径、所有共享赋值试验、最佳赋值及其 compiler 结果精确相同，
接受边的全部 f32 规范点仍由测试逐点核对。
B / C 没有单独重跑完整 compiler；它们消费的全部候选程序与 A 一致已单独验证。

恢复见证仍为
`sumo:--30608#7_2 → sumo::-10004_5_1 → sumo:--30608#6_1`。
其首候选仍为 43 条 Line，最大控制多边形偏离估计约 7.773 mm、网格观测约
4.520 mm，compiler 长度为 11,167 mm，相对源长度 11.05 m 多 117 mm。
这些普通 f64 数值估计仍不是浮点认证的连续界。

当前完整结果见 [results.json](results.json)，阶段计数和相等性核对见

## 重建与验证

在对应阶段提交构建 converter 库测试可执行文件：

```text
cargo +1.99.1 test --locked -p laneflow-lust-converter --lib --no-run --message-format=json
```

将 `S1_BENCH_INPUTS` 设为本报告提供的 inputs.json 副本，将 `S1_OUTPUT_DIR`
设为每轮独立且尚不存在的输出目录，再从构建结果的 executable 字段找到测试程序，
按上面的顺序以这些参数运行：

```text
output::emit::s1::measurement::fixed_sample_search_measurement --exact --ignored --nocapture
```

每轮产出 results.json 和 timing.json。旧阶段从冻结 Git 提交重建，不在当前树选择
旧算法。用于比对的输入与可执行文件 SHA-256 记录在 comparison.json 中；
这是供人工使用 PowerShell Get-FileHash 等独立工具复核的互操作摘要，不参与候选去重。

完整验证设置 `LUST_SOURCE_DIR` 为 pinned LuST 来源、`S1_OUTPUT_DIR` 为新目录后运行：

```text
cargo +1.99.1 test --locked -p laneflow-lust-converter --lib output::emit::s1::pinned_lust_s1_sample_validation -- --exact --ignored --nocapture
```

普通回归 **211 passed / 0 failed / 12 ignored**；fmt、check --tests、
clippy --all-targets -- -D warnings 通过。新增回归覆盖钳制来源往返、扫描参数逐位等价、
规范点精确去重、去重预算、前缀坐标重放、入射方向隔离、失败后游标推进与工作预算回滚。
没有运行其他 ignored 全网验收或重建失败 manifest。

## G1 输入

本轮支持继续保留扫描复用作为研究候选。去重的正确性已由构造案例覆盖，但当前真实
样本没有提供它减少开销或增加恢复的证据。游标式回溯降低了一些重复工作，仍未改善
恢复结果；不能据此把当前搜索预算冻结为生产默认。

下一步仍需解释六条样本的预算截断与候选覆盖，明确总预算的计数对象，并补充真实
多条恢复边、控制器闭包和有信号完整路径证据。原成功边涉及的三组方向失败继续属于
独立几何范围。#790 和生产 S1 的 G1 保持开放。
