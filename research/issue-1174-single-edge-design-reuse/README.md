## 结论边界与差异记录

**探索性定位**：本批是方法复用性探针。148 族在 7 个单缺边形态 **0/7 出候选**——有限族完成只表示本族未通过，不作无解证明；见证/排除/未决均只对原固定曲线成立；零恢复为有效结论。**方法复用性观察**：族内拟合拒绝占比 53–63% 主导拒绝来源，叠加 C12（0 候选）与 #1136 的 `-10564_3_0`（1 候选）——148 族在单缺边形态的出候选率为 1/8 边，指向该设计族的系统性不足（g1-proposal 待决选项记录）。

**过程记录（实现缺陷/口径澄清/授权，均不改研究口径）**：

1. **复核域计费口径（lead 裁定 A）**：首跑基准拟合被 32M 句柄截断（`bounded reference polyline fit`）——#1154 同表示资格的实现先例仅覆盖 2 点源（S=1，反向 ≈25.2M），本批 7 边源点均 5 点（S=4，67–84M）；裁定复核域无工作预算上限、只记实耗（独立句柄 `source_fit_remaining=u64::MAX`），搜索域零改动。中止批次归档 `candidate-run-aborted-review-domain-budget*`。
