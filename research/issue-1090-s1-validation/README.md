# 真实 LuST 样本的有界采样与完整路径验证

任务：[#1090](https://github.com/illusion-tech/laneflow/issues/1090)，父议题为
[#790](https://github.com/illusion-tech/laneflow/issues/790)。本研究检验
[#1084 候选设计](../issue-1084-lust-sampling/s1-design.md)，为生产 S1 的 G1 提供输入。

## 结论

2026-10-27，Rust 研究代码 `fd93e363a3aba13939376838220b225c25c08eda`，
合入基线 `baebb3031bafbc4786525850cf4744626febfb16`，Windows x86_64 / Rust 1.99.1。
输入为原 17 条样本，重新验证全部 8 个 pinned LuST 文件及
`c4bd5bd3751d426d42a9a1749c815e47ea188549` 来源提交。

- 8 条原成功样本保留程序；全量 16,265 条原成功边另行重放，完整有序段、全部 f64
  坐标位和画布选择键相同。
- 9 条原失败样本中，`sumo::-10004_5_1` 找到 8 份符合本次筛选规则的候选程序。
  首个候选的真实完整路径通过 compiler，所有规范点逐点核对一致。
- 6 条样本用尽每边 32,768 次划分尝试后截断；2 条穷尽当前有限划分族。
  截断与有限族耗尽都不证明其他划分无解。
- 17 条样本关联 34 条真实完整路径。原程序赋值为 7 条接受、3 条跨边方向拒绝、
  24 条缺失真实程序；候选赋值为 8 条接受、3 条跨边方向拒绝、23 条缺失真实程序。
  三条方向拒绝涉及原成功边，在保持成功程序不变的本范围内继续保留。
- 当前生产采样、阈值、锁定失败清单和全网转换结果均未改变。本研究不接受生产 S1
  的 G1，也不关闭 GE1、换道或 Runtime 的验收。

完整结构化结果见 [results.json](results.json)，两个独立进程的复验与分阶段耗时见
[verification.json](verification.json)。完整结果包含每个候选的程序与控制点、34 条路径的
前后结果、缺失边、诊断和全部 8 次共享赋值试验。

## 实验范围与搜索规则

研究仅在 `cfg(test)` 下显式开启。原成功边直接使用原程序；失败边重走同一源中心线、
钳制方向、倒圆和 span 构造，只替换固定 cubic 的划分。直线 span 沿用原发射行为。
每个 cubic 按片数 2 至 2,048，依次测试等 t 与固定 512 步累计切向角划分，候选点按原
cubic 求值，末点强制使用原 b；不在候选片内递归启动搜索。

每条候选使用真实规范坐标和原 `EmissionSink`：量化弦长严格大于 0.1 m、相邻弦角
不超过 1.95°。完整边首末量化弦与已有钳制方向的偏角还须不超过实验值 0.95°。
这些局部条件只是筛选，最终接受来自真实 compiler 的 Balanced5Cm / Balanced2Deg。

本轮上限为：

| 计数对象 | 实验上限 |
| --- | --- |
| 单次固定 cubic 候选枚举 | 4,094 个划分 |
| 每条边的累计划分尝试，含重放和回溯 | 32,768 |
| 每条边的候选点使用与切向求值预算 | 32,000,000 |
| 每条边保留的完整程序 | 8 |
| 所有边共享候选赋值的组合试验 | 128 |

按 span 顺序深度优先枚举候选序号；当前 span 耗尽后回退到前一 span。重放和重复的
前缀计算全部计入上述预算。候选片本身不递归。达到 8 份程序也记为预算截断，不能
称为该边的全部解；程序未按规范 f32 点去重。候选参数扫描包括算法的数值近似，
不是所有非均匀划分的完备搜索。

全局赋值按边名和候选序号确定顺序，同一边在每条关联路径中消费同一程序。本输入
只有一条失败边产生候选，故执行 8 次组合即可遍历保留的候选池；这不等于穷尽更大的
候选族，也没有完成多条同时恢复边的真实组合覆盖。

## 完整路径夹具

从完整转换模型保留真实 `entry + 全部 internal + exit`，保留原 namespace、边键、
movement 归属、全局 `path-*` 序号、速度、车道宽度和 alignment/corridor/section/lane
声明。使用全部路网先计算的钳制，裁剪后不重新计算钳制。

有信号时，保留整个关联控制器、相位状态、全部 group 及其受控路径，直到引用闭合；
保留停止线与机动门，不改写控制器状态来迎合单路径夹具。额外关联边缺失真实程序时，
整项标为 `target_check_not_completed / emission_prerequisite`。占位程序不进入 compiler。
不增加人工直线 lead，不把真实 approach 改为内部边。

compiler 接受后按原稳定身份字段找到每条边，核对全部规范点，再读取实际
`length_mm`。编译拒绝只有在诊断指向目标路径的相邻边时才归为接缝位置或跨边方向
拒绝；其他阶段和前置失败单列。本轮 23 个未完成项均停在缺失真实程序的前置阶段。
34 是目标路径数，控制器闭包带入的依赖路径不重复计作额外目标通过数。
本轮 8 条真实接受路径均无信号；真实有信号目标仍受缺失真实程序限制。

普通回归覆盖控制器引用闭包、原路径序号、多个 internal、共享入口、真实程序缺失、
接缝拒绝与边内前置失败的区分。带控制器的合成夹具通过不替代真实有信号路径验收。

## 恢复样本的几何与长度

`sumo::-10004_5_1` 的首个候选使用 7、9、20、7 片，共 43 条 Line 段。
真实路径为
`sumo:--30608#7_2 → sumo::-10004_5_1 → sumo:--30608#6_1`。

- cubic 与量化弦的同参数差曲线控制多边形估计上界最大为 **7.773 mm**。
- 每区间固定 9 个参数点到所属弦的观测最大为 **4.520 mm**；这不是整条折线的
  连续最近距离界，也没有只比较位于曲线上的采样顶点。
- 每 cubic 以 4,096 个参数区间累加弦长与控制多边形长，原 cubic 总长约
  **11.167570837 m**。原始两侧估计分别保存在 JSON 中。
- 候选逐弦 f32 长度提升 f64 后累计为 **11.167177767 m**；compiler 视图提交的
  空间弧长为 **11.167178154 m**，实际交通长度为 **11,167 mm**。
- 源 `@length` 为 **11.05 m**，最终交通长度与其相差 **+117 mm**。

偏离与长度区间计算使用普通 f64；实数算术下的控制多边形结论不自动成为浮点认证界。
尚未冻结连续误差、舍入余量或长度偏差的新产品门槛。ADR 0022 的表示误差预算和原
采样 0.01 m 矢高目标不被挪作新的 S1 合同。

## G1 建议与下一步

本轮提供一个真实的完整路径恢复见证，但不足以把当前枚举方式冻结为生产默认：
6 条样本的搜索受预算截断，真实多边组合和有信号路径的候选恢复仍缺证据。
下一切片应先验证固定 cubic 的参数扫描复用、候选去重和有界前缀回溯，明确全局
预算的计数对象，再在相同输入上复测并补充真实多边 / 控制器闭包覆盖。

若继续保持全部原成功程序不变，三组跨边方向失败应由独立几何范围处理；若要改变
它们，需在 G1 明列允许改动的确切边及所有关联路径，不能暗中扩大 S1。
资源记录目前为 debug 测试入口，包含观察、比较与度量成本；它不是生产转换性能
结论，不据此线性推算全部 8,230 条失败边的运行时间或恢复率。

两次运行的确定计数相同：累计 **205,457 次划分尝试、211,115 个候选点使用、
52,669,197 次切向求值**。样本研究阶段分别为 10.056 / 9.618 秒，8 次完整共享赋值
编译阶段分别为 16.309 / 15.761 秒；全流程为 186.216 / 204.583 秒，主要时间来自
原全网转换。第一轮与本地检查工作重叠，这些 debug 耗时只描述研究开销。
切向扫描计数显著高于候选点使用，是先验证固定 cubic 扫描结果复用的依据。

```text
cargo +1.99.1 test --locked -p laneflow-lust-converter --lib output::emit::s1::pinned_lust_s1_sample_validation -- --exact --ignored --nocapture
```

`timing.json` 是每次实测耗时，不要求相同。原探索轮没有保留全局路径序号和完整控制器
闭包，不参与此处正式结论；本地正式复验使用修正后的两个结果。
