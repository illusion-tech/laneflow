# 依赖分量中的几何候选恢复研究

本计划先冻结清单规则，再运行候选实验。依据 #1107、ADR 0022 / 0028，以及
[#1105 的修复后基线](../issue-1105-direct-successors/README.md)。仅使用 Rust 测试研究
入口；生产 S1 的 G1 未接受。

## 清单规则

输入为现有 pinned LuST 和 #1105 的固定 84 条目标。先对全网所有真实机动路径建图，
不是只在 84 条目标内部求闭包：

- 路径依赖包含 entry、全部 internal、exit，以及所引用停止线所在边。
- 共享原失败边的路径属于同一分量。原成功边完全固定，不引入候选选择耦合。
- 同一完整信号控制器的所有相关路径属于同一分量，包括其全部组、相位、机动门与
  停止线。共享失败边与控制器关系取传递闭包。
- 只选择与原 84 条目标相交的分量；每个分量以成员路径 ID 的字典序最小值命名。
  同一可变边只能属于一个分量，原目标恰好分配一次。

## 初始实验优先次序

按完整分量的缺失程序数、分量 ID 排序。主实验选取缺失一到两条程序、至多 64 条
关联路径和 128 条关联边的分量，累计至多 32 个分量、64 条待搜索边。
遇到超限分量保留完整清单与排除原因，不裁掉成员后纳入。零缺失分量保留为基线
对照；多缺失分量保留为后续研究范围。

选样不依赖新搜索结果。清单运行完成后保存实际分量及边集合，再冻结候选族和各项
工作、存储与组合上限，之后才运行搜索。

## 验证边界

清单与后续覆盖入口每次重新捕获生产转换，并逐行比较 #1105 修复后保留的完整
成功程序、规范点、失败诊断和转换拓扑/控制信息。大体积快照保存在本机证据目录，
研究报告记录源码与可复跑入口。SHA-256 仅为外部 `Get-FileHash` 的互操作核验；
内容相等依据完整值与完整字节。

后续实验保持源形状、曲线控制点、端点、钳制方向、倒圆切点、span 分界和控制锚点。
候选只改变固定 cubic 上的采样划分。完整路径和 LFCA 后发射检查决定接受，原成功
几何不被替换，三个原跨边方向拒绝另列。有限族耗尽、预算停止、缺失真实程序与
编译拒绝分别报告，不把没有恢复解释为数学无解。
