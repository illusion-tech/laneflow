# 依赖分量中的几何候选恢复研究

本计划先冻结清单规则，再运行候选实验。依据 #1107、ADR 0022 / 0028，以及
[#1105 的修复后基线](../issue-1105-direct-successors/README.md)。仅使用 Rust 测试研究
入口；生产 S1 的 G1 未接受。

## 清单规则

输入为现有 pinned LuST 和 #1105 的固定 84 条目标。先对全网所有真实机动路径建图，
不是只在 84 条目标内部求闭包：

- 路径依赖包含 entry、全部 internal、exit，以及所引用停止线所在边。
- 共享原失败边的路径属于同一分量。原成功边完全固定，不引入候选选择耦合。
- 同一完整信号控制器的所有相关路径属于同一分量，包括其全部组、相位、机动门与
  停止线。共享失败边与控制器关系取传递闭包。
- 只选择与原 84 条目标相交的分量；每个分量以成员路径 ID 的字典序最小值命名。
  同一可变边只能属于一个分量，原目标恰好分配一次。

## 初始实验优先次序

按完整分量的缺失程序数、分量 ID 排序。主实验选取缺失一到两条程序、至多 64 条
关联路径和 128 条关联边的分量，累计至多 32 个分量、64 条待搜索边。
遇到超限分量保留完整清单与排除原因，不裁掉成员后纳入。零缺失分量保留为基线
对照；多缺失分量保留为后续研究范围。

选样不依赖新搜索结果。清单运行完成后保存实际分量及边集合，再冻结候选族和各项
工作、存储与组合上限，之后才运行搜索。

## 验证边界

清单与后续覆盖入口每次重新捕获生产转换，并逐行比较 #1105 修复后保留的完整
成功程序、规范点、失败诊断和转换拓扑/控制信息。大体积快照保存在本机证据目录，
研究报告记录源码与可复跑入口。SHA-256 仅为外部 `Get-FileHash` 的互操作核验；
内容相等依据完整值与完整字节。

后续实验保持源形状、曲线控制点、端点、钳制方向、倒圆切点、span 分界和控制锚点。
候选只改变固定 cubic 上的采样划分。完整路径和 LFCA 后发射检查决定接受，原成功
几何不被替换，三个原跨边方向拒绝另列。有限族耗尽、预算停止、缺失真实程序与
编译拒绝分别报告，不把没有恢复解释为数学无解。

## 冻结清单与候选实验

清单由 `d9b4ffb9` 的 release 入口生成，见 [inventory.json](inventory.json)。原 84 条
目标对应 53 个完整分量、183 条关联路径；按上述规则选中 15 个分量、18 条缺失边，
涉及 26 条关联路径和两处信号控制器。本节在这些边运行新候选搜索前冻结。

18 条边中 13 条属于 #1103 的 43 条搜索集合，另五条此前没有搜索。旧族对这五条边
的新增候选属于覆盖扩展收益，必须与新族的额外恢复分开报告；不能全部归功于新算法。
五条新增对照为 `sumo::-10564_3_0`、`sumo::-19726_2_0`、`sumo::-20112_0_0`、
`sumo::-25490_4_0`、`sumo::-7348_3_0`。

对照为现有等参数/等切向角划分族，单边划分上限 32,768，原六条候选边的 48 份程序
继续保留。新研究族使用固定 cubic 上的 512 等分参数网格，共 513 个节点：

1. 保留显式首末点，其他节点按现行 cubic 运算求值，再按现行方式量化。候选弦须
   通过实际规范最短弦检查；其子 cubic 控制包络与同参数量化弦的普通 f64 偏离估计
   须不超过 0.01 m。这是研究筛选条件，不是连续误差认证，也不改变旧族的接受规则。
2. 以有向前进弦为状态，按广度优先顺序搜索；同一末两节点只保留首个确定前缀。
   各节点的出边按终点参数递减排列。状态转移使用实际量化弦的 1.95° sink 检查，
   起始弦还消费真实进入方向；整边首末弦继续通过原 0.95° 钳制检查。
3. 搜索得到的终端状态按末弦与固定末切向偏差、片数、参数索引序列排序，保留至多
   32 个代表路径。完整边跨 span 继续有界回溯；同一规范点序列只保留首个代表。
   状态合并与代表路径上限都意味着没有枚举所有网格路径，更不证明所有连续划分无解。
4. 单边至多保留八份新程序；每个 cubic 搜索至多 65,536 个状态，每边至多 256 个
   回溯帧、262,144 个保留参数点。总工作上限为 32,000,000 次节点求值、弦筛选、
   转移检查及前缀点重放之和。分别记录这些计数、峰值内容量和停止原因；它们不是
   分配器峰值或与旧算法同价的 CPU 指令计数。

旧候选池与新候选池按完整规范点去重后合并，每边至多 16 份；旧代表优先，原成功
边永不进入替换池。每个候选齐备的完整分量按边 ID 和候选索引遍历全部组合，上限
256 次；缺失一两条边的主实验因而可覆盖保留池的全部组合。超限或前置缺失仍单独
标记，不能把部分遍历写成穷尽。

每次赋值必须对完整分量的全部路径和完整控制器做一次真实联合编译及 LFCA 后发射
检查；只有整个分量接受才选择这份共享赋值。另重验原 84 条目标，并保存新增接受
分量的 LFCA、控制锚点和长度结果。

正式覆盖用四个独立原生进程，搜索顺序依次为旧→新、新→旧、新→旧、旧→新。
几何和组合结果必须一致，耗时另存；源码、可执行文件与输入在运行前冻结。耗时只
说明此机器上这组输入的实际研究成本，不外推为生产或全网性能。
