# 依赖分量中的几何恢复与共享组合

**结论：研究完成，生产 S1 的 G1 仍未接受。** 本轮冻结 15 个完整依赖分量、18 条
失败边后，补搜原候选族恢复了一条此前遗漏的无信号路径；新参数网格族零完整候选。
四次独立 release 进程的几何、搜索、组合与 LFCA 输出逐字节一致。

本研究对应 #1107，父任务 #790 保持打开。源码冻结于
`de65187c811ea86be2461ad2498a75995bb97268`，生产采样、编译器、阈值与控制锚点均未修改。
本轮只增加 Rust `cfg(test)` 入口与证据；Traffic Runtime API、数据格式、Adapter API、
依赖与许可证均无变化。新的决策输入见 [G1 Proposed](g1-proposal.md)。

## 范围与事前冻结

从 [#1105 修复后基线](../issue-1105-direct-successors/README.md) 的 84 条目标出发，
在全网真实路径中求共享失败边与完整信号控制器的传递闭包，得到 53 个分量、183 条
关联路径。成功边几何固定，不参与候选耦合；原目标恰好归属一个分量。

按缺失程序数、分量 ID 排序，预选缺失一到两条程序的分量，并执行路径、边和总量上限。
实际选中 15 个分量、18 条失败边、26 条关联路径和两处信号控制器；另外 38 个分量保留
完整成员及排除原因。[计划](plan.md) 与 [清单](inventory.json) 在新搜索运行前已提交。

18 条中有五条未进入 #1103 的 43 条搜索集合；它们的原算法收益单独计算。原六条边的
48 份候选继续保留。对其余重叠边，本轮重新运行的原算法报告及完整候选与 #1103 相同。
原始形状、钳制方向与来源、失败诊断见 [inputs.json](inputs.json)。

新族固定使用 512 等分参数网格、量化弦最短长度与 1.95° sink 检查、0.01 m 普通 f64
控制包络筛选、完整边 0.95° 钳制检查。状态为有向弦，广度优先保留同末两节点的首个
前缀，终端按末切向偏差、片数与索引序列排序，保留至多 32 个代表。状态合并、代表
上限和网格本身均限制覆盖范围；没有穷尽所有网格路径或所有连续划分。

## 组合验证与真实停止原因

每个分量只使用一份共享赋值，并把该分量的全部路径、控制器、组、相位、机动门和
停止线送入一次真实联合编译。只有整个分量接受才选用其赋值。原固定边不进入候选池。
候选组合按边 ID 和候选索引遍历，每分量上限 256 次。

最终 53 个分量中，26 个接受、24 个缺真实程序、3 个被原跨边方向约束拒绝。
对候选齐备的 29 个分量共执行 43 次赋值，全部穷尽各自保留池，无组合预算停止。
其中只有两个分量包含可变候选，各有一条候选边、八次赋值且八次全部接受。
因此，本轮**没有取得真实多候选边分量的正向接受证据**；缺候选的分量未执行赋值，
不能把它们写成组合穷尽或编译拒绝。

常规回归补充了两条共享可变边的完整信号分量：四份组合中仅完整正确赋值通过；另有
缺失依赖、错误候选、256 次停止前未访问的正确候选等反向测试。它们验证研究入口的
行为，不冒充真实 LuST 多边或信号恢复。

新网格族的搜索结果分为：

- 七条触及每边 32,000,000 工作上限。
- 另有一条结束于保留代表耗尽，但此前触及状态上限；连同上述七条，共八条有预算停止。
- 其余十条未触及工作/状态上限，结束于本次保留代表耗尽。
- 五条边至少一次触及 65,536 状态上限，十一条边发生过 32 个终端代表裁剪；这两项
  与工作停止可重叠，不能相加作互斥分类。

全部失败位置、固定控制点、进入方向与计数见 [grid-searches.json](grid-searches.json)
和 [resource-counts.json](resource-counts.json)。`retained_family_exhausted` 仅指本次代表
集合，不代表全部网格路径、连续划分或其他候选族无解。

## 几何、长度与控制锚点

每次重新捕获真实全网生产转换，完整保存并与 #1105 修复后基线逐行比较：

- 16,265 条成功边的全部 f64 程序和规范 f32 点，69,898,773 字节。
- 全部转换拓扑与控制信息，10,310,418 字节。
- 8,230 条失败边及原始诊断，4,541,257 字节。

接受分量逐点验证编译后几何与实际输入程序相同，并核对编译后的停止线所在边、
机动门路径与转换下标、信号组绑定。输出保存规范端点位表示及停止线所在边长度；
所有接受结果都经过 LFCA 后发射检查。源信号信息没有改写或裁去控制器成员。

新增边选定代表的发射累计弧长为 7.392294481 m，编译后规范弧长为 7.392294884 m，
整数长度为 7,392 mm，源声明为 7.39 m（整数长度对源声明 +2 mm）。该完整路径的
固定进入边仍保留原来的 +140 mm 源长度差，出口边为 0 mm 差；没有把源长度差当成
采样误差。选定候选四个 cubic 的最大控制包络偏离估计为 0.009709793 m，八份候选的
范围为 0.003762116–0.009709793 m，均为普通 f64 估计，未提供连续误差认证。
新增路径无控制锚点，不能据此宣称新采样已完成信号锚点验收。

## 确定性与复现

四次正式运行全部完成且退出码为 0。后三次分别对首轮的全部 84 份非计时文件执行
Windows `fc.exe /b` 完整字节比较，全部相等：包含 77 份 LFCA 和七份 JSON/JSONL。
这是三组独立逐字节比较，不以摘要相等替代内容相等。SHA-256 仅由 PowerShell
`Get-FileHash` 提供外部互操作核验，完整清单见 [evidence-manifest.json](evidence-manifest.json)。

大体积几何、可执行文件、源码 tar 和四次完整输出保留在
`E:/projects/laneflow/target/issue-790-806-handoff-20261026/dependency-recovery-20261028`。
仓库保存计划、样本、完整搜索/组合结果、时间、摘要与决策材料；未将约 85 MB 的
每轮几何/拓扑快照重复加入 Git。

复现使用上述冻结提交和 LuST `c4bd5bd3751d426d42a9a1749c815e47ea188549`。
先按 [#1105 复现说明](../issue-1105-direct-successors/README.md#复现与检查) 生成修复后
完整基线，或使用 `experiment-protocol.json` 中已经保存的基线目录。使用 Rust 1.99.1
对 `laneflow-lust-converter` 的 lib test 执行 release `--no-run` 构建，再直接运行生成的
测试可执行文件，过滤精确测试名
`output::emit::s1::recovery_coverage::dependency_recovery::experiment::pinned_lust_dependency_experiment`，
参数为 `--exact --ignored --nocapture --test-threads=1`。

环境变量：`LUST_SOURCE_DIR` 指向钉版源，`DIRECT_SUCCESSOR_BASELINE_DIR` 指向 #1105
修复后完整输出；`DEPENDENCY_OUTPUT_DIR` 每次必须是不存在的新目录；
`DEPENDENCY_ORDER` 按上述四次顺序取 `old-grid` 或 `grid-old`。样本、分量、预算、
原候选池均直接读取冻结源码及证据，不能替换为其他样本后沿用本报告结论。
