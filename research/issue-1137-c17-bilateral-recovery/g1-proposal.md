# C17 双边恢复新变量族探索后的生产决策材料

**状态：Proposed；未接受生产 G1。** 继承 [#1133/#1136 决策边界](../issue-1136-c12-curve-design/g1-proposal.md)与 #1137 冻结方案（[design.md](design.md) v3、[短首段证书](short-span-certificate.json)）；ADR 0022 / 0028 / 0033 现行权威不变。

## 本轮事实

在端点与首末钳制（原 f64 位）、原成功几何、拓扑、控制锚点与全部现行阈值不变、工作预算零提高的条件下，S1（内部 CR 结点切向扰动 ±6/12°）与 S2（pair-L/pair-R 逐组独立柄因子 {0.75,1,1.25,1.5}²）两新变量族对 C17 两条失败边 **547 列明配置零候选**（有限族完成、无预算停止）；负对照 281 配置（S1-keep + S2-pair-R，受短首段硬障碍证书覆盖）**零合法程序**、最早拒绝阶段如实记录，与证书保守下界 2.7804511 mm 一致。C17 两程序不齐备、联合赋值未进入、完整路径不接受——**如实记不齐备**。旧族（#1131 148 配置）只作对照列。

新增事实边界：单边独立柄因子族与内部切向扰动均未跨越既有阻点；短首段（span 0 端点距 0.19697715603589877 m）在冻结常数下的采样硬障碍已固化为入库证书（可复算、可负验证），keep 首 cubic 与 pair-R 首组在此常数下不可能产生合法划分——**这是已证的配置级结论，不是整条边无解证明**。

## 下一设计范围（待决选项，不预设）

1. **改变短首段必要条件方向的构造**：合并短首段的组（pair-L/whole 路径）已试（pair-L 256 配置零候选，拟合弦近似误差项主导拒绝）；若继续，需新的拟合筛选口径或新的组构造——属新变量/新口径，须新冻结。
2. **跨边/整分量联合设计**（J 的联合自由度扩展）：现 J 只做池字典序枚举 + 接缝全角记录；跨缝切向协调等联合变量属新设计，须新 G1。
3. **来源拟合弦近似误差项的口径审定**：reference_error 对参数化敏感（直线输入因子≠1 先被拟合拒）——保守方向、既有口径；若生产需要区分「几何偏离」与「参数化近似误差」，属生产质量合同问题（工程目标 vs 数值认证）。
4. **未决/见证边的必要条件补强**（#1121 框架）：`-10564_6_0` 首弦、`-10564_3_0` 末弦的固定曲线诊断仍未决；补强取证不预设恢复结果。
