## 1. 问题与冻结事实（修正版）

C17（`sumo:-10564:--32172#4_0-to--31194_0::-10564_3_0.:-10564_6_0`）为单条完整路径，
需两份程序齐备：

| 边 | s | 点上限 96s+1 | 首末钳制（冻结，原 f64 位） | 既有状态 |
| --- | ---: | ---: | --- | --- |
| `sumo::-10564_3_0` | 2 | 193 | 末端 finish boundary clamp（起始 interior CR） | #1131 已有 1 份候选（几何 80，pair 合段、因子 [1.5, 1]、等 t 22 片） |
| `sumo::-10564_6_0` | 3 | 289 | 起始 start boundary clamp（末端 interior CR） | #1131 旧族 148 配置**零候选** |

**旧族拒绝分布（钉版 #1131 记录，已复算改正）**：`-10564_6_0` 进入划分尝试的几何
18 个，完整划分尝试 3,420 次（18×190），其中 **sink 拒绝 3,314 次、采样偏离拒绝
106 次**；全部 190 次均 sink 拒绝的几何只有 **3 个**（不是 18 个）。回折拒绝 51、
双向来源拟合拒绝 79、成功 0 不变。

**判定顺序事实**：`attempt` 的逐区间管线中 sink 失败即返回，端弦（0.95°）检查在其
之后；因此旧记录的端弦拒绝计数 0 **只说明未到达该检查**，不能推出端弦方向无问题。
柄长变化**本身可以改变曲率分布**；旧数据只证明「旧有限族未通过」，不证明柄因子
改变不了曲率。旧记录只有合并 sink 计数；`degenerate_chord` / `weld_turn` 子原因
是本轮新增观察口径（对照列重放可另行记录子原因观察，不改写旧记录）。

**短首段硬障碍（新事实，已固化入库证书）**：`-10564_6_0` 首段（span 0）端点距
为固定值（复算精确 0.19697715603589877 m；展示值 0.196977 m **非严格上界**）。
独立复核（`short-span-certificate.json` + 复核测试
`short_first_span_obstruction_certificate_recheck` + 参数化负验证
`certificate_tampering_is_rejected`）确认：keep 模式首 cubic 与 pair-R 首组共 21
个配置（S1 五种首结点扰动 + pair-R 首组 16 组柄因子）的控制点凸包直径复算精确值
同端点距，**保守上界声明 0.19697716 m**（向上取整）；**总余量保守上界
0.000211432024 m**（= f32 量化 √3×2⁻¹³ 0.0002114319833 + 曲线求值舍入
128·ε·尺度 0.0000000000405，向上取整）；两条连续合法弦（量化弦长严格大于
0.1 m，证明常量保守下限 0.099999 m；焊接全角 ≤ 1.95°）的端距**保守下界
0.1999690432 m**（2×0.099999×cos(0.975°) = 0.1999690432949 m，向下取整）；按
核验后的保守界：凸包上界 + 余量上界 < 弦对下界，**缺口保守下界 0.0027804511 m**
（复算精确 0.0027804552 m ≈ 2.78 mm；维护者较松包围 2.74 mm 结论相同）。每
cubic ≥2 片 ⇒ 任何划分不可能产生两条连续合法弦。该结论只覆盖列明配置，**不写
整条边无解**；合并短首段的组（pair-L / whole）改变该必要条件的方向。

### S1：内部结点切向扰动族（修订定义）

- **结点类型与切向来源断言（实际断言，不写「预期」）**：被扰动结点必须是内部
  Catmull-Rom 结点——运行时断言其切向等于相邻结点中心差分单位化（|t_k −
  unit(P_{k+1} − P_{k−1})| < 1e-12）且非规定倒圆切向；不满足即该配置记
  `knot_not_interior_cr` 并终止该配置（不静默）。
- **旋转定义（补齐）**：t'_k = t_k·cos δ + w_k·sin δ，δ ∈ {−12°, −6°, 0°, +6°, +12°}。
  旋转平面单位向量 w_k 的确定性顺序：
  1. 第一层取 c_k = unit(P_{k+1} − P_{k−1}) 的正交分量 w = c_k − (c_k·t_k)·t_k——
     CR 结点上 c_k 与 t_k 同向，**该分量必然退化**（|w| < 1e-9），这是正常路径而非
     异常；
  2. 回退取前一弦 d = unit(P_k − P_{k−1}) 的正交分量 w = d − (d·t_k)·t_k；
  3. 仍退化（|w| < 1e-9，即整段共线）再取后一弦 unit(P_{k+1} − P_k) 的正交分量；
  4. 三者全退化则 δ 强制 0 并记 `tangent_rotation_degenerate`。
  单位化顺序：先减投影分量 → 判模 ≥ 1e-9 → 再单位化 → 合成 t'（余弦/正弦系数
  保证单位长）。
- **δ=0 对照规则**：δ=0 配置的控制点位必须与同一构造在未扰动切向下**逐位一致**
  （校准断言）；与原参考控制点位的逐位比较结果如实记录（相等与否均记录，不强求）。
- 配置与模式：S1 只作用于 keep 分段（内部结点存在）与 pair-L 合并链（内部结点 2
  存在）。柄 = 各 cubic 自身弦长 / 3（不乘因子）。计数：`-10564_3_0` keep 5；
  `-10564_6_0` keep 25（**负对照**）+ pair-L 5（探索）。

### S2：逐组独立柄因子族（修订）

- 模式与变量：**pair-L**（`[0,1] [2]`，合并短首段，探索）与 **pair-R**（`[0] [1,2]`，
  新组序，**负对照**）。每组独立 (f_start, f_finish) ∈ D²，D = {0.75, 1, 1.25, 1.5}
  （原域中段细化子域，不外扩）；柄 = 组端点弦长 / 3 × 因子，组首末外侧切向沿原参考。

  `degenerate_grouping`。whole 单组无新自由度（共用因子空间由旧族重放对照列

1. 边序：`-10564_3_0`（S1-keep，δ 升序 5 配置）→ `-10564_6_0`。
2. `-10564_6_0` 组序：**探索组先行**——S1-pair-L（δ2 升序 5）→ S2-pair-L（因子元组

   每族取第一个完整合法程序。完整程序过原 sink（0.1 m/1.95° 量化预检）、存在
   钳制端 0.95° 端弦、0.01 m 逐区间筛选。

## 5. 边界情形（修订）

- 短首段负对照：keep 首 cubic 与 pair-R 首组受证书硬障碍；预期**零合法程序**、
  最早拒绝阶段如实记录（先采样偏离后 sink，不预期特定拒绝标签），逐配置记录
  预期 vs 实测；结论只覆盖列明配置。
- s=2（`-10564_3_0`）：pair/whole 退化同形，S2 不执行、记 `degenerate_grouping`。
- δ=0：控制点与未扰动构造逐位一致（断言）；与原参考逐位比较如实记录。
- 切向退化：三路回退顺序见 S1；全退化 δ 强制 0 + `tangent_rotation_degenerate`。
- 结点非内部 CR（规定倒圆切向或来源断言不满足）：记 `knot_not_interior_cr`，
  不扰动、不静默。
- pair-L 对角 16 配置：显式跳过 `skipped_old_family_overlap`，不消耗划分预算。
- 接缝跨边方向由真实编译裁决；不新增任何方向阈值。
- 失败边新规范长度不声称与来源 `@length` 相同；禁止比例缩放或重写源长度。
- sink 子原因为本轮新增观察口径（见 §1）。

  - 预期通过 P1（全链入口，钉合成输入）：三点共线直线链（弦长 0.5 m/段），keep、
    δ=0、因子对 (1,1)，等 t 2 片/弦 → 全筛选通过；
  - 预期通过 P2（全链入口）：K1 的 #1131 几何 80 重放（同 K1）；
  - 预期拒绝 R1（全链入口，钉合成输入 + 全 n×2 族）：短首段合成复刻（首 span
    端点距 0.1969771560 m + 后续长 span）keep 模式 → **零合法程序**，最早拒绝阶段
    如实记录（不钉特定标签；与证书反例锚交叉一致）；
  - 预期拒绝 R2（判定器直接入口，钉合成弧输入与 (族, n)，同窗采样偏离须先通过）：
    半径 3 m、圆心角 30° 合成弧 → `weld_turn` 子原因；
  - 预期拒绝 R3（判定器直接入口，同 R2 前置保证）：相邻点距 0.09 m 合成折线 →
    `degenerate_chord` 子原因；
  - 预期拒绝 R4（全链入口）：控制多边形负增量合成（回折）→
    `backtracking_rejected`（判定在划分前）；
  - 预期拒绝 R5（全链入口，钉合成输入）：离来源直线 0.1 m 的合成弧 → 双向来源
    拟合筛选拒绝（判据归属 `source_fit_rejected`，判定在划分前）。
  R2/R3 的判定器直接入口为逐配置尝试拒绝明细（E 公共扩展，见 §8）；落地前以
  全链入口的报告字段（sink 计数与子原因观察）交叉断言。

## 7. 复核规则

- 每配置保存：拒绝阶段、sink 子原因计数、划分尝试数、成功 n、控制点位（f64 bits）
  与参数位；每边停止原因与实际访问配置序号全量保存；负对照逐配置记录预期 vs 实测。
- 保留池去重（规范 f32 点位）与排序由独立单测覆盖；既有候选入池/截断/跳过规则各
  有断言（§2.J）。
- 候选接受只有完整筛选全过才成立；分量恢复只有 J 的真实联合编译接受才成立。
- 排除性表述仅限有限族口径与证书列明配置；任何必要条件排除/见证类结论按 #1121
  复核器口径独立复算后入报告。
- 四个独立 release 进程 ABBA、非计时输出逐字节比较；结果 JSON 禁计时字段；生成物
  外置（Release + MANIFEST），仓库只留方案、入口、证书与摘要。
