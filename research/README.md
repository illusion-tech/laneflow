# 研究源码与证据

`research/` 保存研究源码、实验计划、结论报告和简短的复核索引。目录中的实验与
诊断结论沿用各报告的观察边界，不等同于产品性能或交通质量认证。

完整诊断 JSON、逐拍日志、全量文件清单、环境转储及封存二进制应写到已忽略的
`target/` 或仓库外目录，再作为可下载制品交付。源码树保留人可审阅的结论、关键
统计摘要、冻结提交与制品地址、字节数、SHA-256 和复核方法。完整清单随制品保存，
不为保留证据另造一份全量索引进入 Git。规则见
[文档边界政策](../docs/governance/documentation-policy.md#研究证据与大体量生成数据)。

生产契约、规范输入和现有测试夹具按实际用途保留。比如
`issue-679-route-query/evidence/` 是当前 Runtime 完整性测试与研究编译使用的夹具，
仍随源码交付。

## 本机路径占位

研究文档、索引、脚本和提交的工具输出不写采集机绝对路径。以下占位只表示位置类别，
不是可访问的入口：`<evidence-root>` 为仓库外证据目录，`<checkout>` 为主 checkout，
`<worktree>` 为某个工作树根，`<cargo-home>` 为 Cargo 主目录。证据按冻结提交、
二进制与输入 SHA-256 或制品下载地址定位。

2026-10-10 起已提交的工具日志、构建 JSONL 与 WPR 统计只把上述路径前缀替换为占位，
其余字节不变；替换前原件可在 `7e4fc6ea` 及更早提交读取。
