## 2. 设计变量与不变量（design.md §设计变量；C12 特有说明）

- 可变：失败边内部 Bezier 控制柄；内部曲线分界是否保留（合并分界可跨内部位置，含跨原内部倒圆切点——**span 0/1 接缝为规定倒圆切点**（span 0 末弦见证对应位置），合段跨过它须逐候选记录 `crosses_prescribed_fillet_seam` 标记，不得写成纯采样优化）。
- 固定：原 SUMO 输入、全部原成功程序/规范点、身份、拓扑、控制器成员、信号组、停止线、机动门声明；`sumo::-10100_1_0` 首末坐标与首末钳制方向（起始 fan-out、末端 pair）保持原 f64 位；sink 1.95°、端弦 0.95°、规范弦严格大于 0.1 m、0.01 m 研究筛选、compiler 配置档全部不变。
- C12 特有：**单缺边单路径分量**，候选按现行接受口径全量验证（完整分量一次真实联合编译）；新规范长度不等同源 `@length`；禁止比例缩放/重写源长度。

## 3. 冻结候选族与选择（design.md §冻结的候选族与选择，逐值沿用）

- 每边保留原参考链对照；三组分段按序：保留全部原分界、顺序两段合并、整边合段；组内保持首末点与外侧切向。
- 新柄 = 组端点弦长 / 3 × 因子；首柄/末柄因子各遍历 `[0.5, 0.75, 1, 1.25, 1.5, 2, 3]`（外层首柄、内层末柄，组间同一对因子）→ 每组 49 份；**148 个预定义几何配置**（原参考 1 + 3×49），不按结果追加；记录实际访问的几何数与配置序号，148 是配置数不是已完成数。
- 回折拒绝：控制多边形在组端点弦方向的三个增量均须非负。
- 来源拟合双向筛选通过后：每 cubic 同片数 n∈2..96；等 t 与 512 步累计切向角两划分族各取第一个完整合法程序；每程序过原 sink、存在钳制端首末 0.95°、逐区间 0.01 m 筛选。
- 保留：固定顺序尝试；全局最多 8 份，按双向拟合估计最大值、两值之和、|规范长度 − 原参考弦长估计|、几何序号、划分族、n 排序；规范点全量位相同只留先到代表；仅对保留池声称组合穷尽。每配置的拒绝阶段、采样尝试数与成功 n 全量保存。

## 4. 来源拟合与长度口径（design.md §来源/参考/规范与锚点）

- 0.01 m 只筛新参考→量化折线逐区间；来源拟合为独立双向相对筛选：候选正/反向最大距离估计均不得劣于原参考对应值（估计规则 64 区间/弦，见 design.md）。
- 长度报告清单：来源 `@length`、来源 shape 折线长、原/新参考弧长（4096 分段弦长与控制多边形估计）、规范 f32 弦长累计、compiler `length_mm` 及差值；失败边新规范长度不声称保持不变、不等同源 `@length`；禁止比例缩放/重写源长度。

## 6. 资源与停止（design.md §资源和停止；段容量按 s=4 冻结）

每边：预定义几何配置 148、完整划分尝试 32,768、采样工作 32,000,000、来源拟合点到线段评估独立 32,000,000（工作预算沿原值不变）。段容量按原诊断实际参考段数 **s=4** 冻结，每段 ≤96 片，**临时程序 ≤ 96×4+1 = 385 点**（`search_with_curve_cap` 参数化断言）。其余上限沿 design.md：保留池 ≤8、去重键 ≤262,144 点、几何报告 ≤148 行。到限分别报告停止原因（缺程序/筛选拒绝/回折拒绝/有限族耗尽/预算停止/编译拒绝分列），并记录实际访问的几何数与配置序号；有限尝试无候选只表示本族未通过，不作无解证明。不追加预算、不放宽筛选；不预设必须恢复；零恢复为有效结论。首弦已证冲突与 span 0 末弦见证都只对原固定曲线成立，不外推到设计族。
