# #706 P3/P5 并行化的检查映射与成本对照

Refs #706。固定基线 `b99a282ee399e15687301265dd8b27e8f7457d27`（main，含 #717 全部
成果）。#706 在 #717 的 P2 预览分发之上新增 P3/P5 分发；本目录只保存该增量的对照基线与
成本证据，不改变算法、候选集合、资源生命周期或 1_024 分发阈值。

并行化不得把原先交错发生的计算、领域检查和真实预留重排为「全部算完再统一检查写入」。
两份文档分别记录这一约束的逐检查点对照，以及新实现相对基线的整拍成本。

## 目录内容

- [checkpoint-map.md](checkpoint-map.md)：增量 A 交付物。逐检查点记录当前串行实现的原
  逻辑位置、输入生产者、可能结果、原有预留、写入对象与并行化分类，作为 P5/P3 原语提取
  与分发的对照基线。文中路径均相对 `crates/laneflow-runtime/src/`。
- [cost-evidence.md](cost-evidence.md)：增量 E 成本对照证据（审阅者 §9.4，R6 修正版）。
  正常 release 非插桩两轮测量（返工前 + R1/R2/R4 修复后），含 `b99a282e` 有界对照；
  未测项逐条标注，插桩诊断与非插桩结果分开记录。

## 测量环境

- 场景：`examples/preview_parallel_wall_clock` 的 multi-gate 1_024 活动车（补员保持
  稳态），warmup 24 拍 + 测量 128 拍 × 3 rounds，逐拍整步墙钟 p50/p95；
  worker ∈ {1,2,4,8,16}。
- 机器：9955HX 16C/32T。同组内两臂串行执行、无并发编译负载。

**跨轮负载不同，绝对值不可跨轮直比**：`cost-evidence.md` 注明此前各轮测量期间有验证链
并发，只有 W1/W2 后短对照（2026-09-19，当前 head 重跑）是机器无并发负载的。因此本文件
不汇总 p50/p95 数值、不声称净收益；`cost-evidence.md` 另注明 `b99a282e` 基线对照为 R3
前中间修订测量、未在当前 head 重测。

测量口径、逐轮原始输出与结论以 [cost-evidence.md](cost-evidence.md) 为准；本文件不复述
其结论。
