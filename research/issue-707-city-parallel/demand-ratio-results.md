# #707：本拍准入需求占当前构造的比例

2026-09-22。状态：**方向保留，本轮不写原型。** 被让行查询读到的
frontier 只占当前插入的约四分之一。推入的候选里约 99% 在仲裁前已经拒绝，
授予约占 1%。两条都低于收口线。16 ms 目标未达到。

合同见 [需求比例计划](demand-ratio-plan.md)。保留组合不变，源码仍以
`target/issue707-m8-source` 为准。本轮只在副本上计数。

## 1. 比例

100k 长尾、4 workers、33 ms、256 拍，一次运行，统计 tick ≥ 65 的 192 拍。
`LF707_COAST=on`，并打开阶段计时和计数。单位除比例外是每拍个数的均值。

| 项目 | 均值 |
| --- | ---: |
| 走过的 Active | 72,765 |
| 其中缓存复用 | 72,730 |
| 整段重走 | 35 |
| 有插入的车 | 1,431 |
| 插入次数 | 3,270 |
| 插入过的 cell | 1,665 |
| 让行查询 | 564 |
| 既插入又被查询的 cell | 396 |
| 落在被查询 cell 上的插入 | 822 |
| 进入 Gate 求值的车 | 2,422 |

| 下游声明 | 14 |

按合同的均值：

- 被查询的已插入 cell / 插入过的 cell = **0.238**。192 拍里最高 0.318。
- 落在被查询 cell 上的插入 / 全部插入 = **0.251**。192 拍里最高 0.313。
- 一拍可达的插入 / 全部插入 = 0.314。这一列不参与收口。
- 推入时已拒绝 / 候选 = **0.990**。中位数是 1。最低 0.677。
- 授予 / 候选 = **0.010**。192 拍里只有 18 拍出现授予，单拍最多 440。

两条收口线都是 0.80。两条“缺口够大”的线都是 0.50。frontier 的两个比例
和 P3 的两个比例都落在保留一侧。192 拍里 frontier 的两个比例没有一拍
高于 0.50。

让行查询次数与被查询 cell 数在每一拍都相等：同一个 cell 本拍不会被查第二次。
被查询的 564 个 cell 里，约 169 个本拍没有插入，前沿是空的。

下游声明已经很少。672 个预检拒绝的候选没有再写下游声明，整拍平均只有
14 条声明。被物化的是候选 cell，平均 2,042 条。

## 4. 随后

按需构造 frontier，以及少做已经会拒绝的候选物化，这两条都还开着。
本轮按合同不写原型。

现有流程先走完约 7.3 万辆车，再得到平均 564 次让行查询。缓存已经挡住
整段重走，剩下的是每辆车的复用和一拍可达判断。真正被读到的插入大约
800 条。下一次若写原型，应先从本拍会做让行查询的车得到目标 cell，再只为

拒绝后跳过。
