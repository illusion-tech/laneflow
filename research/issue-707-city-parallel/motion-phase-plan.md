# #707 M1：Motion 四段成本测量

2026-09-22。承接 [C1 结果](constraint-reuse-results.md) 与
[激进优化计划](performance-first-next-plan.md) 的第 1 项。状态：测量合同，
结果见 [M1 结果](motion-phase-results.md)。本页在跑数前写定口径。实现使用
`lfence; rdtsc; lfence`。运动缓存探测和决策尝试的构造记在其余约束里，
没有单独拆出。第 3 条门槛未通过，名次见结果页。

保留组合仍是 B1 + H1。本轮不改跟车公式、约束规则、状态写入或调度，不引入
新缓存，不修正红灯 ETA，也不做 H2 降频。诊断耗时不能当成 Core 已降到某个
毫秒数，也不能与封存的无插桩 33–37 ms 直接相减。

## 测什么

对象是 4 workers 下每个 Active 车辆的 `vehicle_motion_outcome`，含它调用的
`calculate_active_vehicle_motion`。P2 预览走同一运动函数，但诊断时钟只在
Motion 任务里打开，预览不计入这四段。

四段互斥，按 CPU 周期累加后再换算。并行 worker 的周期相加，是 CPU 时间，
不是墙钟。墙钟另记三段：输入表收集、并行求值、join 之后的串行消费。

| 段 | 包含 | 不包含 |
| --- | --- | --- |
| 输入读取 | 停车绑定与有效性、预约/已到达、运动缓存查找；完整求值时的编译路线、边、长度、限速、profile、期望速度、前视窗取值 | 前车行走、门控、跟车公式 |
| 约束查询 | 等待/冲突停止约束、路终、信号停止、停车停止、停止点选择、决策资格里的门控、硬边界及其 hop 许可 | 前车查询单独成列，但与本列相加后才是“约束查询” |
| 跟车求解 | `si_comfort_travel`：包络、IIDM 或已给加速度、夹紧、前方限速 | 前后的查询和状态写入 |
| 下一状态构造 | 有限性检查、余量、`apply_travel_mm`（含行程中的 hop 许可）、速度落账、完成/到达、到达观察 | `boundary::advance` 与 join 后的串行消费 |

前车查询是约束查询的内部分列，用来避免再把“调用次数多”当成“时间多”。
`boundary::advance` 只作旁路列，不参与四段谁最大的判定。复用预览时不进入
完整求值，跟车求解记 0，等待/冲突查询仍算在约束里。

时钟用 `lfence; rdtsc; lfence`，每个区间结束一次。空转两次该序列的中位数记为
每个区间的计时开销，从该段周期里扣除，小于零则记 0。同时保留未扣除的原始
周期。扣减使用本拍采样得到的中位数。`lfence` 让区间在退休指令之后闭合，
也会压低相邻段的指令重叠；因此校正后时间和未校正时间的名次都必须一致，
才把某一段定为主要对象。进程启动时用约 50 ms 的墙钟标定 TSC 频率，不放进被测拍。

采样在正在提交的 tick 上：`tick >= 64` 且能被 4 整除。未采样拍只留分支，
不读 TSC。同一二进制里，稳态未采样拍的 Core / Motion 墙钟用来观察插桩
开销，不代表封存基线。

全局锁只在每个并行块结束时合并一次。车辆循环内不使用互斥量、Instant 或
共享原子加法。

## 如何判定“值得改”

场景固定为既有 `junction_long_tail-100k`，`approx/both/combined/boundary=on/decision=every`，
`LF707_OBSERVE=fused`，4 workers，33 ms 步长，每臂 256 拍。诊断臂重复 3 次，
串行，中间夹一次封存 H1 二进制的同长度参照，用来记录当天运行波动。另用
`junction_long_tail-10k` 看同一分段比例是否只在 100k 出现。

稳态取记录 tick ≥ 65。分位数用 `(n-1)*p` 线性插值。三次诊断都要保留。

四段比较用校正后的 CPU 时间。某一段成为下一轮原型的主要对象，需要同时满足：

1. 三次运行里，它在校正后和未校正的四段中都是最大段。
2. 它相对第二名的校正后领先，大于这三次领先值本身的跨次极差。
3. 校正后均值至少为该段被扣计时开销的两倍；否则视为还没露出工作量。

做不到这三条，就同时列出仍分不开的段，不指定单一原型。约束查询若胜出，
再看前车查询和其余约束谁占该段的多数，只把多数的那一类交给下一轮。
10k 若前两名顺序不同，100k 结论只覆盖 100k 长尾夹具。

本轮不启动优化原型，不创建 PR，不提交，不宣布 16 ms 或 33 ms 达标。
