# #707 M5：拆开还在执行的非前车约束

2026-09-22。状态：**测量完成，不指定下一次原型。** 九个桶的校正均值都低于
各自计时开销的两倍。三次运行的大小顺序相同，冲突停止最大。
短窗交通输出与 M3 逐字节一致。16 ms 目标未达到。

合同见 [M5 计划](motion-constraint-split-plan.md)。保留组合仍是
B1 + H1 + 屏障跳过 + 稠密 binding。

## 1. 测了什么

诊断二进制在保留配置上跑了三次。采样拍是运行时 `tick_index` 为 4 的倍数
且不小于 64；统计 harness tick ≥ 65 的采样拍，每臂 48 拍。
Active 为 70,761–74,392。进入运动原语的车辆均值 72,737，其中完整重算
70,978，其余走运动缓存。CPU 毫秒是四个 worker 之和，不是墙钟。
空转计时中位数三次都是 100 个 TSC 周期，TSC 约 2.4953 GHz。
每个桶每辆车记一次，对应开销约 2.915 ms（完整重算上的桶约 2.844 ms）。

| 桶 | diag-a | diag-b | diag-c |
| --- | ---: | ---: | ---: |
| 冲突停止 | 4.730 | 4.785 | 4.871 |
| 跳过用的 profile 与行程上界 | 2.214 | 2.229 | 2.226 |
| 信号停止 | 2.120 | 2.152 | 2.201 |
| 路终距离 | 1.457 | 1.476 | 1.517 |
| 硬边界与 hop 许可 | 1.163 | 1.180 | 1.211 |
| 运动缓存探测 | 1.095 | 1.109 | 1.164 |
| 等待停止 | 0.687 | 0.708 | 0.763 |
| 停止点合并 | 0.383 | 0.382 | 0.410 |
| 停车停止 | 0.354 | 0.355 | 0.396 |

单位是校正后的毫秒 CPU。顺序在三次运行里没有变化。冲突停止相对第二名的
领先约 2.52、2.56、2.65 ms，自身极差 0.142 ms。停车停止和等待停止都已经
落到 1 ms 以下。

两倍开销线是 5.83 ms。最大的冲突停止是 4.730–4.871 ms，没有一个桶越过
这条线，所以合同不把任何一个桶定成下一次原型的目标。

未采样拍的 Core 均值是 39.427、39.378、39.186 ms。采样拍约 56.0–56.2 ms，
多出来的是计时本身。这组绝对水平和 M3 dense 的 29.334 ms 不是同一次对照，
不替换保留组合的 Core 数字。

## 2. 交通结果

三臂的 `quality.csv`、`ticks.jsonl`、`events.jsonl` SHA-256 与 M3 的 100k
短窗相同。计时没有改计算结果。

## 3. 后续

保留组合不变，源码仍以 `target/issue707-m3-source` 为准。
M5 诊断留在 `target/issue707-m5-source`。没有进入正式 PR。

冲突停止是这些校正值里最大的一块，而且领先幅度大于它自己的运行间极差。
它没有通过事先写好的两倍开销线，本轮因此不启动原型。停车停止不是这块里的
大头。
