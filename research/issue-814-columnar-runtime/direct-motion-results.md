# P5 直接列消费与常规数值融合

Refs #814，PR #815 保持草稿。常规 P5 已改为直接读取运动列，并融合整数输出；
工作量变化可验证，普通整拍稳定收益尚未证明，A+B+C 接入验收仍开放。

本报告保留上一轮原件。2026-10-02 降低宿主负载后的 32 进程重测见
[后续重测报告](reduced-load-results.md)；它不改写下面的历史计时与拒绝记录。

## 来源与实现边界

- 前态：8fa2ad0fa275c0715dde0247beb76959e01cd059。
- 直接列消费：d48719c22b076fd5a2ea43b75185b8cb5426eb4e。
- 直接整数输出、普通统计关闭及必要读取清理：902ac9bfeacd9158861808408039a4d695c74a90。
- 普通采集工具继续冻结于 e18f93d72f76d66ba4671e813b7526e979f3de26。
  诊断工具冻结于 902ac9bf，对同一前/后源码独立导出；成对构建五项身份字段一致。
- 十万为总车辆，初始 75000 Active、25000 Parked；workers=4、AVX2、dt 33 ms，
  每进程 256 拍、无预热。不表示持续十万 Active、16 ms 达标或 #707 完整认证。

P5 绑定只读 ActiveBlock 后使用同一字段读取原语准备约束、基础和路线。
每行仍验证完整句柄、generation、目录位置及物理行；完整预览复用和实际停车
绑定按需组装原逻辑值。多 hop 复用已绑定的路线与 profile，真实 occurrence、
Gate、停车、carry 和到达语义保持。

常规数值子批直接输出整数 speed/progress/carry/travel 与状态掩码，省去稠密
浮点中间输出；全关闭组跳过计算，全启用通道的提案均复用时跳过 IIDM 重算。
普通构建使用不带逐行统计的内核，诊断和测试独立启用统计。AVX2/AVX-512
仍有有界局部数组、f64 量化及完整 u64 范围的标量回退，不能称为全程寄存器执行。
复杂限速/边界路径继续使用原阶段管线；MotionInputs 准备与 Batch 打包仍存在。

## 验证与原件

Runtime release + placement-fixtures：536 项单元测试、集成与文档测试通过，
20 项手工诊断忽略。纯数值 crate 十项测试通过，覆盖三后端、尾块、孔洞、
无效值、整数范围、关闭组、复用提案、直接输出长度拒绝及原参数比较语义。
研究 crate 121 项测试通过、3 项手工探针忽略；普通和诊断导出均编译成功。
最终 release Clippy all-targets -D warnings、格式、架构与提交说明检查通过。

同槽旧 generation 的隔离负向验证只削弱完整句柄为 index 校验，精确 oracle
报 NonFiniteMotion，原执行及冻结 EXE 重放均返回 101。首错、真实 reserve、
完整 join、重试、并发参与、资源账本、无半提交与稳态分配门禁保持。
源码绑定的 release 汇编观察确认统计开/关分立，直接量化辅助内联；它不是计时证明。
