# S1 的 G1 决策材料

**状态：Proposed，待维护者评审；未接受生产 G1。**

依据：[本轮完整报告](README.md)、[#1090](../issue-1090-s1-validation/README.md)、
[#1093](../issue-1093-s1-efficiency/README.md)、[#1099](../issue-1099-s1-release-retest/README.md)，
以及 [ADR 0022](../../docs/adr/0022-authoring-curve-and-canonical-polyline-error-budgets.md)、
[ADR 0028](../../docs/adr/0028-integer-millimeter-traffic-geometry.md)。
本材料不变更现有数值、几何或拓扑权威。

## 建议决策

暂不把当前 S1 研究实现接入生产，也不把默认划分预算提高为 262,144。
继续研究时保留 32,768 作为成本基线，262,144 只作为显式诊断档。
六条原截断样本零新增候选，扩展 43 条失败边的完整候选也没有随预算增加而改变；
约 5.96 倍的固定样本耗时没有换来完整路径恢复。更高预算目前只有排除当前有限族的
诊断收益，没有可据以设定生产默认值的恢复收益。

这不是停止后续算法研究的决定：固定族没有覆盖所有合法分段，12 条扩展失败边在高档
仍受预算截断。不能用“迁移成本”或这次有限实验否定未来不同候选族的持续收益。

## 已验证的范围

1. 原成功的 16,265 条边完整 f64 程序与规范 f32 点不变；两次完整输出逐字节一致。
2. 所有目标在同一轮消费同一赋值，原进出边角色、所有者内路径键和控制锚点保留。
   真实控制器关联路径未被删掉来制造单路径成功。
3. 84 条目标中 22 条原已接受，研究候选只恢复已知的一条，未损失原接受路径。
   14 条多内边目标已有 3 条接受；新增多失败边同时恢复和有信号路径恢复均为零。
4. 搜索、前置缺失、拓扑编译拒绝和跨边方向拒绝分开保存。实际负载和正式 / 停止运行
   标签可追溯；局部计时不外推为全网收益。

## 接受生产方案前仍须解决

| 待决项 | 本轮证据 | 后续验证要求 |
| --- | --- | --- |
| 无内边转接的拓扑声明 | 两个具备全部几何的信号闭包被 `LF-COMP-DISCONNECTED-MANEUVER-PATH` 拒绝；生产发射未给普通段间转接声明后继 | 单独界定拓扑修复切片，保留路径和控制器；修复后重新验证该闭包。不得塞入 S1 采样候选来绕过 |
| 有界候选族的恢复能力 | 六条旧截断样本仍零候选；43 条只有六条得到候选；新增五条候选边的闭包仍缺其他几何 | 在固定输入上比较新的候选族或失败跨度定位；分别计恢复收益、每次执行成本、执行频率和迁移成本 |
| 组合预算与依赖范围 | `8^6` 组合仅遍历前 128 次，前几个维度没有充分变化；31 条信号目标均未接受 | 先定义依赖连通分量与共享候选一致性，再决定遍历 / 剪枝和全局预算；对多边同时恢复及真实有信号闭包给出正向与反向回归 |
| 几何质量目标 | 当前网格和控制包络值均未认证，只描述候选跨度相对固定 cubic 的估计 | 明确沿用 ADR 0022 的 B1 工程质量还是另提连续硬保证；前者给出可测门槛和失败边界，后者另行证明含 f64 求值、f32 量化及整段范围的误差；两者都要区分源拟合偏离和采样误差 |
| 长度与控制锚点 | 接受边长度对源声明有 -5.003 至 +3.337 m 差异；包括原成功边 | 按既有权威分别验收源声明对照、编译长度、停止线、机动门及所有关联路径，不用局部采样误差代替长度契约 |
| 生产资源与失败语义 | 每边有操作和容器内容限额，但未测分配器峰值；候选池跨边保留 | 固定每边、每分量、全转换的工作和存储预算，测实际峰值，定义预算停止与有限族耗尽的可追溯诊断；禁止占位几何进入正常编译 |
| 原成功边的跨边方向问题 | 三条目标方向拒绝在基线和两档候选下都存在 | 另行界定是否允许改动原成功几何；当前保持原程序不变的 S1 范围不能消除此类问题 |

上述事项不是本轮已经获准的生产实现计划。父议题 #790 保持打开，不能把本研究子任务
完成解释为 G1 接受或 LuST 全网转换成功。

## 后续切片的完成边界

优先把无内边转接的拓扑声明问题单独处理，使已有完整几何的真实信号闭包能够走到目标
检查；同时保留本轮原始失败作为回归基线。之后再评估候选族和按真实依赖划分的组合搜索。
每个切片都需明确生产变更范围和自己的验收证据，不复用本报告的“研究已完成”标签。

本轮的直接产出是预算收益边界、真实失败分类及可重跑的 G1 输入材料；没有提供生产
参数冻结、连续误差认证、组合完备性或实际堆峰值认证。
