# 连续列运动数值内核

本 crate 是 ADR 0031 的纯数值边界。输入只包含受检切片，不持有车辆、路网、资源或
回调；Runtime 仍采用工作区的 `unsafe_code = "forbid"`。

安装时用 CPU/OS 检测选择整组 Scalar、AVX2 或 AVX-512 入口。没有全局目标 ISA、FMA、
近似倒数或 fast-math。运行时 ISA 分发、指针范围与尾部证明集中在 `lib.rs`、`x86.rs`。

执行包括整数 SI 换算、IIDM 未量化提案、安全投影、降速约束、f64 ties-even、整数
量化、carry、硬空间、同边推进和掩码多 hop。路线发现与规范资源消费由 Runtime 完成。
极大整数的 checked 标量分支仍保留，并由实际统计单独计数。

同布局三后端按位差分覆盖稀疏掩码、尾部、完整 u32 范围、非有限、溢出、舍入边界、
重复过边和阻塞；这些测试验证数值边界，不证明城市整拍收益。
